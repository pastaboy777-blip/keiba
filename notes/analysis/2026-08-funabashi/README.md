## 結論（2つの条件の掛け算）

**① 前半3F 37.0以上 → 前で決まる（3/3）。**
上がり幅が1.3秒あった8/6 7Rでも前が残った。**流れが緩ければ、終いの脚があっても位置を逆転できない。**

**② 前半3F 37.0未満 かつ 上がり幅 1.0秒以上 → 後方が来る（6/6）。**
8/2 8R・8/3 7R・8/3 8R・8/4 7R・8/5 8R・8/6 9R。例外なし。

**③ 前半3F 37.0未満でも上がり幅が小さいと前が残る。**
8/5 9R は前半36.1と速かったが上がりが **38.3／38.4／38.4** の0.1秒差で、4角1・3・4番手。
8/6 10R も上がり幅0.6で、勝ち馬は4角3番手（ただし2着6番手・3着8番手）。

→ **前傾ラップは「差しが利く土壌」を作るだけで、実際に差せるかは上がりが割れるかどうかで決まる。**
この2つを掛け算にすると、11鞍で判定が微妙なのは8/6 10Rの1鞍だけになる。

## ズブ穴としての使い方

- **前半3F 37.0以上が読めるレース**（逃げ馬が1頭だけ、頭数が少ない）→ 前の馬から。ただし人気になりやすく妙味は薄い
- **前半3F 36秒前半が読めるレース**（逃げ・先行が3頭以上）→ **後方待機の上がり上位馬**。ここが的
- 極端な例が **8/6 11R（前半3F 34.2）**。4角11番手の11番人気が勝ち、2着も4角12番手。
  **前半3Fが35秒を切るとレースが壊れて、人気が無意味になる**

これは川崎で使っている「399・上がり実数を先に見て、位置で最終選択する」手順と矛盾しない。
**位置で足切りする強さを、前半3Fの読みで調整すればいい。**
