### 読み取れること

**1. 399の最上位2頭が4角6〜8番手で4着・5着。** ⑥ザーシッダレイ（399=11.8・本物3）と
②セレナエフォール（399=11.3）は数字ではカード断然だったが、位置が足りず届かなかった。
**8/21の川崎とまったく同じ形。**

**2. 勝ったのは399=7.2・エッジ5・457kgの小型で、4角3番手まで押し上げた⑧。**
過去3走は 9-7-6 / 7-5-5 / 8-6-6 と、いつも「後方から4角5〜6番手まで押し上げる」形。
この日は**初めて3番手まで上がって**、そのまま上がり37.0のメンバー最速で抜けた。
4番人気・単760はズブ穴として理想的。

**3. 決定的なのは「上がりが割れなかった」こと。**
上位5頭の上がりが **37.0 / 37.3 / 37.4 / 37.6 / 37.7** と0.7秒に密集している。
終いの脚に差がないので、**位置差がそのまま着順**になった。

比較：8/21 川崎1Rでは◎⑧セイウンパイオニアが上がり38.4に対し2着馬39.8・1着馬40.2で
**1.4秒差**あり、4角11番手から3着に届いている。

→ **上がりが密集するレースでは位置が全て。上がりに1秒以上の差を作れる馬がいるときだけ、
後方型が届く。** 399の高さそのものではなく、「その馬の上がりがメンバーからどれだけ離れるか」
を見るべき。399はメンバー内での相対値ではないので、この判定には使えない。
