## 前日9/7から持ってくる ── 見るのは1つ

**「その組でいちばん速い上がりを使える馬が、4角でどこにいるか」。**

9/7はこれだけで12鞍が割れた。前にいた8鞍は三連単が最高7,240円、
後ろにいた4鞍が 34,240／70,710／77,280／**207,310**。

**終いを使える馬が前に行けるなら堅い。後ろに置かれるなら荒れる。**
12Rなら終いを使えるのは⑧キクノルタと⑫リュウバター。
**⑧が前めを取れれば堅く、⑫が後ろに置かれたまま⑤が逃げる形なら荒れる。**

**馬場は必ず1R・2Rの勝ち時計で確かめる。**
前開催の良は ダ1400が1:31.2〜1:32.4、ダ900が54.6〜56.2、ダ2000が2:13〜2:17。
**9/7は表示が「不良」のまま終盤にその良より速くなった。表示は見ない。**
