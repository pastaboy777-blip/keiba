**1番手だけが突出し、2〜5番手は測定値より悪い。**
6番手以降の4.4%は測定値どおりで、ここは動かない。

## 枠は出なかった ── 理由も出た

5日合計（人気薄365頭）。

| | 頭数 | 3着内 | 2026年の測定値 |
|---|---|---|---|
| 1〜2枠 | 59 | **5.1%** | 15.1% |
| 3〜4枠 | 73 | 8.2% | 12.3% |
| 5〜6枠 | 110 | **15.5%** | 10.9% |
| 7〜8枠 | 123 | 11.4% | 9.0% |

内枠がまったく出ていない。馬場で割ると理由が見える。

### 2026年の南関・人気薄　枠 × 馬場

| 場 | 馬場 | ぜんぶ | 1〜2枠 | 7〜8枠 |
|---|---|---|---|---|
| 川崎 | 良・稍重 | 11.0%(1830) | **15.3%**(275) | 8.3%(651) |
| 川崎 | 重・不良 | 11.6%(749) | 13.5%(111) | 9.8%(244) |
| 浦和 | 良・稍重 | 11.5%(1248) | 14.1%(205) | 9.7%(442) |
| 浦和 | 重・不良 | 13.6%(301) | 17.6%(51) | 12.9%(116) |
| 船橋 | 良・稍重 | 10.0%(2234) | 8.3%(456) | **13.1%**(719) |
| 大井 | 良・稍重 | 8.5%(2625) | 9.1%(440) | 8.7%(841) |
| 大井 | 重・不良 | 10.0%(1143) | 7.3%(191) | **13.7%**(365) |

川崎を前後半に割ると

```
良・稍重  全体 1〜2枠 15.3%(275)　前半 13.6%(184)　後半 18.7%(91)   ← 安定
重・不良  全体 1〜2枠 13.5%(111)　後半 10.1%(99)                    ← 弱い
```

**内枠の利は良馬場寄りで、渋ると薄れる。**
この開催は5日とも渋りだったので、出にくい条件だった。
ただし5.1%(59頭)は 重・不良の13.5% すら下回っていて、そのぶんは運の幅。

大井は逆で、**渋ると外が強くなる**（重・不良で7〜8枠13.7% 対 1〜2枠7.3%）。

## 初出走・転入初戦は、やはり強い

5日合計64頭。

```
4角 1〜3番手  39.1%（2026年の測定値 32.0%）
3着内        46.9%（測定値 30.1%）
```

**5日通しても大きく上振れ。** 隊列に入れないと全部ずれる、という判断は正しかった。

## 次にやること

```
1. 枠は馬場で分ける。良・稍重の内枠（川崎15.3%）と、渋ったときは別扱い
2. 初出走馬を人気から隊列に入れる（1〜3番人気0.18 / 4〜5番人気0.36 / 6番人気以降0.64）
3. 「前に1頭」に限る（前に0頭は6.9%でいちばん悪い）
4. 1番手を当てにいく。この開催では73.3%で、2番手以下とは別物だった
```
