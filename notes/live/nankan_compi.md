# 南関版コンピ指数（市場コンピ）エンジン

日刊コンピ指数（出走馬を序列点数化→1位指数・指数合計で堅い/荒れを判定）の思想を、
南関の**単勝オッズ**から自作したもの。日刊コンピが新聞予想順位ベースなのに対し、
本エンジンは**市場（単勝オッズ）→控除補正した真の勝率**ベース＝"市場コンピ"。

## コード
`scripts/ana/nankan_compi.py`
```
python3 scripts/ana/nankan_compi.py <rid>     # 例 2026111003110724
```
- オッズ取得＝`{BASE}/chihou/odds/1/{rid}`（`odds5 {sortValue: x}` に単勝）。cookie＝kb.conf。
- API: `compi(rid)` → `(horses[], race{})`。`horses`は指数降順の`{ub,name,odds,p,idx}`。

## 計算式
```
p_i  = (1/odds_i) / Σ(1/odds_j)                 # 単勝→テラ銭(控除)を除いた真の勝率
idx_i = clamp(40, 90, round(40 + 150 * p_i))    # 勝率33.3%で90到達、25%→77、15%→62、5%→48
```
- 40〜90帯＝日刊コンピの見た目レンジを再現。1位指数はレースごとに変動（断然人気→高、混戦→低）。

## レース指標と荒れ判定（勝率空間で判定）
指数は90飽和するので、堅い/荒れは**勝率(p)**で判定する。
- `p1`=1位勝率, `gap_p`=p1−p2, `top3share`=p1+p2+p3。
- 断然（軸1点）      : p1≥33% かつ gap_p≥12%
- 堅い（軸中心）      : p1≥25% かつ gap_p≥7%
- 2強対決（馬連本線）  : p1≥22% かつ p2≥18% かつ gap_p<6%
- 上位拮抗（3頭BOX）  : top3share≥58% かつ p1<28%
- 混戦・波乱含み（手広）: p1<17%
- 中間（軸+相手厚め）  : それ以外
- `arate_score` 大きいほど荒れ（並べ替え用）。

## 検証（2026-07-24 大井・成立10R／確定オッズ）
- **1着＝コンピ1位 5/10** ／ **馬連が上位4頭内で完結 8/10**。
- 実結果がコンピ順を裏付けた好例＝11R：1着⑪(コ1位)→2着⑩(コ2位)。
  （※この日の我々の11R◎②はコンピ15位の人気薄＝市場コンピなら回避できた）
- 拾えなかったのは 1R(1着コ5位)・8R(1着コ6位)＝**市場も見抜けぬ本質的な穴**。
