# 3着内率で測っていたのが間違いだった

2026-11-14

## 何が起きたか

この4日間、条件の良し悪しを全部「3着内率」で判定していた。
そして次のように結論していた。

```
人気薄 × ふだん前   3着内13.0%（層10.2%）  +2.8pt
→ 「ほとんど差がない。使えない」
```

南関の生データ（楽天の競走成績）にオッズが入っていないので、
回収率を出せないまま3着内率だけで進めていた。

ただオッズは要らなかった。**外れた馬の払戻は0なので、3着内に来た馬の
払戻だけあれば回収率は正確に出る。**それは払戻ページに載っている。

1日分の全レースが1ページなので、1,778鞍でも151回の取得で足りた。
（`scripts/ana/fetch_nankan_payout.py`）

```

  1〜3番人気            5,236頭   単 77.8%   複 81.9%
  6番人気以降（人気薄）    11,157頭   単 65.4%   複 66.7%
  10番人気以降           4,511頭   単 54.2%   複 63.7%
```

人気薄の単勝回収は65.4%。ここが比べる相手。

```

  ふだん後ろ             387頭   単 47.4%
```

**163 / 64 / 47 と一方向に並ぶ。**

### 訂正：前半後半の割り方が間違っていた（2026-11-14 追記）

当初ここに「前半201.0 / 後半158.4 で両方で残る」と書いた。**これは誤り。**

データ全体の中央（20260805）で割ったが、`hp`（ふだんの位置）は過去3走が要るので、
データの頭のほうには材料がない。

```
hp が出せる割合   〜3月 0.1%  ／ 4〜6月 23.7%  ／ 7〜9月 51.0%  ／ 10月〜 65.2%
```

その結果、前半が30頭しか残らず、**単201.0%は1着1頭・払戻6,030円の1頭だけ**
だった（6030÷30=201.0）。検定が成立していない。

**履歴を使う条件は、該当馬それ自身の日付の中央で割る。**層の中央ではなく。
割り直した値:

```
川崎 人気薄 × ふだん前   251頭 単163.5%   同期間の層 74.5%（前半76.0 / 後半73.2）
  前半  80頭 単150.8%   1着5頭   最大1頭抜き 75.4%  ← 層と同値まで落ちる
  後半 171頭 単169.5%   1着7頭   最大1頭抜き 95.7%
  偽薬5回  48.8 / 67.8 / 74.1 / 99.0 / 132.2%
```

163.5%は偽薬の上限132.2%の外にあり、両期とも層を上回る。
ただし**251頭で1着12頭しかなく、各期から大穴1頭を抜くと前半は層と同値**。
**2026-11-14 追記：この条件は取り下げた。**A班の公平な集中度検定（該当の上位n頭を
該当と層の両方から抜く）で、上位3頭を抜くと該当64.6% / 層65.4% と層を下回る。
251頭で1着12頭、うち3頭で出来ていた。偽薬は通った（該当馬を除いて200回引いて
95%点118.4%、該当以上は0/200）が、集中度で落ちる。D班のデータ拡充後に測り直す。

## 疑っておくこと

### 偽薬の幅が広い

同じ鞍から人気薄を1頭ずつ無作為に取る偽薬を5回。

```
111.1% / 83.9% / 116.6% / 86.3% / 90.1%
```

単勝回収は分散が大きく、偽薬でも117%まで出る。163.5%はこの外だが、
**最大の1頭（12,620円）を抜くと113.2%で、偽薬の幅の中に入る。**

251頭で1着は12頭しかいない。この12頭のうち1頭に全体が乗っている。
断定はできない。

### 人気帯をそろえても残る

```
6〜7番人気     93頭   単129.2%   同人気の層 59.2%   +70.1pt
8〜10番人気   115頭   単142.6%   同人気の層110.1%   +32.6pt
11番人気以降   43頭   単293.5%   同人気の層 35.2%  +258.2pt
```

11番人気以降の+258ptは大穴1頭ぶん。信用できるのは上の2行。

### 偽薬の平均が層より高い

偽薬5回の平均は97.6%で、川崎人気薄の層74.2%より高い。
「ふだん前の人気薄がいる鞍」そのものが、人気薄の払戻が大きい鞍
かもしれない。**馬を選べているのではなく、鞍を選べているだけ**の
可能性が残る。

## 動画解析はどうするか
