# E班 — 年齢は人気薄の単勝回収に効くのか（船橋の精査）

測定スクリプト `scripts/ana/body_age.py`（`python3 -I` で動く。標準ライブラリのみ、
ネットワークに出ない）。土台は `scripts/ana/nankan_body.py` の
`load_body / BODY / MIN_N` を読むだけ。`nankan_body.jsonl` も読むだけ。

データ 20,011頭。層は払戻が取れて完走6頭以上の 19,889頭、人気薄（6番人気以降）11,157頭。

**結論を先に。船橋の年齢は採れません。**

船橋 × 人気薄 × 6〜7歳（624頭・1着17頭・単93.1%）は、前後半・偽薬200回・
人気帯そろえ・馬1頭単位の3頭抜きまでは通ります。落ちるのは次の3つです。

1. **日単位の集中度**。1着17頭は**11日**にしか乗っていない。
   上位3日を該当と層の両方から抜くと **該当45.8% / 層45.7%（差+0.1pt）**。
   CLAUDE.md の川崎の例（3頭抜きで層と同値）と同じ形が、日で起きている
2. **1歳刻みに割ると6歳も7歳も単独では残らない**。
   船橋6歳は前半が層以下（片側だけ）、船橋7歳は後半の1着が2頭で検定不成立。
   624頭を1つにまとめたときだけ関門を通る
3. **場をまたいで一貫しない**。川崎は−0.7pt（公平な3頭抜きで−33.5pt）で効かず、
   浦和は層そのものが3頭で出来ている。浦和を除く3場では公平な3頭抜きで**+4.3pt**

# 0. 使った道具と決めごと

CLAUDE.md「検証の作法」と、今日確立した3項目をそのまま当てた。

| 道具 | 中身 |
|---|---|
| 前半／後半 | **該当馬それ自身の開催日の中央**で割る。層も同じ境目で割り、同じ期間・同じ場に絞る。各期の1着の頭数を必ず出し、片方が3頭未満なら「検定として成立していない」と書く |
| 公平な集中度 | 該当の上位1,2,3,5頭を**該当と層の両方から**抜く。分母は抜く前のまま |
| 偽薬 | **200回**。同じ鞍の人気薄から**該当馬を除いて**引く。5%点／中央／95%点／最大／該当以上の回数。鞍の構成をそろえた**厳密な期待値**も並べる |
| 人気帯そろえ | 6〜7 / 8〜10 / 11番人気以降 |
| 浦和 | 必ず上位3頭を抜いた値を併記 |

**足した道具が2つある。**どちらも先に決めた5つの測定すべてに同じように当てており、
選んだ帯だけに当てる後付けの道具にはしていない。

- **日単位の集中度**。該当の単払戻を開催日で合計し、上位1,2,3日を**該当と層の両方から**
  抜く。馬1頭ずつ抜くやり方では、同じ日に2頭来た分が見えない。
  船橋の6〜7歳は 20260806 に2頭（6,370円・4,160円）、20260123 に3頭が重なっている
- **月ごとの内訳**。前後半の2分割は境目の置き方で見え方が変わるので、
  ①の4帯すべてで月ごとに並べた

## 偽薬が成立しない帯がある（先に書いておく）

**2〜3歳と4〜5歳では「該当馬を除いて引く」偽薬がほとんど引けない。**
南関には2歳戦・3歳戦があり、その鞍の人気薄は全員が該当馬になるので、
該当を除くと引ける馬が残らない。

```

人気薄が全部2〜3歳の鞍      南関4場   514鞍(29.3%)　船橋 140鞍(29.5%)
6〜7歳の人気薄がいる鞍      南関4場   985鞍(56.2%)　船橋 270鞍(57.0%)

  船橋 4〜5歳 1,376頭 → 655頭（47.6%）　← 半分しか引けない
  船橋 6〜7歳   624頭 → 560頭（89.7%）

```

**2〜3歳帯の「偽薬の幅 0.0〜233.8%」は幅ではなく、引けなかったことの表示。**

## ②の判定

**南関4場では「6〜7歳」というまとめ方は後付けではない。**
6歳（90.8%・1着26頭）と7歳（95.9%・1着23頭）は、どちらも単独で
前後半の両期で層を超え、偽薬200回の上に出る。片方だけが効いているのではない。
2〜5歳と8歳以降が低く、6歳と7歳だけが並んで高いので、
帯の切り方を結果から選んだ形にはなっていない。

**船橋では、6歳も7歳も単独では残らない。**
船橋6歳は前半が層以下、船橋7歳は後半の1着が2頭で検定不成立。
船橋の93.1%は**624頭を1つにまとめたときだけ関門を通る数字**で、
1歳刻みに割ると両方とも落ちる。1着が8頭と9頭しかないので、
割った側が落ちるのは当然ではあるが、**「船橋の6〜7歳」は年齢2歳分をまとめて
初めて成立する形**だということ以上は言えない。

4場6歳・4場7歳が公平な3頭抜きで+3.3pt・+3.8pt（層とほぼ同じ）まで縮むのも、
同じことの裏返し。まとめた2,170頭（1着49頭）では3頭抜きで+14.6pt残る。
**同じ現象が、くくり方によって「残る」と「消える」に分かれる。**

# 4. ③ 年齢は何の言い換えか

## まず hn が使えないことを確かめた

```
hn はこのデータ（2026年）の中の走数。最小0　中央2　最大11　10走以上 21頭
```

`hn` は土台がデータ内で数えた走数なので、**1年分しかない。**
6〜7歳の中央値2走、それ以外も中央値2走で、**年齢で差がつかない。**
「長く使われている馬」という言い換え候補は、**この土台では検証できない。**
キャリアの長さを入れるには2025年以前のデータが要る。これは測れなかったこととして残す。

## ⑤の判定

**2つの偽薬は、この条件では同じ引き方になる。届くかどうかを別に測れない。**

理由。該当が**年齢だけ**で決まっているので、「同じ鞍の人気薄のうち該当馬」と
「同じ鞍の人気薄のうち6〜7歳」が同じ集合になる。
除く馬が一致するので、引ける馬も一致する（スクリプトで集合の一致を確認した）。
**2つを分けて測れるのは、条件が年齢と何かの掛け算になっているときだけ。**
たとえば「6〜7歳×牝」なら、該当を除く版は同じ鞍の6〜7歳牡を引けるが、
6〜7歳以外から引く版は引けない。年齢単独の条件では原理的に同じ。

**そこで「鞍の性質を見ているのか」は、別のやり方で測った。**
該当がいる鞍の人気薄すべてを層にする（鞍の選び方そのものを層に写す）。

# 7. 最終判定

## 船橋の年齢は採れない

通した関門と結果。

| 関門 | 船橋 6〜7歳（624頭 1着17頭 単93.1%） | 通ったか |
|---|---|---|
| 母数20頭以上 | 624頭 | ○ |
| 両期で1着3頭以上 | 前半1着10頭 / 後半1着7頭 | ○ |
| 自分の中央で割って両期とも層超え | 99.5%（層62.7）／84.7%（層49.3） | ○ |
| 偽薬200回（該当馬を除く） | 0/200回。厳密な期待値との差 +48.9pt | ○ |
| 鞍の性質ではないか | 同じ鞍の6〜7歳以外は47.0%、該当93.1% | ○ |
| 人気帯をそろえる | 3帯すべて層超え（+79.5 / +12.7 / +26.7） | ○（11番人気以降は1着2頭） |
| 公平な集中度（馬1頭ずつ） | 3頭抜き +9.1pt、**5頭抜き −2.1pt** | △ |
| **公平な集中度（日単位）** | **上位3日抜き 該当45.8% / 層45.7%** | **×** |
| **1歳刻みに割る** | **船橋6歳は前半が層以下、船橋7歳は後半1着2頭で検定不成立** | **×** |
| **場をまたいで一貫するか** | **川崎 −0.7pt（3頭抜き−33.5pt）、浦和は層が3頭製** | **×** |

**採れない。**理由を並べる。

1. **1着17頭が11日にしか乗っていない。上位3日を両方から抜くと層と同値（+0.1pt）。**
   CLAUDE.md の川崎「3頭を抜くと層と区別がつかない」と同じ形。
   馬1頭ずつ抜く数え方では3頭抜きで+9.1pt残るが、
   8/6に2頭・1/23に3頭が重なっているので、日で数えると3日で消える
2. **条件の切り方を少しずらすと消える。**1歳刻みに割れば6歳も7歳も落ち、
   場を川崎に替えれば効かず、浦和は層そのものが3頭で出来ている。
   前向きに使う物差しは「6〜7歳」「船橋」という2つのくくり方を
   両方そのまま使い続けることが前提になる
3. **4場のうち船橋と浦和だけ。**4場あれば偶然でも1〜2場は出る
   （C班の浦和×軽い側と同じ論法）。浦和を除く3場では公平な3頭抜きで+4.3pt
4. **③で、船橋の中身は1600m以上では消えていた**（261頭 1着6頭 −2.7pt）。
   624頭のうち41.8%がそこ。「船橋の6〜7歳」として宣言すると、
   効いていない半分を含んだまま買うことになる
5. **絶対値の指標である。**年齢は鞍のメンバーによって変わらない。
   CLAUDE.md「絶対値はもう値段に入っている」に正面から反する形で、
   南関の払戻率72%を20pt以上超える説明がついていない

## 南関4場まとめ（2,170頭）については「採れないとは言えない」

公平を期して書く。船橋1場に絞ると落ちるが、**4場まとめの2,170頭は
日単位の3日抜きでも+14.1pt（該当76.2% / 層62.1%）残り、馬単位の5頭抜きでも+8.2pt、
6歳と7歳が別々に前後半を通り、偽薬200回で0/200。**
ここで落ちる関門は今回の測定にはなかった。

ただし
- 浦和を除くと+27.5pt → +16.1pt、公平な3頭抜きで**+4.3pt**まで縮む
- 浦和の層そのものが3頭製で、そのうち1頭（マイカグラ6歳15,800円）が該当に入っている
- 8〜10番人気の+52.3ptは浦和由来（浦和+198.3pt、他3場は+12〜+20pt）
- 1歳刻みにすると6歳・7歳それぞれ公平な3頭抜きで+3.3pt・+3.8pt（層とほぼ同じ）

**E班としての判定：船橋は採れない。4場まとめは落ちなかったが、
浦和を抜くと公平な3頭抜きで+4.3ptまで縮むので、採るなら
notes/calls/ に宣言して前向きに測るしかない。後ろ向きの数字としては
「4場まとめでだけ残り、どう割っても残らない」という形で終わっている。**
