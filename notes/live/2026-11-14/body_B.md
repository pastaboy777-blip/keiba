## 結論

**何も残らなかった。**

母数20頭以上のセルが67通り。そのうち**前後半のどちらも20頭以上かつ1着3頭以上で、

同期間の層を単勝回収で30pt以上超えたセルは8通りあったが、検定として成立するのは
⑧川崎 hp<=1/3 −4〜+4kg の1通りだけで、それも偽薬の幅の中だった。

馬体重の増減も休養日数も、人気の中に入っている情報の言い換えになっている。

割り方を直したついでに hp<=1/3 自体も測り直したところ、**両期で同期間の層を

前半317頭（1着4頭）45.0% が層62.5% を下回る）。増減を足す相手の土台が

## 【訂正】前後半の割り方を直した

### 何が間違っていたか

最初は `load_body()` が返す `mid`（データ全体の開催日の中央 `20260805`）で
前後半を割っていた。これは誤り。`wt_diff` も `rest` も `hp` も前走の履歴が要る
ので、データの頭のほうには材料がない。全体の中央で割ると前半がほぼ空になり、
残ったわずかな頭数に1頭の大穴が乗って「前半◯◯%」という数字が出る。

実際に起きていたこと（川崎 人気薄 × hp<=1/3 の251頭）：

| 割り方 | 前半 | 後半 |
|---|---|---|
| 全体の中央 `20260805` | **30頭 単201.0%　1着1頭（6,030円）** | 221頭 単158.4%　1着11頭 |
| **該当馬自身の中央 `20260908`** | **80頭 単150.8%　1着5頭** | **171頭 単169.5%　1着7頭** |

前半の201.0% は 6,030÷30 で、**1着1頭だけの数字**だった。検定が成立していない。

### どう直したか

```python
def cut(S):
    d = sorted({x['ymd'] for x in S})
    m = d[len(d)//2]
    return [x for x in S if x['ymd'] < m], [x for x in S if x['ymd'] >= m]
```

1. 該当馬それ自身の開催日の中央で割る（層の中央ではない）。
2. 比べる層も**該当馬と同じ期間**（該当馬の最初の開催日〜最後の開催日）に絞り、
   同じ分割日で割る。全期間の層と比べると、前走の履歴が溜まっていない1〜3月ぶんが
   層にだけ入って、構成の差を見ることになる。
3. 各期の**1着の頭数と払戻の内訳**を必ず出す。
4. **片方の期の1着が3頭未満なら、その割り方は検定として成立していない**と明記する。

スクリプトは `cut()` 版が正であることを確認するため、上の251頭で
「前半80頭150.8%・1着5頭／後半171頭169.5%・1着7頭」を検算として出力している。

以下、各測定で **【訂正】該当馬の中央で割った場合** と
**【参考・誤】全体の中央で割った場合** を並べる。古い数字は消していない。

## ⑧の判定：増減は hp に足せるのか

**足せると言えない。**ただし**訂正で理由が変わった。**

訂正前は「前半が19頭しかなく測れない」と書いたが、該当馬自身の中央で割ると
**川崎 hp<=1/3 −4〜+4kg は前半49頭（1着4頭）220.0%／後半95頭（1着3頭）223.7%
で、検定として成立し、両期とも同期間の層（150.8%／169.5%）を超える。**
測れていなかったのではなく、**測れたうえで偽薬に負けた**というのが正しい。

1. **偽薬の幅の中。**川崎 × 人気薄 × hp<=1/3 の251頭から「−4〜+4kg」の144頭に
   絞ると 163.5% → 222.4% に上がる。偽薬5回は 178.3〜231.8% で、
   **222.4% はその中。**251頭から144頭を無作為に引いても同じだけ上がる。
   1鞍1頭の鞍が146鞍中82鞍あるので、偽薬は該当とほとんど同じ馬を引く
   （5回のうち3回が同じ数字になった）。これは増減が独立な情報を足していない
   ことの現れでもある。
2. **南関4場でまとめても同じ。**hp<=1/3 −4〜+4kg は568頭 単90.5%（層81.2%）で
   両期を通るが偽薬79.3〜102.9%の中。最大1頭（12,620円）を抜くと層との差は
   +0.5pt になる。
3. **良い帯が場ごとに違う。**川崎は −4〜+4kg（222.4%）、大井は −9〜−5kg
   （233.9%）、南関4場でまとめると −9〜−5kg（126.2%）と +10kg以上（142.8%）の
   両端。4場で同じ帯が出てこない。しかも大井・南関の数字は前半の1着が0頭で、
   後半だけの数字だった。
4. **「増えた馬は hp でも安い」も確かめられない。**南関4場 hp<=1/3 で
   増(>=+5kg) は215頭 単44.8%（層81.1%）だが、前半81頭で1着1頭。
   場ごとに見ても4場すべてが前半1着0〜1頭で、**どの場も検定として成立しない。**
5. **⑧は「同じものを測り直している」可能性が高い。**川崎 hp<=1/3 の251頭は
   全頭で wt_diff が出る。hp と wt_diff はどちらも「データ内に走りが積まれている
   馬」を選ぶ条件で、増減の帯で切ることは251頭を間引くことに近い。
6. **足す相手の土台も、川崎以外では両期を通らない。**正しく割って測り直すと、
   hp<=1/3 が両期で同期間の層を超えるのは**川崎だけ**。南関4場でまとめると
   947頭 単81.1%（層65.3%）だが前半317頭（1着4頭）45.0% は層62.5% を下回り、
   大井・船橋・浦和は前半の1着が0〜1頭で検定として成立しない。
   増減を足す前に、土台そのものが川崎に限られている。

川崎 × 人気薄 × hp<=1/3 の163.5% は、増減で切らずにそのまま使うのが妥当。
増減で絞ると数字は上がるが、無作為に絞っても同じだけ上がる。
