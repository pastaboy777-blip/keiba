# 0. 割り方の訂正（作業中に差し込みを受けた）

**前半／後半を `ev()` の `mid`（データ全体の中央 '20260805'）で割るのをやめ、
該当馬それ自身の日付の中央で割り直した。層も同じ境目で割る。**

```python
def cut(S):
    d = sorted({x['ymd'] for x in S})
    m = d[len(d)//2]
    return [x for x in S if x['ymd'] < m], [x for x in S if x['ymd'] >= m], m
```

なぜ要るか。`wt_diff` は前走がデータ内にある馬だけに付くので、全体の中央で割ると
前半が薄くなる。⑧2〜3歳の5帯は、全体の中央だと前半134〜203頭しかなく、

馬場も時期で固まるので（重・不良は前半757頭・後半2,353頭）、①②⑦も全体の中央で
割ると**馬場の構成差を見ることになる**。

**あわせて各期の1着の頭数と払戻の内訳を出し、片方の期で1着が3頭未満なら
「この割り方は検定として成立していない」と書くことにした。**

古い数字は消していない。表の「旧」列が全体の中央で割った版、「新」列が自分の
中央で割った版。

## 偽薬の期待値を厳密に出した（足したもの）

`placebo()` は「各鞍で該当が何頭いたか」だけを守って無作為に取る。その期待値は
閉じた式で出る。

```
E[単回収] = Σ_鞍 m_鞍 × (その鞍の母集団の平均単払戻) ÷ Σ_鞍 m_鞍
```

層（鞍を数えず全頭を平均したもの）との差は**鞍の構成の差**を含む。この期待値と
比べると構成の差が落ちる。56枠すべてで出した（選んだ枠だけに当てる後付けの
道具ではない）。

要るとわかったのは、②良・稍重×500kg〜 で層との差が **−4.1pt** なのに偽薬5回の幅
（35.4〜53.3%）より**上**に出たから。厳密な期待値は56.5%で該当は57.3%＝**+0.9pt**。
層で読むと負、5回の幅で読むと正、厳密値では横ばい。

5回の幅の校正も確かめた：**偽薬を置いた29回のうち26回で、厳密な期待値が5回の幅の
中に入った**（本編25回＋点検4回）。幅の作り方は壊れていないが、「幅の外」は片側
おおむね1/6のゆるい関門でしかない。

# 6. ②の判定 — 「重馬場は重い馬」は値段に入っているのか

**「重い馬が渋り馬場で得をしている」形跡は回収に出ていない。**
入っていて得になるなら層を上回るはずだが、上回っていない。

| 重・不良 × 人気薄 | 頭数 | 1着 | 単 | 厳密な期待値 | 差 | 新・前半 | 新・後半 |
|---|---|---|---|---|---|---|---|
| 〜449kg | 913 | 21頭 | 94.8% | 68.8% | +26.1 | 1着7頭 単64.1(層87.7) | 1着14頭 単125.1(層65.1) |
| 450〜499kg | 1,626 | 30頭 | 78.0% | 83.1% | −5.1 | 1着19頭 単118.9(層87.7) | 1着11頭 単42.3(層65.1) |
| 500kg〜 | 571 | 9頭 | 37.7% | 65.0% | −27.3 | 1着3頭 単29.8(層84.3) | 1着6頭 単43.8(層67.4) |

向きは**逆**（軽いほど回収が高い）。同じ向きは相対の物差しでも出る
（①重・不良：軽い側 +16.1 / 中 −9.1 / 重い側 −11.2）。

**ただし断定はしない。**

- 重・不良×500kg〜 の37.7%は偽薬5回の幅（30.3〜80.4%）の**中**
- **571頭で1着が9頭しかない。**前半はちょうど3頭で関門のぎりぎり
- 最大1頭(5,580円)を抜くと28.0%まで落ちる。少ない当たりに乗っている印
- 重・不良×〜449kg の94.8%も片側だけ（前半64.1%／層87.7%）

良・稍重では3帯とも期待値ちょうど（+1.9 / −1.3 / +0.9）。
**乾いた馬場では絶対体重は何も生まない。**

測れたのは次の2つまで。

1. 「重馬場は重い馬が有利」が**値段に入って得になっている形跡はない**。
   重い側は層を超えていない。この向きは①②で一致している
2. 「逆に売れすぎている（重い馬を買うと損）」のほうは、**偽薬の幅の中で、
   かつ1着9頭なので断定しない**

**「入っていない」と「逆向きに入りすぎている」の区別は、このデータでは
つかなかった。** つけるには重・不良×500kg〜 の1着の数を増やす（期間を足す）
必要がある。

ただし⑦で分かったとおり、**渋り馬場で効いていたのは体重ではなく性**
（牡 −25.0pt / 牝 +22.3pt）。②と①の体重の向きは、渋り馬場の牝が軽い側に
寄っていることの映りかもしれない。この切り分けは3段目の掛け算になるので
（人気薄×馬場×性×体重）、母数が割れてこの報告ではやっていない。

# 7. 4場を混ぜた数字が歪んでいた例

## 例1：③1300〜1500m×軽い側1/3（落ちた）

4場を混ぜると106.8%、その距離帯の層86.5%に対して+20.3pt、厳密な期待値に対して
+21.0pt。偽薬の幅の上にも出て、自分の中央で割っても両方で層超え（1着20頭/20頭）。
ところが

- この1,575頭のうち**26%が浦和**（浦和の軽い側593頭の**69%**がこの距離帯に入る）
- **浦和の層を作る上位3頭のうち2頭がこの帯に入っている**（マイカグラ・サッシーユー。
  どちらも1400m）
- 浦和を抜くと1,166頭・76.4%。期待値との差 +21.0pt → **+6.5pt**。
  後半は56.4%で層（61.4%）以下に落ちる
- 上位3頭を抜くと 80.8% 対 層74.0%（層も同数抜き）で +20.3pt → **+6.8pt**

浦和は1,400m・1,500mが中心なので、「1300〜1500mの軽い馬」は実質
「浦和の軽い馬」になっていた。**距離の話に見えて場の話だった。**

## 例2：④大井を混ぜた層で読むと全部「層以下」に見える

大井の3帯は50.4% / 44.9% / 68.3%。4場を混ぜた人気薄の層65.4%と比べると
3帯のうち2帯が層以下。ところが大井の層は54.2%なので、重い側1/3の68.3%は
**+14.1pt**（厳密な期待値比でも+7.5pt、自分の中央で割って両方で層超え）。
混ぜた層で読むと、大井の数字はまとめて低く見える。
（偽薬の幅の中なので採らないが、見え方は反対になる。）

## 例3：浦和×軽い側1/3 の差の大きさが4通りになる

| 何と比べたか | 比べる相手 | 差 |
|---|---|---|
| 4場を混ぜた人気薄 | 65.4% | +92.4pt |
| 浦和の人気薄 | 93.3% | +64.4pt |
| 鞍の構成をそろえた厳密な期待値 | 107.1% | +50.6pt |
| 浦和の人気薄・上位3頭抜き（該当も上位3頭抜き） | 66.5% | **+22.3pt** |

混ぜた層で読むと差を**4.1倍**に見積まることになる。
浦和の軽い馬が走る鞍は、浦和の中でもすでに単107.1%が返ってくる鞍だった。
そして浦和の93.3%そのものが3頭で出来ている。

## 例4：⑥6〜7歳

4場混ぜて+28.2pt（期待値比）だが、浦和を抜くと+16.7pt。差の4割は浦和。
残ったものではあるが、4場混ぜた数字はこの形でも1.7倍に見えていた。
（上位3頭を抜いた比較では +27.5pt → +16.2pt でほぼ同じ縮み方。）
