# 動画解析の数値を、レース結果に突き合わせる仕様

獣医師による走行動画の解析（1本の映像から重心・蹄の軌跡・関節角度を数値化）を、
こちらの南関データと突き合わせるための受け入れ仕様。2026/11/14 時点。

映像と資料は先方のものなので、このリポジトリには入れない。数値だけを受け取る。

## 1. 受け取る形

1行1頭。判定しなかった項目は**空欄のまま**残す（埋めない）。

```
race_id      レースID。または 日付・場・R
umaban       馬番
section      解析区間（元動画の何秒〜何秒／レースのどのあたりか）
frames       真横らしさ0.8以上で使えたコマ数
kakikomi     かき込み度（蹄が後ろへ戻る速さ ÷ 馬の速さ）
rhythm       リズムの重なり（1完歩ずらした一致。1.0が完全）
stride       歩幅（胴の長さ比）
arc_fore     軌跡の幅・前肢（胴の長さ比）
arc_hind     軌跡の幅・後肢（胴の長さ比）
arc_flat     軌跡の扁平（横÷縦）
swing_hip    腰の振り幅（度）
swing_fore   前肢の振り幅（度）
fore_split   前肢の振り幅の内訳（前へ◯度・後ろへ◯度）
reach        後肢の踏み込み（臀端0〜肩端1）
rider_shift  人の重心のずれ（胴の長さ比・前が＋）
```

**総合点は要らない。** 9項目中5項目しか採点できないとき、平均は採点できた項目に
偏る（先方も「平均は高めに出ている可能性」と明記している）。項目ごとに持つ。

**測れなかった馬も行として残す。** 真横で大きく映るのは内めを通った馬・先頭付近に
偏るので、測れた馬だけ集めると「よく走った馬だから測れた」が混ざる。
測れなかった馬の着順と比べて差がなければ、偏りはないと言える。

## 2. こちらが足すもの

race_id と umaban があれば、1頭につき全部返せる。

```
4角の生の順位 ／ 4角の正規化位置（0が先頭・1.00が最後方）
内外（括弧の中で内から何番目か。0が最内）
枠 ／ 人気 ／ 単勝オッズ ／ 着順 ／ 上がり3F ／ 馬体重 ／ 騎手 ／ 調教師
その鞍のハロンタイム（200mごと）／ 馬場 ／ 前半3F・後半3F
同じ馬の過去走と次走（南関4場ぶん）
```

## 3. 先に決めておく区分（あとで動かさない）

- 速度に依存しない指標：kakikomi、rhythm、arc_flat、fore_split の比
- 速度に依存する指標：stride、arc_fore/hind、swing_*（同じ速度の馬としか比べない）

根拠：毎秒の完歩数はレースで 2.36±0.12回（日本の921頭・Takahashi 2025）。
ばらつきが±5%しかないので `速度 ≒ 歩幅 × 2.36`。
**歩幅は速度の代理変数**であり、「歩幅が長い馬ほど着順が良い」は
「速い馬が強い」とほぼ同義。速度はすでに人気に入っている（CLAUDE.md）。
新しい情報は、速度で割った指標にしかない。

## 4. 測る順（先に書いておく。結果を見てから選ばない）

### ① 速度依存の切り分け（1頭でできる）

同じ馬の、速度の違う2区間を測る。どの指標が速度で動くかを確定する。
ここが決まらないと、何を集めるかが決まらない。

### ② 位置との関係（同一レース5〜6頭）

同じレース・同じ区間で、4角1〜3番手だった馬と6番手以降だった馬を各2〜3頭。
速度・馬場・展開・カメラ条件がそろうので、残る差は走り方だけ。

測るのは `kakikomi` と `4角の生の順位`。

狙い：こちらの未解決は「誰が4角で前に行くか」。
人気薄がふだん前に行く馬でも実際に前に行けるのは33%（人気上位は72.6%）。
位置が当たれば着順は決まる（川崎の人気薄 4角1番手73.3% / 6番手以降4.4%）。

### ③ 持ち越し（同じ馬の2走ぶん × 5組）

今走の `kakikomi` が、次走でも同じ値になるか。

```
自己相関 +0.6 以上  → 馬の性質。前日の材料になる
+0.3 前後          → 弱いが使える（位置の自己相関が +0.29 だった）
ほぼゼロ            → その日の状態。前日には使えない
```

先方の資料に「調教の最大歩幅は、その後の成績を予測しなかった研究もある」とある。
こちらの実測（ふだんの位置 → 次走の位置 が +0.29）と同じ構造。
**走行中の指標が次走を予測しないのは、ありうる**。ここで落ちたら落ちたと書く。

### ④ 馬場との噛み合い（20頭 × 2走から）

先方のカードで唯一、賭けに直結する行がこれ。

> 合う馬場の目安：ダート・力の要る馬場（確かさ低め・経験則で未検証）

```
かき込み度が高い馬は、良馬場より重・不良で相対的に良くなるか
```

**同じ馬の良馬場と渋った馬場を比べる**ので、馬の能力は打ち消される。
残るのは条件適性だけ。市場は馬の総合力に値段をつけるが、
条件ごとの出入りまでは織り込みきれない。ここが唯一、人気に入っていない可能性がある。

1走ずつ100頭より、**2走ずつ50頭のほうが価値が高い**。

## 5. 判定の作法（CLAUDE.md）

```
人気の帯をそろえて上振れptを出す（生の率は人気でほとんど説明がつく）
偽薬を置く（馬番の偶奇など、関係ないもので同じ割り方をして差が出ないか）
日付で前半・後半に割って、両方で残るかを見る
母数が足りないときは「判定しない」。無理に点を付けない
落ちたら落ちたと書く。消さない
```

必要な頭数の目安（人気薄の3着内率が11%前後なので）

```
向きが見える   20頭
判定できる     100頭
条件にする     300頭
```

## 6. いま返せるもの

メイショウアキカゼの race_id（または 日付・場・R）をもらえれば、
その鞍の時計・ハロンタイム・4角順位・人気・着順・馬体重・騎手と、
**過去走と次走すべて**を返す。

先方の「まだ言えないこと」のうち

```
能力の高さ（実際の時計・成績が必要）   → こちらが持っている
回転の速さ・時計（スロー映像で不明）   → ハロンタイムで 1/13.5 と 0.43秒の仮定を外せる
回転型か中間型か（比べる馬が必要）     → 同一レース複数頭で埋まる
```

上2つは、情報をもらった時点で埋まる。
