## A. 使える較正値（仮定なしでデータから出たもの・再利用可）

### 1順位 ≒ 0.13〜0.16秒 ≒ 約1馬身
最終コーナーの順位差と、体感テン（走破−上がり3F＝実測）の差を回帰して較正。

```
800m 0.112 / 900m 0.126 / 1000m 0.124 / 1200m 0.162
1400m 0.142 / 1500m 0.133 / 1600m 0.141 / 1800m 0.146 / 2000m 0.148
```

位置と時間を相互変換するときは常にこれを使う。

### ペースの代償（道具変数法・南関16,717走）
流れに1秒速く走らされると、上がりを **0.24秒** 失う。

```
〜1000m  -0.03（無し）   1200m +0.12
1400-1500m +0.19（最大） 1600m〜 +0.03（無し）
```

**素直に回帰すると +0.007 でゼロに見える。**調子の良し悪しが交絡するため。
他馬が作った流れを道具にして初めて出る。**潰れるのは中距離だけ。**

### 枠は内外を決めるが、前後を決めない
```
枠 → 4角の【内外】位置   +0.579
枠 → 4角の【前後】位置   -0.005
枠 → 1角の【前後】位置   +0.01（1200m）
```
「内枠だから前に行ける」は南関では成立しない。**ground loss の話としてのみ有効。**

### 時計と上がりの分散分解（場×距離を揃えた後）
```
走破タイム（SD 1.93秒）  クラス26.0 / 馬場11.6 / 位置12.0 / 騎手2.1 / 馬21.6 / 不明26.7
上がり3F  （SD 1.51秒）  クラス 9.1 / 馬場 8.0 / 位置 1.0 / 騎手3.2 / 馬34.3 / 不明44.5
```
- 条件側は 時計51.7% / 上がり21.3%。**上がりのほうが窓が澄んでいる**
- **馬の成分は 時計0.90秒 / 上がり0.88秒 でほぼ同じ**（同じ馬なので当然）
- **不明が両方 SD 1.00秒 ≒ 6〜7馬身。馬の成分より大きい**
  → 1走だけで能力は読めない。繰り返しでしか削れない

### 位置と上がりの関係は距離で符号が反転する（同じ馬の中で見ても同じ）

## B. 弱いが生きている条件

### 1. 上位人気の「消し」信号 ── 今日いちばん大きい差
```
1-2番人気 × 指数上位   3着内 71.7%
1-2番人気 × 指数下位   3着内 45.2%   （帯全体 62.9%）
```
**17.7ポイント差。**ただし単勝で測っても価値が出ない（消しは買えない）。
**券種を変えて測っていない。ここが最大の未着手。**

### 2. 負け方の仕分け（上がりの落ち幅）
同じくらい負けた馬（今走BT差 −8〜−2）の中で：
```
上がりも落ちた     n 43  次走3着内 11.6%
上がりは平常どおり   n 95  次走3着内 21.1%
```
**約2倍。**「展開で負けた」と「力で負けた」を分けられる。

### 3. コーナーの脚（穴帯限定）
7月南関262R。穴帯（6番人気以下）で上位→下位が単調に落ちる。
```
16.4% / 91%  →  9.8% / 84%  →  9.0% / 66%
プラセボ（後ろから行く順）は 12.0 → 7.8 → 12.8 でぐちゃぐちゃ
```
**4場すべてで再現。**ただし単独選択は川崎ででたらめと同じ、船橋は n=27 で判定不能。

### 4. 濃い脚×着外 × 前づけ型が少ないメンバー
```
濃い脚×着外（単体）           3着内 22.6%（対照25.7%を下回る）
 ＋前づけ型が5%以下のメンバー    3着内 30.9%
 ＋前づけ型が25%以上のメンバー   3着内 21.0%
```
**単調。**ただし単回収は 85% → 85% で動かない。**織り込み済み。**

### 5. 騎手の内外の癖 × 枠
走行位置の癖は**馬ではなく騎手の性質**（前後半の相関 騎手0.613 / 馬0.129 / プラセボ-0.04）。
その騎手自身の3着内率からの差：
```
              内枠      中枠      外枠
内を突く騎手    +1.4pt   +0.4pt   -1.6pt
外を回す騎手    -2.8pt   -0.3pt   +2.7pt
```
**差5.5ポイント。**浦和・川崎で効き、**大井では効かない**。

## D. いちばん重要な学び

### ① 回収率がプラスに見えたら、必ず最大配当の1頭を抜いて見る
今日3回とも1頭で説明できた。
```
きついラップ組  304.7% → 1頭除くと 7.1%
中山×6-9番人気 117.6% → 1頭除くと 66.5%
```

### ② 着順・人気・払戻で切ったあとの数字は、その日の性質ではなく結果の言い換え
（`jiko_time_hi_tekkai.md` と同じ穴。今日も「前残り度合い」で一度落ちた）

### ③ 仕組みが実在することと、値段が間違っていることは別
今日見つけた仕組みはほぼ全部、的中率では効いて回収率では効かなかった。
**市場は仕組みを知っている。**

### ④ 馬の個体差は出てこない。条件の構造は出てくる
```
出なかった … ペース適性 c=0.087 ／ 走行位置の癖 r=0.129 ／ 父の残差 r=0.003〜0.111
出た     … 騎手の癖 r=0.613 ／ 位置↔時間の換算 ／ 代償の距離依存 ／ 枠の内外
```
**南関のデータで安定して測れるのは「条件側」であって「馬側」ではない。**

## E. 未着手（ここが残っている）

**消しの信号を、消しが値段になる券種で測っていない。**

1-2番人気で17.7ポイントの差が出ているのに、単勝回収でしか測っていない。
単勝で本命を消しても得られるのは「買わなかった」だけでゼロ。
三連単のフォーメーションから1頭外せば、**消したこと自体が配当になる。**

**今日いちばん大きい差が、いちばん価値の出ない券種で測られたまま放置されている。**
