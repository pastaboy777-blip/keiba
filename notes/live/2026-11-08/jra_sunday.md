# 11/8(日) 中央 ── 推奨3点の根拠

土曜(11/7)の3場の結果と、過去のレース実績を突き合わせたもの。

|---|---|---|---|

## ① AR共和国杯（東京芝2500m 18頭）⑯キングズパレス・⑰キングスコール

**2頭は同じレースで東京芝2500mを走っている。**
```
2026/05/31 東京 芝2500m 14頭
  ⑰キングスコール 14番 7人気 5着 通過1-1-1-1 上り34.2（逃げ）
  ⑯キングズパレス 12番 11人気 7着 通過3-3-3-3 上り34.3（3番手）
```
年に数回しか使わない距離で、2頭とも前目から人気薄で掲示板近く。

**⑰は東京の長めで勝っている。**
```
2026/05/16 東京 芝2400m 15頭 7番 5人気 1着 通過9-8-9-9 上り33.3
```
父ドゥラメンテ×母父Frankel。斤量55.0は18頭中で軽いほう
（トップは②ビザンチンドリーム59.5）。前でも後ろでも走れる。

**8枠そのものの実績。** 18頭立てになった4年すべてで3着内。
```
2020 1着(18番)  2022 2着(17番)・3着(16番)  2023 2着(17番)  2025 2着(18番)
```
2022年は16番・17番で2・3着独占。今年の⑯⑰と同じ馬番。

弱いところ。土曜の東京芝に外枠有利は出ていない（外1/3 -2.5pt・
内1/3 -3.2pt、93頭）。8枠の根拠はこのレース固有の過去で、当日の馬場
ではない。⑯は5か月半の休み明け。

## ② 東京12R（芝1400m 12頭）⑫ウォーターエアリー（佐々木）

父サートゥルナーリア×母父マンハッタンカフェ。近5走の形が一貫。
```
10/17 京都1400 10人10着 通過17-15    上り33.9
07/26 中京1600 12人11着 通過13-11-12 上り33.9
06/13 阪神1600  6人 9着 通過10-11    上り33.6
05/24 京都1400  5人 4着 通過14-13    上り33.4
04/25 京都1400  8人11着 通過15-15    上り33.3
```
毎回ほぼ最後方から上がり33.3〜33.9。着順が悪いのは前に行けないから。
土曜の東京芝は勝ち馬の上がり順位が中央値2位で差しが届いていた。
父サートゥルナーリアは土曜の東京芝で2勝（10R・12R）。
8枠の外は、もともと外を回る馬なので減点が小さい。

根拠としてはいちばん薄い。馬場の読みは土曜7鞍ぶんの観察でしかない。

## ③ 福島12R（芝1200m 16頭）⑪ロンドンアームズ（菊沢）

父グレーターロンドン×母父ウォーエンブレム。この舞台で人気薄で走っている。
```
07/04 福島1200 16頭 16番 8人気 3着 上り34.4（大外から）
04/12 福島1200 16頭 12番 9人気 5着 上り33.6
07/18 福島1200 15頭  5番 2人気 7着
```
人気を背負うと走らず、人気がないときに来る形。
土曜の福島は3着内の52%が6番人気以降。菊沢騎手自身も9番人気1着・
7番人気3着を取っている。父グレーターロンドンは土曜の東京芝3Rでも
11番人気3着を出した。

## 筋の通り方

いちばん強いのは⑰キングスコール。独立した根拠が4つ重なる
（東京2400m勝ち／同舞台2500m5着／軽斤量／8枠の過去実績）。
いちばん薄いのは⑫。馬場の読みが土曜1日・7鞍しかない。

3つとも「人気がないこと」が前提。人気になったら根拠は消える。
