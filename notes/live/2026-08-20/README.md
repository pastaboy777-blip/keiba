## この日から適用した修正ルール

8/18の結果から立てた仮説を、8/19の結果が否定した。修正内容は以下。

| | 8/18時点の解釈（誤り） | 8/19を経た修正版 |
|---|---|---|
| ハナ主張が多いレース | 前が潰れる → **後方を狙う** | **配当が荒れる → その競り合いを制せる前の馬を狙う** |
| ハナ主張が少ないレース | 前が楽 → 前を狙う | 前が楽 → 前を狙う（変更なし） |

つまり **ハナ主張の頭数は「位置取りの正解」ではなく「配当のボラティリティ」を示す指標**。
どちらの場合も狙うのは4角3番手以内を取れる馬で、多頭数のハナ争いは荒れ幅だけを大きくする。

根拠（8/19 川崎の勝ち馬の4角位置）:

```
2, 5, 1, 3, 1, 1, 1, 2, 1, 2, 1, 1   ← 1番手7勝・3番手以内10勝
```

- ハナ主張8頭の7R … 4角1番手の馬が勝利
- ハナ主張7頭の6R … 4角1番手の馬が勝利（単7,840円）

「ハナ主張が多い＝前が潰れる」なら、この2レースは後方が来ていなければならなかった。来なかった。

### 選定の順序（8/18の失敗からの学び）

**「数えたもの」（エッジ数）より「測ったもの」（399・上がりの実数）を優先する。**
エッジ数はタグの個数でしかなく、同じ1個でも重みが違う。399と上がり実数は連対圏の中身そのもの。

### 継続している方針

- **足切りしない** — 4角位置による◎の機械的な除外は行わない（8/18に3R⑥3着・5R④1着で証明済み）
- **当日の人気・オッズをカードに書かない** — 過去走の人気は可
- ◎ = 人気を被らない馬／○ = 中身が確かな馬（○が人気側になるのは許容）
- 締め文言は「この条件が向いている」のみ。強調語・断定語は使わない
