# JRA（中央）から南関への引き継ぎ（2026-11-15）

中央の展開・隊列の道具を作ったセッション（ブランチ `claude/wizardly-sagan-xprlvq`）から、
南関（大井・川崎・船橋・浦和）を扱うセッションへの申し送り。

- 中央の数字は、ユーザーの指示で 2023-11〜2026-11 の約1万鞍を研究したときのもの。
  **南関で同じ数字を測りに行くのは、ユーザーが指示したときだけ**（CLAUDE.md 最優先ルール。§4）。
- ここに書いた中央の数字は「南関でも同じ向きかもしれない」という見当であって、南関の事実ではない。
- 出典は `notes/live/` のノート名で書く。

## 1. 南関でもそのまま効きそうな考え方

### 1-1 当日の傾向で後半の狙いを決める（隊列は前日、狙いは当日）

出典: `jra_zu_hyougen.md`、`jra_yosou_3nen.md`、`20261115_jra_bunseki.md`

- 2026-11-14 にユーザーと決めた形: **隊列（並び）は前日に作って変えない。狙い（赤丸・白丸）は当日に決める。**
- 前半の鞍が終わったら、**今日ここまでの3着内が4角でどこにいたか**（前1/3の割合・組の外の割合）を数え、
  ふだんと比べて ±15pt 以上なら「前◎／差◎」、外が 67%以上／33%以下なら「外◎／内◎」の札を後半の鞍に出す
  （`jra_today.py` → `jra_tenkai_zu.py` の `_today_line`）。
- 中央3年の検証では、「差しの日」は 前×内 の3着内が鞍平均の 1.30倍 → 1.14倍 に落ちる（前×外は落ちない）。
  **内の日／外の日の差は1pt前後で、数字としては使えなかった**（`jra_yosou_3nen.md`）。
  → 前後の傾向はかなり当てになる、内外は「その日に目に見えて偏ったときだけ」くらいで扱う。
- 11/15 の実例: 福島は芝ダとも3着内の **87%が4角前1/3**。中団予想の馬が4角までに押し上げて来て、赤丸 0/5（福島11R）。
  前決着の日だと分かった時点で、後半は「前へ出られる馬」を丸に入れるべきだった。
- 南関側の既存の道具と同じ発想: `scripts/ana/nichi.py`（その日1日を終わった鞍だけから読む）、
  CLAUDE.md「1R〜3Rが終わった時点で、その日の決着傾向を見て後半を組み直す」。
  **南関では nichi.py が本体。中央の `_today_line` は「4角前1/3の割合・組の外の割合を、ふだんと比べて札にする」部分だけ参考になる。**

### 1-2 終い候補（同じ距離帯の上がり順位で、1鞍2頭まで）

出典: `jra_course_pos.md` §3・§3-2

- 物差しは **ag = 過去5走のうち、同じ芝ダ・距離±400m の走の「その鞍の上がり順位」の中央値**。
  距離帯の違う上がりは持ち込まない（CLAUDE.md ルール2・買う馬リストの物差し1と同じ）。
- 中央・芝16頭以上で予想4角が後ろ1/3の馬（3,106頭）:

| 物差し | 3着内 |
|---|---|
| ag ≤ 3 | **21%** |
| ag 3超〜6 | 11% |
| ag 6超 | 6% |
| 芝1800m以上の上がりだけで見た rk 1〜3位（距離帯をまたぐ） | 18%、ただし1600m以下では 15% vs 11% と差が小さい |

- ag≤3 の後ろの馬は「予想4角が中団の馬の平均（22%）」と同じくらい来る。**位置だけで切らない。**
- 札が1鞍6頭付いた（11/15 京都11R）ので **ag の小さい順（同値は距離帯の走数の多い順）に1鞍2頭まで**にした。
  3着内 21% → 23% を保ったまま 1.36頭/鞍 → 1.10頭/鞍（`jra_tenkai_zu.mark_kouho`）。
- 南関への注意:
  - 中央で効いたのは **芝・16頭以上**。南関はダートで12〜16頭。CLAUDE.md ルール7のとおり
    **多頭数（12頭超）の1400m以下では上がり順位を使わない**、使ってよいかはその日の `nichi.py` の判定に従う。
  - 上がり順位は「差した馬」を拾い「前で粘った馬」を落とす（ルール7）。終い候補は丸の候補を増やす札であって、前の馬を下げる札ではない。

### 1-3 押上候補（前で決まりやすいコースで gain ≥ 0.20）

出典: `jra_course_pos.md` §2

- gain = 過去走の（1角の相対位置 − 4角の相対位置）の中央値。＋が前へ出る。
- 予想 gain ≥ 0.20 の馬は、実際に1角→4角で頭数の 6〜12% ぶん前へ出ていた（それ以外はほぼ0）。予想として当たっている。
- 3着内への効き（同じ予想4角の組の中で、gain≥0.20 とそれ以外の差）:

| コースの前残り | 予想4角 前 | 中 | 後 |
|---|---|---|---|
| 強（4角前1/3の3着内率 ≥0.40） | +15.8pt | +8.7pt | +12.4pt |
| 中 | +13.7pt | +11.2pt | +2.7pt |
| 弱（東京芝・新潟芝など） | −0.2pt | +1.9pt | +7.3pt |

  上がり実績（ag）をそろえても、前残りの強い場で +8〜9pt 残る。
  **効くのは「上がりの実績はふつう〜悪いが、位置を上げてくる馬」**（ag≤3 の馬では逆に出た）。
- 中央の前残り上位はローカルのダート（函館54%・札幌50%・小倉45%・福島44%）。
  **南関ダートは中央の小回りダートより前が強いはずなので、押上候補は南関でいちばん有望な材料。**
  CLAUDE.md の物差し3（gain を点数に入れる）、10/20 浦和で穴の主役がこの形だったこととも合う。
- 押上候補は「予想4角を1段前に置いた馬」として扱う（後&gain 23% ≒ 中 20%、中&gain 29% ≒ 前 33%）。
- 前残りの弱いコースでは gain を加点に使わない。南関でどの場・距離が「強／弱」かは、南関のデータで表を作るまで分からない（§2）。

### 1-4 時計の基準は「同じ開催の前の日の、同じ馬場・距離の実際の時計」

出典: `20261114_jra_kensho.md`、`jra_kenkyu_01.md`、`jra_tenkai_zu.py` の `--base-day` `--base-baba`

- 11/14 福島芝1200: 「1:10.3」を基準にしていたが、それは稍重の日の時計。良に戻ると1勝クラスは 1:09.1。
  **馬場は発走前に取り直し、基準もその馬場の時計に替える**（CLAUDE.md ルール3「馬体重は発走30分前に取り直す」と同じ考え方）。
- 当日の前の鞍の勝ちタイムのずれ（馬場の速さ）は、6割足すと後半の鞍の時計の誤差が 1.30 → 1.13秒、メインで 1.66 → 1.49秒。
  **時計（馬場の速さ）は次の鞍に引き継がれる。ペースの形（前後半差のずれ）は引き継がれない**（2割足しても3区分の当たりは変わらない）。
- 南関の既存: `scripts/ana/baba_today.py` が「同じ馬の過去走と比べる」物差しを持っている
  （`toki.json` の全クラス中央値と比べるとクラス差に引っぱられる、11/9 川崎の教訓）。中央の `--base-day` と同じ向きの考え方。

### 1-5 ペースは「そのコースにしては」で見る

出典: `jra_pace_teigi.md`、`note_munehiro_gakushu.md`

- 3着内の馬が4角で前1/3にいた割合（中央約1万鞍）:

| 決め方 | S | M | H | S−H |
|---|---|---|---|---|
| 前後半差を全体で3等分 | 67.3% | 69.1% | 69.0% | −1.7pt（分かれない） |
| **コース平均と比べた前後半差** | 74.6% | 68.5% | 62.4% | **+12.2pt** |
| コース平均と比べたテンだけ | 63.1% | 69.1% | 73.3% | −10.2pt（向きが逆） |

- 全体の3等分は **コースを当てているだけ**（短距離ダートはいつもH）。決着の形と結びつくのは「このコースにしては遅い／速い」。
- テンだけ速い鞍は、前に行った馬自体が強い（前が残る）。テンの速さで「差し有利」と決めない。
- ただし「このコースにしては」のペースを前もって当てるのは難しい（的中 41.6%、当てずっぽう 33%）。効いた材料は
  直線の向かい風・当日の前の鞍のずれ・前に行く3頭が過去に作ったペース。**確度が低いときは形を決めつけない。**
- 南関の `scripts/ana/tenkai.py`・`zu.py`（ペースごとに狙う帯を変える）でペースを区分するときは、場×距離の平均からのずれで区分する。

### 1-6 1日の結果で仕組みを変えない。変えるなら過去で確かめてから

出典: `jra_pace_baba.md`、`jra_blood_baba.md`、`jra_wet_kenshou.md`、`jra_hana_hikaku.md`

1日の振り返りで出た「直すこと」を、ユーザーの指示で3年分に当てたら、どれも **その日だけ** だった例:

| 11/15 に思ったこと | 3年で見たら | 扱い |
|---|---|---|
| 渋った芝はペース予想を1段スロー寄りに | 芝重はむしろ予想より前半が **速い** 側に外れる（−0.2〜−0.3秒）。日によって向きが割れる | 入れない |
| 京都の重い芝は「ロベルト系」 | ロベルト系は良のほうが高い。同じ馬どうしでも渋って良くならない（渋り−良 −4.0pt） | 札を出さない |
| 渋った馬場は「重で◯勝」「重なら外・前」で狙いを動かす | 力だけで選ぶ 53.0% > 馬場の得手を足す 50.9% > 決着の傾きも足す 44.7%（稍重） | 動かさない |
| ハナは専用モデルに替える | 1頭目では +1〜2pt しか差がない（上位3頭なら +4〜6pt） | 図は変えない |

- 南関での使い方: **1日の分析で出た「明日から直すこと」は、その日のノートに書くまでにとどめる。**
  仕組み（card.py・shirushi.py の重み）を変えるかどうかはユーザーが決める。確かめるのもユーザーが指示したときだけ。
- 逆に、当日の中で形が出たら（前半の鞍で前決着がそろった等）、その日の後半に使うのはよい（1-1）。

### 1-7 展開図の描き方

出典: `jra_zu_hyougen.md`、`jra_tenkai_zu.py`（`STYLE="kawa"`／`simple`）

- 元は **川崎の図**（`scripts/ana/zu.py`）。中央はこれと同じ形に寄せた。南関は元に戻すだけ。
- 4角の盤面1枚。**横＝前後（前が進行方向）、縦＝内外（上がラチ側）**。名前がぶつからない間隔で段に振る。
- **向きはスタンドから見た向き**。最初のコーナーあたりで馬が走る向きに合わせる（ユーザー指摘 11/14「位置も向きも逆」）。
  - スタートが正面側 … 左回りは右が前、右回りは左が前。スタートが向こう正面 … その逆。
  - 南関: 大井は右回り（内回り・外回り）、川崎・船橋・浦和は左回り。**コースごとに確かめて、ユーザーが見て決めた向きを優先**する表（中央の `FRONT_OVERRIDE`）を持つ。
  - 盤面の上に「← 左が前（スタンドから見た向き）」と書く。左が前なら馬の絵も矢印もゴールの線も左。
- **赤丸＝狙い、白丸＝相手候補**（`--circle`、`--circle2`）。当日に付ける。
- 馬は騎手が乗ったイラスト（`scripts/ana/uma/uma1..8.png`、`scripts/ana/uma_img.py` の `horse()`）。
  帽子・勝負服・ゼッケンは枠の色（1白 2黒 3赤 4青 5黄 6緑 7橙 8桃）、ゼッケンに馬番。PIL が無ければシルエット。
- 馬の下に 枠色の丸数字＋馬名、その下に札。札は短く: 終いN位／▲押し上げ／内に入りがち／外に出せる／終い候補／押上候補／内◎外◎前◎差◎。
- ペースバッジ S/M/H。見解は1段落（先頭争い → その後ろ → 押し上げる馬 → 終い一番手）。
- 気候の札は出さない（11/14 ユーザー「パクッてると思われちゃう」）。有料記事の文言は図に載せない（1-8 の厩舎の話も札だけ）。
- 結果の図（`jra_kekka_zu.py`）も同じ絵で、実際の通過順から起こす。予想と並べて答え合わせ。

### 1-8 その他、南関でも使えそうな小さな知見

- 通過順の括弧の中は **内から** 書かれている（2頭並び 86,921組で先に書かれた馬が内枠 81%）。`jra_kenkyu_01.md`。
  南関の `scripts/ana/corner.py` の lane もこの前提。映像と食い違う例外は手で直せるようにしておく（`--inner`）。
- 内外（4角で組の外になるか）は **ほぼ馬番で決まる**（相関 +0.42、騎手の外出し率を足して +0.43）。`jra_asa_matome.md`。
- 漏れた3着内馬は「位置は読めていたのに丸を付けなかった」型と「予想より前に出てきた」型に分かれる（`20261115_jra_bunseki.md`）。
  前者は終い候補・前の粘りを丸に残す、後者は押上候補で拾う。

### 3-2 研究用（ユーザーの指示で過去を測ったもの。南関では指示があるまで回さない）

### 3-3 南関の既存の道具との重なり

- **上がりは距離帯をまたがない**: 中央 `ag`（同じ芝ダ・距離±400m）と、南関 `shirushi.py` の edge（1400m戦なら1200〜1600m）は同じ考え方。距離帯の幅は南関の決め方（CLAUDE.md 物差し1）に従う。
- **gain**: 中央 `r["gain"]` と `shirushi.py` の gain は同じ定義（1角→4角でいくつ前へ）。中央の「前残りの強いコースでだけ効く」を足すなら、コースの表が要る（§2）。
- **位置**: 中央は「前ほど1頭あたりでは勝つ」。南関の物差し2（中団前め 0.30〜0.55 を上に）と食い違うように見えるが、
  中央でも東京芝2000・2400は3〜4番手が1-2番手より3着内率が高かった。**コースで違う**ので、南関は南関の物差しのまま。
- **展開図**: `jra_tenkai_zu.py` は `scripts/ana/zu.py` と同じ見た目で作った。新しい部分（向きの判定・赤丸白丸・騎手イラスト・候補の札・今日の傾向の札）だけ持ち帰ればよい。
- **当日の読み**: 中央 `jra_today.py` の札は、南関 `nichi.py` の判定を代わりにするものではない。nichi.py を先に回す（ルール7）。
