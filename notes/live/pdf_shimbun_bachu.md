## ① 33ラップ（3行目の先頭）── 式が確定

**前半3F − 後半3F**。レース単位の値なので、同じレースの馬は全頭同じ数字になる。

- ダ1400（7ハロン）… **2〜4ハロン目の3F − ラスト3F**。1ハロン目（スタートの加速区間）は捨てる
- ダ800（4ハロン）… 1〜3ハロン目 − 2〜4ハロン目（＝ 1ハロン目 − 4ハロン目）

浦和で検算し、8本すべて一致した。

| 紙面 | レース | ラップ |
|---|---|---|
| +0.8 | 9/22 浦和3R ダ1400 | 12.6-12.8-13.3-13.1-11.7-13.4-13.3 |
| −1.3 | 9/22 浦和2R ダ1400 | 12.7-12.5-13.0-13.1-12.5-13.5-13.9 |
| 0.0 | 9/22 浦和6R ダ800 | 12.2-10.8-12.0-12.2 |
| −0.1 | 8/7 浦和3R ダ1400 | 12.5-12.2-13.3-13.4-12.1-13.8-13.1 |
| −3.0 | 7/14 浦和3R ダ1400 | 13.5-12.5-12.6-13.0-12.0-14.4-14.7 |
| −1.0 / −1.1 | 9/25 浦和3R / 4R ダ1400 | |
| −0.7 / +0.2 | 9/24 浦和3R / 4R ダ800 | |

**作者本人の線引きは1秒。** 差が1秒以内なら瞬発戦、1秒以上開いていれば持久戦。
馬ごとにこの2種類の成績を別々に集計するのが理論の骨子
（本人のXの例：イラーレは瞬発戦【2340】・持久戦【0125】）。

## ② ペース指数（3行目の2番目）── 符号と係数まで

`S2.6` `M-0.5` `H-2.7` の形。**S＝スロー（正）／M＝ミドル／H＝ハイ（負）**。

- 符号は **プラスがスロー、マイナスがハイ**
- 同じ日・同じ距離・同じ馬場で比べると **1秒あたり約9〜10ポイント**
  （9/22 浦和2R 前半51.3秒 → M−0.5 ／ 3R 前半51.8秒 → S4.3）
- ただし基準はコース・距離・馬場だけでなく **クラスと時期でも動く**。
  7/14の2歳新馬は前半51.6秒で H−2.7（ハイ判定）になっており、
  9/22の古馬1400（51.3秒）より遅いのにハイ側に出る
- 一般的な西田式の定義では「スピード指数を前半部分だけで計算したもの」。
  正負の向きが逆の流儀もあるので注意

**基準タイムの表が非公開なので、式そのものは再現できない。**

## ③ タイム指数（4行目の先頭）── 1秒 ≒ 10ポイント

その馬がその走りで得た能力値。**馬ごとの値**（同じレースでも着差で変わる）。

9/22 浦和6R ダ800（不良）の例

| 着 | 着差 | 紙面のタイム指数 |
|---|---|---|
| 4着 | 0.9 | 38 |
| 12着 | 2.5〜2.8 | 21〜22 |

差1.6〜1.9秒で16〜17ポイント動くので、**1秒あたり約10ポイント**。
凡例の「102」は、今回のレース欄に出る各馬の能力値。

## ④ レース総評（4行目の残り）

`超低 / 低 / やハ / 水準 / 2強 / 3強 / 2着大差 / 3〜5小差 / 2頭大逃 / 前残り / 捲り / 内前め`
のような語の組み合わせ。末尾の `速0.5(速1)` `遅1(速1)` は33ラップを段階に落としたもの。
**線引きの基準は不明。**
