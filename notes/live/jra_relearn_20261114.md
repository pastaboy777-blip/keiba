# 障害の混入を直したあとの学び直し(2026-11-14)

`data/jra/races.jsonl` の障害 297鞍を surface「芝」→「障」に直した(控え `races.jsonl.bak_20261114`)。
芝/ダで鞍を絞っている学習スクリプトは、これまで障害を「芝」の鞍・過去走として取り込んでいたので学び直した。
前のモデルの控えは `models/_bak_20261114/`(コミットしない)。

「前」の数字は、各スクリプトを直す前のデータ(.bak)で今のスクリプトのまま回し直したもの
(コミット済みのモデルは少し前のデータで学習していて、ログが残っていないため)。
検証区間の境はデータが変わると数日ずれるので、スクリプトの検証の数字は厳密には同じ鞍ではない。

## 注意: 位置モデルは今のスクリプトの既定のままだと壊れる
`jra_position_model2.py` の STEPS には、あとから研究で足した段(流れ別の位置・出遅れ率・相手との比較)が入っていて、
保存されるモデルの特徴もそこまで増える。展開図(`jra_tenkai_zu.apply_position_model`)はそれらを計算しないので 0 で埋まり、
既定のまま学び直すと kensho の 1角相関 +0.48→+0.43・4角 +0.46→+0.27、hikaku の pos1 1頭目 30.3%→22.6% に落ちた
(直す前のデータで学び直しても同じく落ちる。障害の修正とは関係ない)。
コミット済みのモデルと同じ「+同じ芝ダ・近い距離の位置(long_x_sim)」までの 8段で学習した:
`P.STEPS = P.STEPS[:8]` にしてから `main()` を呼ぶ(スクリプト本体は変えていない)。
