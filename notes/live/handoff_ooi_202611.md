## 4. 印の付け方

### 軸は「4角で前めを取れるか」で決める

**4角の相対位置 0.2以内**が軸（`ninki.py` の `◎`／`MAE = 0.20`）。
終いは**同じ位置の馬を並べるときの差**に使います。

★ **終いの順位で軸を決めない**（ルール35）。
11/13 川崎は 11R・12R とも**相手に置いた2頭が1-2着**で、
終い一番手の馬を軸にして**先手を取る馬を相手に落としたのが裏目**でした。
後3Fが水準より1.5秒以上遅い流れでは、**終いより先手のほうが上**です。

★ **拮抗していると思ったら、表裏を取るか頭を2頭にする**（ルール8・ルール35）。
馬単で1着を固定するのが早い、というのは3か月で3回同じ外し方をしている所です。

### 位置 → 3着内率（そのまま写し）

| 4角の相対位置 | 11/12 川崎・重・136頭（ルール33） | 11/13 川崎・122頭（ルール36） |
|---|---|---|
| **0.0〜0.2** | **59.0%**（39頭中23頭） | **56.8%**（44頭中25頭） |
| 0.2〜0.4 | 20.6% | 26.7% |
| 0.4〜0.6 | 8.3% | 13.0% |
| 0.6以降 | 11.1% | **25頭中0頭** |

月〜水も 56.2% / 26.0% / 10.8% / 5.4% で、**5日とも同じ形**（ルール33・36）。
**0.6以降はほぼ来ません。**

### 印の実績（ルール36）

- 11/12 … 〇 **26頭中12頭が3着内＝46.2%**（勝ち馬が出た鞍 6/12）
- 11/13 … ◎（4角0.2以内＋終い3位以内）**5頭中2頭＝40.0%**

当たった理由はペース想定ではなく、**「4角で前めを取れて、終いも使える馬」を
選んでいたから**です（ルール33）。選び方はこれだけでよい、とユーザーと確認済みです。

### そのほか

- **隊列は1コーナーで組む**（ルール23）。4角の中央値で組むと
  「前に行って下がる馬」が中団に描かれます。**「誰が行くか」は1角、
  「そこから下がるか」は gain（1角−4角）で重ねる。**
- gain は**動く量**です。**どこから動くかは pos が持っています**（ルール9）。
  gain 単独で位置を推測しないこと。
- **過去走のない馬を図から消さない**（ルール22）。鞍の中央に置いて「過去走なし」と書く。
  11/10 7Rの⑦（12人気）が3着で三連単949,920円でした。
- 位置（pos）の精度はここが限界です ── **直近重みづけ 0.2200。枠・騎手・距離・頭数を
  足しても 0.2188 でほぼ動きません**（`tenkai_zu.py` 冒頭）。**位置は「だいたい」。**

## 7. `ninki.py` の使い方（当日のオッズが入ってから）

```bash
python3 ninki.py $W/ooi1116.json --ven 大井 --R 1-12 [--baba 重]
```

**鞍ごとに1頭1行の表を出すだけ**です。買い目も点も出しません。

```
馬番 / 枠 / 馬名 / 騎手 / 人気 / 単勝 / 1角(pos) / gain / 4角 / 内度 / 終い順位 / 印
```

- 並びは **1角(pos) の小さい順**（＝隊列の前から）。pos が出ない馬は最後。
- `◎` は **4角の相対が0.2以内**の馬（ルール33・36）。
- 数字はぜんぶ `tenkai_zu.row_of()` のものをそのまま出しています。ここでは計算しません。
- `arrange()` は通していません（あれは pos が近い2頭を内度で入れ替えるので表とずれます）。
  **拮抗2頭の前後は図（`tenkai_zu.py`）のほうが正しい。**
- **前日は人気・単勝が空**なので「オッズ未発表」と出ます。表の形だけ下見に使えます。

鞍ごとのまとめが2行出ます。

- **ズレ** … ◎（4角0.2以内）なのに**人気5番手以下**の馬。こちらが前めと読んで市場が買っていない
- **逆** … **1〜3人気**なのに4角0.4より後ろの馬。市場が買っていてこちらの読みでは後ろ
