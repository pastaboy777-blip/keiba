# 大井 展開穴の攻略（TCK・1周1200m大回り）── 2026-07 実測

## 結論：大井は「差し天国」。穴の核心＝人気薄×最速上がり
回09+10（6/8-12・6/29-7/3）全118レース実測（大井は結果ページの通過順が"****"マスク
→ 上がり3Fを差し脚の代理指標に使用）。

- **勝ち馬の92%（108/118）が上がり3F順位3位以内**（最速1位=60・2〜3位=48）。
  前で粘って（上がり下位で）勝ったのは2頭=2%のみ。**末脚がすべて**。
- 人気薄(6番人気以下)ベースライン3着内率 = 11%（72/677）。
- **人気薄 × そのレース上がり1位（最速差し）= 3着内55%（16/29）＝5.19倍**。← 大井の穴の核心。
- 人気薄 × 前残り（上がり下位）= 1%（0.08倍）。**前々の人気薄は捨てる**。
- 小型≤440 × 人気薄 = 12%（1.09倍）。**浦和の"小型"テンプレは大井では無効**。

## 展開予想からの穴・運用ルール
1. **狙いは「人気薄でも末脚力の高い差し馬」**。事前は近走の相対上がり順位で末脚力をスコア化（scripts/ana/agari_power.py）。
2. **展開でハイペース想定（逃げ・先行が多い組）ほど前が崩れ、差しの人気薄が突き抜ける**。ペースが速くなる組を選んで末脚型の人気薄を厚く。
3. **前残りの人気薄・小型は狙わない**（大井では効かない）。トラックが変われば穴テンプレも変わる＝浦和の感覚を持ち込まない。
4. 実測でagari_power.pyは末脚1位→1着・末脚2位→2着を的中（回10最終日11R）。末脚力の上位＝好走の芯。

## 【重要訂正】事前バックテスト ── 末脚実績だけでは穴は獲れない
上の「人気薄×最速上がり55%(5.2倍)」は **結果論(そのレースで実際に最速上がりだった馬を事後に見た数字)**。
事前に使えるかを回10全60レースで全頭カバー・対象レース除外でバックテストした結果:
- 人気薄(6+)ベースライン3着内率 = **9.7%**(33/339)
- 事前★末脚穴フラグ(人気薄×過去の相対上がりが高い) = **10.0%(2/20) = 1.03倍 = エッジなし**

### 確定した知見(月曜に適用)
1. **「末脚実績のある人気薄」を穴として買っても素の人気薄と同じ**(市場が末脚力を人気に織り込み済み)。この買い方はしない。
2. 大井が差し天国(勝ち馬92%が上がり3位内)なのは事実だが、**事前に"どの人気薄が今日差してくるか"は過去実績だけでは当たらない**。
3. 大井は展開穴の事前化に必要なデータ(通過=マスク、談話=脚質記述が薄く一部馬のみ)が乏しく、浦和のような機械的ペース想定ができない。
4. 次に試す価値がある方向(未検証): ①クラス替わり×絶対上がり時計 ②前受け人気馬のフェード(前は勝率2%) ③本紙予想/展開コメント等の別ソースからのペース信号。
※ scripts/ana/backtest_ooi2.py で再現可能(全頭カバー版)。

## 方向1・2・3 バックテスト結論（回09+10・上がり代理＝アーカイブ）
アーカイブ(通過マスク)で上がり代理を使う限り、事前の穴信号はどれもエッジなし:
- 方向1 前受け人気馬フェード → **否定**。前受けタイプの人気馬(power<=0.40)は3着内71.4%(10/14)=1.28倍。フェードどころか複勝で堅い。大井は「差しが勝つが前も複勝に残る」。
- 方向2 絶対上がり時計(人気薄×best<=37.5) → 7.7%(2/26)=0.79倍。ベースライン以下。
- 方向3 別ソースのペース信号 → keibabookに事前ペース/展開ページは存在しない(死亡)。

### 運用の最終結論
- **過去アーカイブの機械バックテストでは大井の穴信号は作れない**(通過マスク+上がりは人気に織り込み済み)。
- **月曜以降はライブで通過を取得し、浦和式の展開予想(実脚質→ペース→前崩れの差し穴)を大井に適用する**のが正解。
- 差し天国は事実だが前受け人気馬は複勝で堅い→頭は差し・ヒモに前を残す三連系が向く。

## 【重大訂正】大井は「差し天国」でなく「好位・前が本線」（4-7月54R実測）
正規cookieで実通過が取れたので、回06〜10の勝ち馬の1角位置を集計（54R、結果パース成功分）：
- 勝ち脚質(1角): **好位(3-5)=48%(26)／前(≤2)=39%(21)／差し(6+)=わずか13%(7)**。
- 馬場別も一貫: 良も稍重も不良も好位・前有利、差しは少数（良でも差し2/22）。
- ペース別: **超ハイでも勝つのは好位(5)＞差し(2)、前は飛ぶ(1)**。＝前傾ハイ→"後方一気"は誤り、拾うのは【好位】。
- 人気: 勝ち"前"=平均2.0(堅い・人気サイド)／好位2.9・差し2.7(中穴)。

### 訂正の芯
- 従来の「大井＝差し天国(勝ち馬92%が上がり3位内)」は**"末脚が要る"の意味であって"後方から差す"ではない**。
  実際は【好位・前で運びつつ最速級の上がりを使う馬】が勝つ＝**好位差しが本線、純粋な追い込みは13%の例外**。
- 展開エンジンの「ハイ→差し(後方)」読みは的中48%＝過大。**「ハイ→好位差し」に全面補正**。
  後方一気は"逃げ4頭以上の超前傾＋内で溜めた馬"に限定。
- 推奨は好位優先(1角3〜5番手)。稍重で好位差し推奨が最も効く(32%)。

### 運用（確定）
- 大井は【好位・前】を本線に。前で行ける実力馬は堅実(人気サイド)、妙味は【好位差しの中穴(2.7〜2.9人気)】。
- 前傾ハイは"垂れる前を好位で拾う"。差し本線・後方一気は基本狙わない。
- ※サンプル54R(結果パース成功分)。全300Rには未達だが傾向は強く一貫。

## 【軸・穴の精度検証】展開は"単独フィルタ"でなく"市場との食い違い"で使う（4-7月245R・パース修正版）
54R版は結果ページのハイライト行(`<tr class=...>`)を取りこぼしていた（1番人気の凡走行が落ち、命中率が水増し）。
`<tr[^>]*>`＋`class="umaban"`必須に修正し**245Rで再集計**（scripts/ana/jiku_ana.py, jiku_v2.py）。

### ① 軸ルール比較（複勝率／勝率, 245R）
- **A 市場1番人気**：複**70%**／勝43% ← 最強
- B 好位前×人気上位（展開フィルタ本命）：複61%／勝34% ← **むしろ劣化**
- C 最前avg1（一番前の馬）：複37%／勝18% ← 論外
→ **軸は素直に市場1番人気。展開で"別の馬に差し替え"は逆効果**（市場は展開を織り込み済み）。

### ② 穴ルール比較（単人気≥5狙い, 245R）
- E基準 人気薄筆頭(5.1番人気を機械買い)：複30% ＝ 5番人気の素の複勝率とほぼ同じ＝**エッジ無し**
- D 人気薄×好位前：複13%／F ペース連動人気薄：複11% ← **展開で人気薄を絞ると逆効果**
→ **展開"単独"では穴は獲れない**。市場が展開を織り込んでいるため。

### ③ ★エッジの在処＝「1番人気の展開適性」で信頼度が10pt動く（211R, jiku_v2.py）
- 本命が**好位・前(展開適)** → 複**77%**／勝51%（超ハイ83%・ミドル81%・単騎スロー77%）＝堅い軸
- 本命が**差し・後方(展開不適)** → 複**67%**／勝41%に低下。危険セル＝不適×単騎スロー(複62%)・不適×超ハイ(複43%,小n)
- ただし**本命が不適でも軸は外すな**：好位前の人気上位に乗り換えると複41%（不適でも本命自身は66%）。

### 運用（軸・穴 確定版）
1. **軸＝市場1番人気**を基準に置く（複70%）。差し替えない。
2. **本命の展開適性で信頼度をランク付け**（＝賭け強度・相手の広さを変える）：
   - 本命が【好位・前】→ ◎ 複77%。超ハイ/ミドルなら単勝も。厚く。
   - 本命が【差し・後方】→ ○ 複67%に割引。相手を広げる／勝負度を下げる。特に単騎スロー・超ハイは警戒。
3. **穴は展開単独で狙わない**。狙うなら「本命=展開不適レース」×既検証シグナル（道悪巧者1.97x／小型×人気薄1.89x）の掛け算。
※245R(回06〜10, 4/13-7/3)。①の10pt差は約1.5σで"強い傾向"、回04-05等を足せば確度が上がる（追加検証の余地）。
