## 0. 結論（何を盗むか）
指数の正体は **「走破タイム基準のスピード指数（トラックバリアント補正型）」**。
公式凡例は「距離±500m内で算出」「近5走内トップ＝オレンジ、2〜3番手＝青」としか書かず、
**係数と基準タイムは非公開**＝そこが紙の飯の種。ここを逆算で再現する。

JRAレースの指数は紙面注記どおり **ハイブリッド競馬新聞の指数を流用**。
南関（大井等）は **マキシマム自前の指数**。よって南関は独自ロジックを盗む価値が高い。

## 1. 逆算で分かった計算構造

### (a) 生タイムそのものではない＝トラックバリアント補正
同一馬で「**生タイムが速いのに指数が低い**」が普通に起きる。
- パイナップルケーキ 1200m：1:17.4 → **−8** ／ 別日1:17.9 → **−18**（0.5秒遅い方が…ではなく日が違う）
- ユリシスバタフライ 1200m：稍重 1:18.0 → **−22** ／ 良 1:18.6 → **−16**
  → **速い稍重の時計(1:18.0)の方が低指数**。＝「その日の馬場が速かった」と割り引いている。

つまり **指数 ＝ （その日の基準タイム − 走破タイム）× 係数**。
基準タイム＝当日そのコースの標準時計（＝トラックバリアント）。
→ **我々の既存ルール「当日1〜2Rの実測で馬場を測る」がそのまま基準タイム作りに使える。**

### (b) 良馬場に揃えて評価（＝我々の"稍重↔良反転"の裏付け）
稍重で出た速い時計は「馬場が速いから」と減点される。
逆に良で残った前残り時計は素直に評価。
→ **稍重の好時計を過大評価しない**という我々の補正と同じ思想。指数がそれを数値化している。

### (c) 係数感度（同日・同馬場で計測）
1200m・良で **約 5〜6pt / 秒**（＝ **0.17〜0.19秒で1pt**）。
- ユリシス良1200：1:18.6→−16、1:20.5→−26 → Δ1.9秒で10pt ＝ 5.3pt/秒
距離が延びると1秒あたりのpt価値は下がる（長距離ほど1秒が軽い）。
→ ざっくり **「0.2秒＝1pt（1200基準）」** で自前換算すれば紙とほぼ同じ序列が出る。

### (d) 代表値（馬柱2列目・左の大きい数字）
- **上段＝近2走以内の最高指数＋印**
- **下段＝近5走以内の最高指数＋印**
- 上段無印でも下段に印が入る人気薄＝**今走の条件替わり/乗り替わりで一発**の妙味（凡例明記）。

### (e) per-raceの箱（各過去走）
- 背景 **オレンジ＝その馬の過去5走内トップ値** ／ **青＝2〜3番手**。
- これで「近走で自己ベスト級を出しているか（＝上げ調子）」が一目。

## 2.5 確定版スペック（3回＋実測検証で構造が完全に割れた）
`scripts/ana/speed_index.py` に実装。
1. **指数 = k×(基準タイム − 走破タイム)、k=10 固定（距離不問）**。
2. 標準基準は**二次パー** `par_std(d)=2.02e-6·d² + 0.0667·d − 6.96`（長距離の外挿破綻を防ぐ）。
3. 馬場差は固定値だと当たらない（MAE9.7）。**その日の全馬から観測**すると当たる（MAE2.5）：
   `実測基準 = median(全馬の 走破タイム + 指数/k)` を**一箇所で1回だけ**算出し式に1回反映。**符号一貫が生命線**。
   距離正規化は係数でなく基準タイム側で吸収（kは動かさない）。
→ 「馬場差を紙面のように隠さず、その日の勝ちタイムから観測化」する設計(B)が固定モデルを数字で上回ることを実証。

## 3. 我々のワークフローへの実装（比重は上げない）

**展開予想は主役のまま。指数は"能力上限の客観確認"の補助**に留める。

1. **自前指数**：`(当日基準タイム − 走破タイム) / 0.2`（1200基準）。
   基準タイム＝当日1〜2R実測アンカー（既存の馬場実測ルールを流用）。距離補正は±200mまで直接、以遠は係数調整。
2. **人気薄の一発検出**：近5走で「上段無印・下段有印」or「10走内に今の条件で高指数」の馬＝妙味。
   → 既存 `anaback.py` の穴逆算に "過去高指数フラグ" を足せる。
3. **展開の骨格**：3走以内通過順6マス＝我々の「前/好位/差し」振り分けと同義。
   人気馬が同マスに固まったら別マスの人気薄を積極的に拾う（＝我々の"潰し合い"読みの定型化）。
4. **能力上限の担保**：軸の信頼度に「過去指数トップとの差」を±で乗せる（上限が足りない人気馬を割引）。

> 注意：指数はあくまで**過去時計の客観化**。当日の展開・馬場・位置取りが主役という原則は不変。
> 稍重の好時計を過大評価しない＝指数が既にやっている補正と、我々の補正を二重に効かせない。
