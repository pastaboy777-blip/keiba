## 独自指標は5つ

| | 名前 | 中身 |
|---|---|---|
| ① | **33ラップ** | **「残り6F〜3F」の3ハロン。「レース上がり3F」の対義。**<br>同じ距離・コースでも、瞬発力勝負か持久勝負かで問われる適性が違う<br>→ 詳細は下の「33ラップの定義」 |
| ② | ベース指数 | 馬柱4行目の `/` の左の数字（例 `102/`、`-22/`、`-7/`） |
| ③ | レース総評 | 同4行目の `/` の右（例 `ハイ.2着離.速2(速1)`） |
| ④ | タイム指数（能力値） | 馬名の下の数字（例 `102`） |
| ⑤ | 馬場期待値指数 | 馬柱の左端の印。**◎ ○ ▲ ☆ △ ×** の順。同指数の場合は重 |

- **今回と同じ距離は色付け**（距離欄に着色）

## 33ラップの定義（出典にあたって確認）

考案者は **鈴木ショータ**（元・競馬エイトのトラックマン）。本人のポストに定義がある。

> 33ラップ **−1秒未満の瞬発戦**なら【2340】 例）前半33.9−後半33.8＝**+0.1**
> **−1秒以下の持久戦**だと【0125】 例）前半33.2−後半35.0＝**−1.8**

```
33ラップ値 ＝ 33ラップ（残り6F〜3F） − 上がり3F
   −1秒より大きい → 瞬発戦（最後まで速い脚が使える決着）
   −1秒以下       → 持久戦（上がりが大きく掛かる決着）
```

**「残り6F〜3F」は区間の定義。** 1200m戦なら前半3Fとそのまま一致し、それより長い距離では
「上がり3Fの直前の3F」を指す。だから「レース上がり3Fの対義」と書かれている。

**使い方はレースの判定ではなく「馬の適性」。** 引用の【2340】【0125】は1頭の成績を
瞬発戦／持久戦に分けた着別度数。**同じ馬でも、どちらの決着かで別の馬になる。**
それを馬柱の各過去走にタグとして貼って、どちらで走ってきたかを一目で分かるようにしている。

自前で出すなら `sum(lap[-6:-3]) - sum(lap[-3:])`。

## 1走ぶんの行の読み方（4行）

```
浦和 ダ 800 重 26.9.24  2歳ドリー        ← 場・馬場種・距離・馬場状態・日付・レース名
5  (4.0)519 藤本城54  5人4番6ト          ← 着順 (着差)走破タイム 騎手 斤量 人気 馬番 頭数
-0.7  M0.5  ④⑤ 外38.9❾  395(+8)        ← ★ 33ラップ 通過順 内外+上がり3F(順位) 馬体重(増減)
0/速0.5(速1)            トゥレイク        ← ベース指数/レース総評        1着馬(自身が1着なら2着馬)
```

- 走破タイムは詰めて書く。`519` = 51.9秒（800m）、`2048` = 2:04.8（2000m）、`1362` = 1:36.2
- **33ラップの先頭文字はペース記号で、符号と一致している**
  `S`（スロー）= プラス側／`M`（ミドル）≒ 0／`H`（ハイ）= マイナス側
  実例 … `S6.7` `S3.1` `S2.4` `S1.1` `M0.5` `M0` `M-0.3` `H-1.4` `H-2.7` `H-3.2`
  ハイペースなら前半が速く上がりが掛かる＝持久戦＝マイナス、という関係がそのまま出ている
- 上がりの前の `外` `内` `中` が**4コーナーでどこを回ったか**
- 上がり3Fの後ろの丸数字が**上がり順位**（`38.9❾` = 38.9秒で9位）
- **★印の先頭の数字（`-0.7` `0.2` `-3.4` など）は未確認。** ユーザーに要確認

### ベース指数 ＝ そのレースのレベル

実例で幅が見えた。**2歳の下級条件 −29〜29／C2級 13〜52／東京ダービー(JpnI) 102**。

### レース総評の書式

```
ベース指数 / ペース . 決着 . 時計 ( 馬場差 . 内外どちらが有利か )
```

- ペース … `ハイ` `やハ`(やや ハイ) `水準` `や低` `低` `超低` `2強` `1強`
- 決着 … `差し` `外差し` `内前` `2離` `3離` `2着離` `2着大差` `3〜5小差` `5離` `2下進し` `加速ラ`
- 時計 … `速0.5` `速1` `速1.5` `速2` `速3` `遅1` `遅3` `水準`
- カッコ内 … 馬場差（`速1` `水準` など）と、`内○` `外○`（**どちらを回るのが有利だったか**）

例 `46/ハイ.差し.速0.5(水準.外○)` = レベル46・ハイペース・差し決着・時計0.5秒速い・
馬場は水準で外が有利だった。

右端の別ブロックは **能力試験**（`能試浦和 ダ 800 26.6.26 → 522`）。

左側の列は **全成績 / 道悪 / 持ち時計（同コース・同距離・同競馬場）**。

## ヘッダに【馬場予報】がある

例：`時計:水準　馬場:フ…　2日目も好天続きで良馬場。展開…`
→ **その日の時計の出方と馬場傾向を、開催前に言い切っている**。

## 自分の物差しとの関係（重要）

**33ラップ（残り6F〜3F）は、いま自分がまったく持っていない区間。**
`shirushi.py` が見ているのは

- 上がり3F差（`edge`）… 最後の3F
- 4角の位置（`prel`）・1角→4角の進出（`gain`）… 位置

で、**その間の「残り600mまでをどう走ったか」が抜けている。**

10/21 の浦和で測った「**1400m全6鞍で残り600→400mが最速、最後の1Fで1.4〜2.9秒落ちる**」は、
まさに33ラップの区間の話。あの日に前が止まらなかったのは、**33ラップで緩まずに流れて
全員が最後に失速した**からで、上がり3Fだけ見ていても説明できない。

→ **自前で33ラップを作れる。** 競馬ブックのラップは区間ごとに取れているので、
`capture.py` が保存している `lap` から「残り6F〜3Fの3ハロン合計」を出せばよい
（1400mなら第2〜4ハロン、2000mなら第5〜7ハロン）。指数化するかは別として、
**その鞍が瞬発力勝負だったか持久勝負だったかの判定には使える。**
