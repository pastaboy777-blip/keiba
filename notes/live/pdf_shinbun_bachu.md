## 1走ぶんの行の読み方（4行）

```
新潟 ダ 1200 良 10.10  1勝クラス・牝B      ← 場 馬場種 距離 馬場状態 日付 クラス
2  (0.2)1114 西村淳53  8人8番13ト          ← 着順 (着差)走破タイム 騎手 斤量 人気 馬番 頭数
-2.4  S1.3  ⑦⑤ 36.2❷  470(+15)          ← 33ラップ ペース指数 通過順 上がり3F(順位) 馬体重
速1(速1)                      マルモマリア  ← [タイム指数/]レース総評   1着馬
```

- 走破タイムは詰めて書く。`1114` = 1:11.4、`519` = 51.9秒、`2048` = 2:04.8
- **1着は黒背景の反転数字。** 競走中止は着順欄が `中止`
- 休み明けは**点線**ですぐ分かるようにしてある。過去走は**必ず4走**載る
- 上がりの前の `外` `内` `中` は4コーナーでどこを回ったか（地方の行で確認）
- 初ブリンカーは `B`、去勢初戦は `去`

## ① 指数（馬名の左）

> 鈴木ショータ独自の予想ファクターを組み合わせた指数。
> **統計的な視点で見込める回収率で表記。**

**＝ 見込み回収率。** `77` なら77%、`102` なら102%。100を超えていれば期待値プラス側。
相手選び、または指数の高い馬から本命を決める使い方。

隣に**本年序列**（`129位`）と、**各項目に対する前年複勝率**（`20% 20% 22%` の3つ並び）。
左から 全成績／ダ（or 芝）／父・母父 の複勝率で、**真ん中が左より高ければ適性あり**と判断する
（ダート替わり・芝替わりのチェックに使う）。

## ② 33ラップ

> 「残り6〜3F」−「レース上がり3F」のタイム差。オリジナル予想ファクター。
> 同じ距離やコースでも、瞬発力勝負か持久勝負かで問われる適性が違う！

**レース単位の値。同じレースを走った馬は全頭同じ数字になる。**

**★実装上の注意：公式の文言は「残り6〜3F」だが、浦和の実ラップで7本検算したところ
一致したのは `前半3F − 上がり3F`（800mは `1F目 − 4F目`）だった。** 1200m戦では
両者が一致する。実装はユーザー検算のほうに合わせる。

- **プラス = 瞬発力勝負／マイナス = 持久力勝負。** ガイドの馬の例では **0.0 を境**にしている
  （リアアメリアは 0.0以上 で好走、阪神JF −0.4・桜花賞 −3.7 で大敗。
  　アーモンドアイは有馬記念 −1.5 で9着、安田記念 ±0.0 で3着・2着）
- 本人のポストでは −1秒 を境とした例もある（瞬発戦【2340】／持久戦【0125】）
- **使い方：「平均33ラップ」と近いタイムで好走している馬を評価。特に同距離実績は重視。**
  新聞には今回の**「推定33ラップ」**も載る

## ③ ペース指数

> 一般的な競馬新聞のS→M→Hは「距離」と前後半の秒差だけで算出していて意味がない。
> **コースごとに平均ペースが違う**から。下り坂スタートの小倉芝1200はほとんど「ハイ」、
> 上り坂スタートの京都芝1200はほとんど「スロー〜ミドル」になってしまう。
> → ①コースごとに基準のペースを算出する ②H→M→S だけでなく数値でも表す

```
ペース指数 ＝ そのレースの前後半差 − そのコースの基準値
   マイナスほどハイペース／プラスほどスローペース
   −1〜+1 → M ／ −1以下 → H ／ +1以上 → S
```

基準の例：**小倉芝1200は前後半差「−2秒」を境にハイ、京都芝1200は「−1秒」を境に。**
**南関4場の基準値は非公開。** 自前で作るなら各場・距離の前後半差の中央値を取る。

**使い方**
- 同じSでも `S2.9` と `S1.4` では意味が違う。`S2.9` は「さすがにスローすぎて差し損ねた」と読む
- **ハイペース数値が大きいほど先行馬は評価できる。スローすぎたときの追い込み馬は巻き返しに警戒**

実際に読み取った値は全て ±1 の規則どおりだった
（`M-0.5` `M0` `M0.3` `M0.5` `M0.9` ／ `S1.1`〜`S9.7` ／ `H-1.4` `H-2.1` `H-2.7` `H-3.2`）。

## ④ レース総評

書式は `[タイム指数/]レベル.決着の形.時計(当日のタイム傾向)`。

### レベル ── ここが一番数字が出ている

**`超ハ → ハイ → やハ → や低 → 低 → 超低` の順。** ハイレベル戦は馬柱がオレンジ色になる。

> **「ハイ」レベルレースで1.5秒差以内に走れていた馬の次走は、単回収率93％・複回収率92％**
> **「低」レベル戦に出走していた馬の次走は、単回収率62％・複回収率66％**

→ **ハイレベル戦帰りは着順が悪くても注意。低レベル戦の好走馬は軽視。**
　 着順が悪いほど人気が落ちるので、ハイレベル戦大敗馬が最高の狙いどころになる。

### 決着の形（主なコメント）

| 表記 | 意味 |
|---|---|
| `加ラ` | **加速ラップ。実際の走破時計以上の評価が必要** |
| `ほぼ加ラ` | 11.2→11.2 のように減速していないラップ |
| `大逃` / `2頭大逃` | 大逃げした馬がいてハイペースに見えるだけ。注意 |
| `4F` `5F` | 残り4F・5Fからのロングスパート戦 |
| `巻返` / `先行勢巻返` | そのレースの先行馬が次走以降で巻き返している |
| `内前` | 上位が内と前にいた馬で決まった |
| `外差し` | 上位が外と差し馬で決まった |
| `3以下弱` | 3着以下が弱い（`2以下弱` `4以下弱` も） |
| `3以下離` | 3着以下の着差が離れていた（`2以下離` も） |

### 時計

`速0.5` `速1` `速2` `速3` `遅1` `遅3` `水準`。**カッコ内は当日のタイム傾向。**
**カッコ内の馬場表記よりも速いタイムだったレースは注目**（`水準(遅1)` や `速2(速1)` など）。

### タイム指数（`/` の左）── 馬単位

**レース単位ではなく馬単位。走破タイムに連動し、1秒 = 10ポイント。**

同一鞍（浦和ダ1400不 26.9.22・33ラップ −1.3・総評も全頭同一）の3頭で検算：

| 走破タイム | 指数 |
|---|---|
| 1:32.8 | **+12** |
| 1:34.7 | **−7** |
| 1:34.9 | **−9** |

1.9秒差 ↔ 19ポイント／0.2秒差 ↔ 2ポイント。別の2鞍でも一致
（浦和ダ800重 9/24 … 49.0→+29 / 51.9→0 ＝ 2.9秒差↔29、
　浦和ダ1400稍 9/25 … 1:36.2→−22 / 1:38.0→−40 ＝ 1.8秒差↔18）。

`指数 = (基準タイム − 走破タイム) × 10`。**基準タイムの表は未特定。**
逆算すると浦和ダ1400(不)で134.0秒、浦和ダ800(重)で51.9秒あたり。
**中央（JRA）の走には指数が付かない**（`速1(速1)` のようにハイフンか無表記）。

## 自分の物差し（shirushi.py）との関係

| | PDF新聞 | 自分 |
|---|---|---|
| 最後の3F | 上がり3F＋順位 | ✅ `edge`（同距離帯のみ） |
| 位置 | 通過順＋4角の内外 | ✅ `prel` `gain`（**内外は無し**） |
| **前後半バランス** | **33ラップ** | **❌ 無い** |
| **ペース（コース基準つき）** | **ペース指数** | **❌ 無い** |
| **レースのレベル** | **レース総評** | **❌ 無い**（着順しか見ていない） |
| **走破時計** | タイム指数 | **❌ 無い** |
| 馬場差・内外の有利 | 総評のカッコ内 | ❌ 無い |

**33ラップは `capture.py` が保存しているラップから自前で出せる**
（`sum(lap[0:3]) - sum(lap[-3:])`、800mは `lap[0]-lap[3]`）。
ただし `tsuka_data.jsonl` の7月ぶんは**ラップを保存するようコードを直す前の記録で
`lap` が入っていない**。基準値を作るには取り直しが要る。

10/21 浦和で「残り600→400が最速、最後の1Fで1.4〜2.9秒落ちる」と書いたのはこの区間の話。
**8R（33ラップ −2.7 の持久戦）で上がり4位の逃げ切りを外したのは、持久戦では上がり順位が
効かないから。** 例外ではなく、型が違っただけだった。

## この新聞の読み取りで間違えたこと（記録）

1. 33ラップの区間を「残り6F〜3F」と読んだ → 実ラップでは **前半3F − 上がり3F** が一致
2. 符号を逆に取った → **前半 − 後半**（マイナスが大きいほど持久戦）
3. レース総評の `ハイ` をハイペースと読んだ → **ハイレベル**の意味。ペースは別欄

1と2はユーザーが実ラップ7本で検算して直してくれた。
**ぼやけた写真から仕様を読むときは、必ず一次情報か実データで検算してから結論を書く。**
