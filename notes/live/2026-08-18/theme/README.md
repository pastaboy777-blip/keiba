# ズブ穴カード カラーパターン

`/tmp/.../theme.py` で 1R〜5R カードから機械生成。**中身（印・メモ）は完全に同一**で、CSSの色トークンだけ差し替えている。
別のカード（6R〜12R など）に適用する場合も、同じスクリプトの `SRC` を差し替えるだけ。

## 差し替えている色トークン（15個）
| トークン | 用途 | ブルー（現行） |
|---|---|---|
| BG | body背景 | #0a4f96 |
| G1〜G4 | カード背景のグラデーション4段 | #2a8fd8 / #1173c4 / #0a58a6 / #084b90 |
| ACC | アクセント（見出し・バッジ地・行の枠・foot枠・強調文字） | #ffd83b |
| ACCD | バッジの影 | #d9a800 |
| BTXT | バッジの文字 | #0a3f78 |
| SUB | リード文/footのサブ色 | #8fe3ff |
| FOOT | foot帯の地色 | #0b2b4d |
| MK | ◎の色・R番号 | #c92a2a |
| MK2 | ○の色 | #1b8fd0 |
| NM | 馬名の色 | #10375e |
| MEMOB | メモ内の太字 | #0a58a6 |
| SIG | 署名 | #dbeaf7 |
| BORD / MEMO / RN | メモの区切り線・本文・距離頭数 | #dfe8f0 / #3c4a58 / #5a6b7d |

## 6パターン
| # | 名前 | 印象 | ファイル |
|---|---|---|---|
| 1 | **ブルー**（現行） | 定形。清潔・データ寄り | `kawasaki_1_5_1_blue` |
| 2 | **クリムゾン×ゴールド** | 勝負・熱量。ブランド名と相性が良い | `kawasaki_1_5_2_crimson` |
| 3 | **パープル** | 高級・非日常。他と被りにくい | `kawasaki_1_5_3_purple` |
| 4 | **ターフグリーン** | 競馬場そのもの。落ち着き | `kawasaki_1_5_4_turf` |
| 5 | **ブラック×ゴールド** | 有料note向き。情報量が多くても重く見えない | `kawasaki_1_5_5_black` |
| 6 | **サンセット** | 夕方〜ナイター。目を引く | `kawasaki_1_5_6_sunset` |

## 使い分けの提案
- **開催ごとに色を固定**（大井=ブルー／川崎=グリーン／浦和=クリムゾン／船橋=パープル）→ 読者が一目で場を判別できる
- **前半カード=通常色／後半カード=濃色**で時間帯を表現
- **重賞・勝負日だけブラック×ゴールド**にして特別感を出す
