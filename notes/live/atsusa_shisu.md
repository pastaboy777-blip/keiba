# 暑さ指数（猛暑日の当日ファクター）

猛暑の日に「暑さに強い馬」を炙り出す指標。2026-07-15 浦和・全12Rで構築＆検証。

## 5つのシグナル
1. **夏(6〜9月)成績**：過去走を夏だけ抜き出した3着内率。夏に好走歴＝暑さOK。
2. **夏場の馬体重**：夏に体重が大きく減らない馬＝消耗しにくい。
3. **今回の厩舎談話**：「暑さに弱い/夏得意/暑さ苦にせず」の明記。
4. **気性（折り合い）**：入れ込む・かかる馬は暑さで消耗。リラックスできる馬＝温存。
5. **去年の夏の実戦談話＋着順**（← 一番固い実データ）。db /db/uma/{umacd}/kanzen から
   2025年6〜9月の seiseki id を拾い、各レースの danwa(/chihou/danwa/1/{rid}) でその馬のコメント取得。
   ※ danwa は保存されていない開催もある（取れる範囲で）。

- 8R（◎③1着・○⑪2着・警告①イタロ飛び）と 10R（◎④1着・⑤2着）は完璧的中。

## 運用ルール（今日の学び＝重要）
1. **800m など超短距離は暑さ指数の重みを下げる**。7R②モズリバー（夏10着16着で危険判定）が800mで1着。
   短距離は暑さで消耗する前に決着＝理論が効きにくい。**1500m以上で最も効く**。
2. **暑さ指数は"相手・ヒモ"で最も効く**。人気でない夏◯馬が各レース2〜3頭ずつ2〜3着に突入。
   軸より **ヒモ穴の精度が高い**＝馬連・三連系で活かす。
3. **実力断然◎でも飛ぶ時は飛ぶ**（11R⑦スタンリー実力70%が着外）。暑さは別要因もある。
   **暑さ指数は"消し"より"拾い"で使う**（危険判定で頭ごなしに切らない）。
4. **各レースに"去年夏無双の人気薄"が必ずいる**（7R⑦・8R④・9R⑧・10R⑦・11R⑥・12R⑥）。
   毎年夏に走る"隠れ夏巧者"を炙り出せるのが最大の価値。

## 馬場との合わせ技メモ
- 「小型有利」は前日(7/14)の**強風固有**だった可能性大。7/15(良・平常)は大型も勝利（8R③549kg・11R②540kg）。
  → 天候（風・暑さ）ごとにバイアスを切り替える。強風=中枠×小型、猛暑=暑さ指数(1500m以上・ヒモ)。
