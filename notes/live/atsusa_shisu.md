# 暑さ指数（猛暑日の当日ファクター）

猛暑の日に「暑さに強い馬」を炙り出す指標。2026-07-15 浦和・全12Rで構築＆検証。

## 5つのシグナル
1. **夏(6〜9月)成績**：過去走を夏だけ抜き出した3着内率。夏に好走歴＝暑さOK。
2. **夏場の馬体重**：夏に体重が大きく減らない馬＝消耗しにくい。
3. **今回の厩舎談話**：「暑さに弱い/夏得意/暑さ苦にせず」の明記。
4. **気性（折り合い）**：入れ込む・かかる馬は暑さで消耗。リラックスできる馬＝温存。
5. **去年の夏の実戦談話＋着順**（← 一番固い実データ）。db /db/uma/{umacd}/kanzen から
   2025年6〜9月の seiseki id を拾い、各レースの danwa(/chihou/danwa/1/{rid}) でその馬のコメント取得。
   ※ danwa は保存されていない開催もある（取れる範囲で）。

## 検証結果（2026-07-15 浦和・猛暑）
- **◎（暑さ×実力の軸）が 5/6 で3着内**（7R②・8R①・9R③・10R①・12R③着、外れ11Rのみ）。
- 8R（◎③1着・○⑪2着・警告①イタロ飛び）と 10R（◎④1着・⑤2着）は完璧的中。

## 運用ルール（今日の学び＝重要）
1. **800m など超短距離は暑さ指数の重みを下げる**。7R②モズリバー（夏10着16着で危険判定）が800mで1着。
   短距離は暑さで消耗する前に決着＝理論が効きにくい。**1500m以上で最も効く**。
2. **暑さ指数は"相手・ヒモ"で最も効く**。人気でない夏◯馬が各レース2〜3頭ずつ2〜3着に突入。
   軸より **ヒモ穴の精度が高い**＝馬連・三連系で活かす。
3. **実力断然◎でも飛ぶ時は飛ぶ**（11R⑦スタンリー実力70%が着外）。暑さは別要因もある。
   **暑さ指数は"消し"より"拾い"で使う**（危険判定で頭ごなしに切らない）。
4. **各レースに"去年夏無双の人気薄"が必ずいる**（7R⑦・8R④・9R⑧・10R⑦・11R⑥・12R⑥）。
   毎年夏に走る"隠れ夏巧者"を炙り出せるのが最大の価値。

## 馬場との合わせ技メモ
- 「小型有利」は前日(7/14)の**強風固有**だった可能性大。7/15(良・平常)は大型も勝利（8R③549kg・11R②540kg）。
  → 天候（風・暑さ）ごとにバイアスを切り替える。強風=中枠×小型、猛暑=暑さ指数(1500m以上・ヒモ)。

## 暑さ × 展開（掛け合わせ）── 2026-07-15 で検証・追加
暑さ指数＝「誰が耐えられるか」／展開＝「どう流れるか」。掛けると精度が跳ねる。

### 手順
1. **展開判定**：逃げ・先行馬の頭数。逃げ2頭以上＝ハイペース／単騎逃げ・少頭数＝スロー。
2. **暑さ指数**：各馬の耐性（既存）。
3. **掛け合わせ**（下のマトリクス）。

### マトリクス（猛暑）
| | ハイペース(逃げ多数=前崩れ) | スロー(単騎逃げ=前残り) |
|---|---|---|
| 暑さ強×差し/好位 | ◎最強（前崩れを暑さ耐性で差す） | ◯地力で3着内 |
| 暑さ強×逃げ/先行 | △前々でも消耗警戒 | ◎楽逃げ鉄板 |
| 暑さ弱×どの脚質 | ✕消し（前で暑さ負け） | ✕最後甘い |

### 核心
- **猛暑はハイペースを増幅**し前を余計に消耗させる → **「暑さに強い差し馬 × ハイペース」が最大の妙味**。
- **実力断然でも「前×ハイペース」は飛ぶ**。展開を先に読み、暑さ指数で"最後まで動けるか"を重ねる。

### 7/15 実証
- 8R：中団③・好位⑪が上位＝前崩れ。暑さ○の中団③グレッチャー1着・好位⑪2着＝的中。
- 11R：◎⑦スタンリー(実力70%・先行)が前で消耗し飛び。暑さ○の好位②・中団捲り③が1-2着。展開を見れば読めた。
- 12R：単騎④ルトンワージが楽逃げ切り（スロー前残り）。暑さ○先行⑩スピンも3着。
- 9R：3歳スローで1〜3着すべて逃げ/先行。前残り想定通り。

## クラス照合（暑さシグナルの必須フィルター）── 2026-07-16 追加
「去年夏に好走」でも、それが**今より下のクラス**なら弱い相手に勝っただけ。必ずクラスを照合する。

### 取得方法
- seiseki / syutuba ページの `<p>サラ,C2,選抜馬</p>` からクラス表記を抽出。
- 南関クラス序列（低→高）：Ｃ３ < Ｃ２ < Ｃ１ < Ｂ３ < Ｂ２ < Ｂ１ < Ａ２ < Ａ１ < オープン。

### 判定ルール
- **同クラス以上で夏好走 → ◎本物の暑さ穴**（格下げ疑惑なし）。
- **格上クラスで好走 → ⬆妙味UP**（今日は降級で相手が楽。買い増し）。
- **格下クラスでのみ好走 → ⚠割引**（クラスが下がって好走してただけ）。
- 3歳条件戦（サラ系条件・選抜など）はＣ/Ｂ表記でないため個別確認。

### 7/16 実例
- ◎本物：7R⑥パルメニデス(同Ｃ３)・8R⑨セファイドループ(同Ｃ１)・12R⑪ユイノパチョレック(同Ｃ２〜格上Ｃ１)。
- ⬆妙味UP：10R⑤マスクドサムライ＝去年夏は格上Ｂ３で3着連発→今日Ｃ１降級。暑さシグナル単体では見えなかった買い材料。
- ⚠割引：11R⑤ボディコンシャス＝去年夏無双は全て格下Ｂ３→今日Ｂ２格上げ。10R③サンスレッド＝去年夏は同Ｃ１で9着(通用せず)、好走は格下Ｃ２のみ。

### 運用
暑さシグナルの「去年夏無双の人気薄」を出したら、**必ずそのクラスを今日と照合**してから穴として採用する。

1. **"実力×先行×暑さ◯"の軸が最強**＝頭で買える。暑さシグナルは軸選びにも効く（従来は"拾い"中心だったが上方修正）。

3. **後方一気の伏兵は暑さシグナル単体では拾えない**：10R②コスタデラルス(6人・後方一気で1着)は夏成績×で圏外だった。ハイペースの前崩れ局面＝<b>展開との併用（暑さ×展開）</b>を必ずかける。
4. 穴は引き続き<b>相手（2〜3着）づけ</b>が安定。頭は"実力×先行×暑さ◯"に絞る。

## 重馬場×前傾ラップの狙い像 ── 2026-07-17 浦和で確立
### 時計比較の習慣（必須）
毎日、同距離の勝ち時計を過去数日と並べて「速い/標準/遅い」を基準化してから馬場を語る。
例：浦和ダ800m 7/13=48.0良 7/14=47.6良 7/15=46.8良 7/16=47.2良 **7/17=48.1重（今週最遅）**
→ 単発時計では「速い重」と誤読。日別比較で「時計の掛かる渋った重」と判明。

### ラップで展開を読む
2R ダ800 ラップ 12.2-10.5-12.6-12.7（前半400=22.7/後半400=25.3、後半2.6秒遅い前傾）。
F2の10.5(異常に速い)→コーナーで+2.1秒失速→ラストも戻らず＝前傾ラップの消耗戦。前で飛ばした馬が
コーナーで脚上がり総崩れ→溜めた差しが拾う。実際2Rは差し決着(1着⑧差・2着②差 上34.9)。

### 狙い像＝「飛ばさず・溜めて・垂れずに差す、パワー持続型の好位差し馬」
- 脚質：好位差し〜差し。自分から飛ばす逃げ・先行は速い区間で消耗して自滅。
- 末脚：キレより"持続"。垂れる区間(ラスト2F)をジワジワ最後まで脚を使える。
- 前走：ハイペースを後方から差した／上がり掛かる消耗戦で伸びた馬。
- パワー：遅い重＝力が要る。大型・パワー型が持続戦で上位。
- 枠：内〜中枠。消し＝前半から先頭〜番手で飛ばすスピード一本の軽い逃げ。
- 展開併用：逃げ・先行が複数＝ハイペース→この狙い像が刺さる。単騎逃げ＝スロー前残り。

### 開催レベルの確定ルール（次開催で最初から適用）
1. **馬場は毎日リセット**：前日を引きずらない。当日1〜3Rの脚質・体重・勝ち時計で「今日のキャラ」を再判定してから7R以降に入る。
2. **勝ち時計は"日内でも"詰まる＝午後は前有利へ回帰**：どの日も後半レースほど馬場が乾いて高速化（7/17の1400mは 1:29.9→1:26.5と日中3.4秒短縮、7/14は4.5秒短縮）。朝の差し傾向を午後まで延長すると外す。時計が縮み出したら「差し」を弱め「前・好位」を厚くする。
3. **1番人気は毎日きっちり4/12勝＝勝率33%で安定して強い**（地方は人気馬が強い）。平均勝ち人気≈3の中人気決着が基本。**実力上位(人気馬)を軸に、穴は相手(2〜3着づけ)で妙味**が最も期待値が高い。荒れ待ちの穴一辺倒も人気ベタ買いも非効率。
4. **1番人気の"逃げ"を機械的に消さない**：消すのは「明確に競られてハイになる」時だけ。単騎で楽なら残す（7/17は⑦ルース・⑩オーシンの逃げ1番人気が2つとも勝ち、"前崩れ"を強調しすぎて取り逃した）。
5. **小型/大型は決め打たず馬場の関数で切り替える**：軽い開幕=大型のスピード有利／時計かかる=小型の立ち回り有利／猛暑ハイ=小型の差し。※7/17の重は当初「大型・パワー持続」と読んだが実際は小型が優勢だった＝前記「重×前傾ラップ狙い像」の"大型・パワー型上位"は**渋った重に限る**。乾き始めたら小型の好位差しへ。
