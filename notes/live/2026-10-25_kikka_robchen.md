# ロブチェン ── 血統の分析まとめ（2026 菊花賞に向けて）

netkeibaの5代血統表を5代ずつ継ぎ足して**12代（4,096マス）まで完全に埋めた**うえでの分析。
計算は `scripts/ana/ped_graph.py`（祖先グラフ）と `scripts/ana/ped_calc.py`（クロス・経路・近さ）。

## 4. ハイインローは父から来ている（経路を名前で追った）

Son-in-Law への10代以内6本は**全部父側**。

```
 9代  ワールドプレミア → マンデラ → Mandellicht → Be My Guest → What a Treat
      → Tudor Minstrel → Sansonnet → Lady Juror → Son-in-Law
10代  ワールドプレミア → マンデラ → Acatenango → Aggravate → Aggressor → … → Lady Juror
10代  ワールドプレミア → マンデラ → Mandellicht → Mandelauge → Mandriale → Mariapolis → …
10代  ワールドプレミア → ディープインパクト → ウインドインハーヘア
      → Burghclere → Highclere → Highlight → Hypericum → Aloe → Son-in-Law
```

母ソングライティング側は**11代以降だけ**（Giant's Causeway→Mariah's Storm→Rahy／
Vevila→Bon Debarras→Ruritania→Graustark→Flower Bowl→Beau Pere）。

Hyperion の最浅は7代で、マンデラ→**Acatenango → Surumu**（ドイツそのもの）。

**菊花賞メンバーのハイインローは、ほぼ全頭が3つの「既製品」でできている。**
① ディープ／ブラックタイド→ウインドインハーヘア→Burghclere（サンデー系なら全馬）
② デインヒル→Razyana→His Majesty→Flower Bowl→Beau Pere（ハービンジャー等）
③ Lyphard→Goofed→Court Martial→Fair Trial→Lady Juror（ほぼ全馬）
**ロブチェンだけが4本目＝ドイツのマンデラ系を持つ。**

## 6. 全兄弟問題 ── 血統表では走る理由が説明できない

```
ロブチェン と テーオーシュタイン（半兄・26戦2勝）
  5代までの共有 4.50 / 5.00 = 近さ 90.0%
  欠けている0.50 = ちょうど父1頭ぶんの重み
```

父ワールドエースとワールドプレミアは**全兄弟＝血統表が同一**。母も同じ。
つまり**2代目から先が1頭も違わない**。26戦2勝の馬とダービー馬が同じ血統表。

血統側に残る説明は、種牡馬として使われた**個体の体**だけ。

```
ワールドエース    446〜478kg  1600中心   上り33秒台の斬れ   → 産駒246頭で重賞51戦1勝
ワールドプレミア   484〜492kg  3000・3200  上り35〜36秒台
ロブチェン       520kg      2400で上り33.2・33.8
```

母ソングライティングは Giant's Causeway × Unbridled's Song ＝**大型を出す血**。
小柄な兄をあてた年は噛み合わず、大型の弟をあてた年に520kgの馬が出た。
中島国治の「形体遺伝」、白井寿昭の「伝えたい部分を引き継げているか」がここ。

ブラックボイス（父ブラックタイド）は近さ65.6%。ブラックタイドには**マンデラがない**ので
持久の供給がなく、**障害**に行った（障害OP勝ち）。ここは血統表で説明がつく。

- **一度もトップ種牡馬がついていない。** ドゥラメンテもキタサンブラックもロードカナロアもなし
- **ワールドプレミアは初年度産駒**。その世代は2025年に出走5頭だけ（産駒順位128位）
- 入れている血は3回とも同じ（サンデー×ウインドインハーヘア）。全兄弟を2組使っている

→ **狙った名配合ではなく、安い定番処方の中から母系の体格とスピードが想定以上に出た馬。**

## 8. 菊花賞（京都・芝3000m）の判断

**血統の形としては合わない。**

- 長距離の供給は父側のドイツ（Acatenango）**一本足**。母系はGiant's Causeway×
  Unbridled's Song×Bold Ruckus＝スピードとパワーで、Son-in-Lawは11代の薄さ
- 母系で距離が持ったのは**障害に行ったブラックボイスだけ**。平地の長距離実績が家系にない
- 出たのは父の持久ではなく**兄の斬れ＋母系の体格**（520kgで2400の上り33.2）
- 皐月賞は1-1-1-1の逃げ切りでコースレコード。消耗戦を我慢して勝った形ではない

**馬場は味方。** 10/24の京都は芝が稍重で、芝5鞍の勝ち馬の4角位置は内・中・内・最内・内（外ゼロ）、
上り34.3〜34.9のスロー寄り。回復途上の内有利が続けば、自在性と上り33秒台が活きる。

→ **馬場は味方、血統は逆風。** 勝つとしたらそれは血統ではなく能力。
ズブ穴を探す立場からは、**血統で買う馬ではない**。
