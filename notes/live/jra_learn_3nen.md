# 中央 3年分（2023-11〜2026-11・10,455鞍）で学習した最終版

収集: 2026-03〜11 は netkeiba（2,172鞍）、それ以前は JRA公式 www.jra.go.jp（8,283鞍、scripts/jra_official_harvest.py）。
検証は後 1/3（境 2025-11-09、3,365鞍）。データ本体（data/jra/races.jsonl、約55M）はコミットしない。

## 想定ペース（スロー／ミドル／ハイ）
- コース平均＋馬場: 3区分の的中 **64.6%**、大外れ（スロー⇔ハイ）**1.6%**（直線式だけなら 60.3%／2.6%）
- 確度 高（境目から0.78秒以上）: 的中 **83.8%**、大外れ 1.5%。確度 低は 49.8%。

## 推定時計（平均誤差）
- 前半3F **0.62秒**／後半3F **0.63秒**／タイム **1.10秒**（芝ダ×距離の平均だけなら 0.69／0.73／1.20）

## 隊列
- 前後（学習モデル、履歴7割以上の鞍）: 1角 **+0.529**、4角 **+0.487**（通過順の中央値だけなら +0.507／+0.447）
- 内外（4角で併走組の外側になるか）: **+0.422**（馬番だけで +0.416）

## 3年分で確定した結論
1. ペースは条件（コース・距離・頭数・馬場）でほぼ決まる。逃げ馬の頭数は効かない。
2. 「ペースで有利な脚質が変わる」掛け算（展開利）は効かない（−0.09）。前にいること自体が効く（+0.12）。
3. 内外はほぼ馬番で決まる。
4. 精度は 6,000鞍あたりで頭打ち。これ以上は過去走以外の情報（出遅れ・当日の作戦・調教）が要る。

models/ の time_model・position_model・lateral_model は3年分版。図（scripts/jra_tenkai_zu.py）はこれを使う。
