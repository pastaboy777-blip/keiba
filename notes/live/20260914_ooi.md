# 2026-09-14 大井（終日 稍重）── 後半3鞍を事前ルールだけで予想した記録

9/15の反省から作ったルールを、**結果を見ていない日**に当てた検証。
9Rまでで日の性格を決め、10〜12Rを予想し、そのあと結果を開いた。

## 1. 使ったルール（結果を見る前に固定）

1. 軸＝「単勝10倍以内 かつ 直近の同距離帯で上がり順位が上位」
2. ★（そのレースで間隔が長いほう2頭）は必ず相手に残す
3. 馬単は 軸1着固定 → 相手3頭

9Rまでの性格：上がり3位以内 70%／1番人気 3着内 8/9／枠フラット（内30 中37 外33）。

## 3. 分かったこと3つ

### ① 上がり順位は「前で粘って勝った馬」を落とす

12R ハイケンス（2.2倍・1番人気）を、直近の上がり順位が **7/13位** だからと軸から落とした。勝った。
ハイケンスの前走は1600m 13頭で**1着**。上がり順位が低いのは弱いからではなく、**前にいたから**。

そして11R（1400m・16頭）は **1着が上り7位、3着が上り9位**。前が止まっていない。

→ **その日の上がり幅で切り替える。** `nichi.py` が判定を出すようにした。

| 判定 | 条件 | 扱い |
|---|---|---|
| 主変数にしてよい | 上がり3位以内 80%以上 かつ 上がり幅 平均4.0秒以上 | 軸を上がりに寄せる |
| 補助にとどめる | 70%以上 | 着順と併せて読む。人気馬を落とさない |
| 使わない | それ未満 | 位置取りと当条件で読む |

実測：**9/14 = 67% / 3.6秒 →「使わない」／ 9/15 = 81% / 4.6秒 →「主変数」**。
※多頭数（12頭超）の1400m以下は、判定に関わらず使わない。

### ② 履歴が引けない馬を切って、2日連続で勝たれた

| | 馬 | 扱い | 結果 |
|---|---|---|---|
| 9/15 6R | クイーンアン（中央から転入・+29kg） | 消し | 1着 3.5倍 |
| 9/14 11R | ナインエスクァイア（履歴が引けず） | 相手から外した | 1着 3.7倍 |

「データが無い」を「弱い」として扱っていた。**転入初戦は比較対象がいないだけ。**
→ `card.py` に `?` を付けて、★と同じく**切らない**運用にした。

### ③ ただし11Rの取りこぼしは、半分はパースのバグだった

ナインエスクァイアの履歴が引けなかったのは、**成績ページの列を決め打ちしていたため**。
出馬表の予想家の欄（「大木尚」「善林浩」…）は開催や場で本数が変わる。
見出し行から列名で引く方式に直したところ、同じ馬に

```
★15 ナインエスクァイア  1番人気3.7  98日ぶり★  大井1400m 1走1勝1好走  道悪4走3勝4好走
```

が出た。**修正後は★が 1着（ナインエスクァイア）と3着（ゴールデンクラウン 325日ぶり）に立つ。**

さらに同じ11Rでは、1頭（ヘルメース）が**騎手と斤量のセルが結合**していて行ごと落ちていた。
**行を落とすと、その馬が検討から消える。** 落とさず `?` を付けて出す形に変更。
