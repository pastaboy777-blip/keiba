# 3年分を自分で予想して結果と照らし合わせ、精度を上げる（2026-11-11）

`scripts/jra_yosou_3nen.py` が全鞍を日付順に「その日より前の情報だけ」で展開図と同じ作りで予想し、
1鞍ずつ結果と比べて data/jra/yosou_3nen.jsonl に書く（ペース・4角の並び・前1/3・ハナ、1頭ずつのずれ）。

## 直したこと
1. **赤丸をレース前の想定で学習**（scripts/jra_zone_kenkyu.py → models/zone_rule.json）
   - スロー=前3割×内（検証 鞍平均の1.32倍、穴 内11.1% 対 外9.5%）
   - 平均=前3割・内外とも（1.40倍）／ハイ=前4割×外（1.51倍、穴 外11.6% 対 内9.2%）
2. **隊列を非線形(LightGBM)に**（scripts/jra_position_model2.py → models/position_model.json）
   - 1角 +0.530 → **+0.536**、ハナ1番手 29.6% → **31.6%**、4角 +0.488 → **+0.494**
   - 同じ芝ダ・近い距離の過去走の位置も足した（線形では ±0.001 だった）
   - 図と同じ作りで通しても 4角の並び +0.481 → **+0.487**（2025-11-02以降 3,473鞍）
   - 図で使うには `pip install lightgbm numpy` が要る（無ければ線形に戻る）

## 試して効かなかったこと（記録）
- 隊列: 斤量・馬体重・年齢・間隔・昇級降級（±0.003）、同じ芝ダの位置（線形 ±0.001）
- ペース: 出走馬の顔ぶれ（逃げ率合計・先行馬割合）。3年分で芝は相関 −0.21 と効き目は見えるが、
  3区分の的中は 芝70.3→70.0%・ダ58.4→57.3% で上がらない（scripts/jra_pace_member.py）。採用しない。
- ペースは条件（コース・距離・頭数・馬場・クラス）でほぼ頭打ち（芝70%・ダ58%）。

## ②の検証（2026-11-11）
**風**（Open-Meteo の1時間ごとの風、10場×3年。scripts/jra_wind.py → data/jra/wind/、scripts/jra_wind_kenkyu.py → models/wind_model.json）
- 直線の向きは決め打ちせず、場×芝ダごとに「ずれ ~ 東西 + 南北の風」を学習。
- ペース誤差 0.976 → 0.967秒（風5m/s以上の鞍は 1.036 → 1.007秒）、3区分の的中は 64.9 → 64.8%（変わらず）。
- 後半3F 0.655 → 0.649秒、勝ちタイム 1.121 → 1.106秒。時計には少し効く。気象データは10km四方の値で直線の風そのものではない。

**出遅れ**
- JRA公式の「競走中の出来事等」は斜行・駐立不良・鞭などで、出遅れはほぼ載らない（1日12鞍で0件）。取り直しても材料にならない。
- 通過順から推定した出遅れ率（ほかの走より1角が0.35以上うしろだった割合）: 線形で 1角 +0.530→+0.532・ハナ 29.6→30.1%。
  LightGBM では変わらず（+0.536 / 4角 +0.495）。

**血統**
- 手元の siremap.json（地方用）では中央の馬の父が 7%（21,411頭中1,546）しか分からない。
- JRA公式の結果ページは勝ち馬の父だけ。全馬は馬のページを1頭ずつ（新馬・未勝利の馬だけで約13,700頭、3秒間隔で約11時間）。

## 頭打ちの確認（2026-11-11）
- ペースに「コースの S/M/H 割合・ばらつき」（学習期間だけで作成）を足す: 3区分 65.7 → 65.7%（変わらず）。
  モデルはよく使う（効いた順2〜4位）が、コース平均の想定と同じ情報。
- 隊列に「相手との比較」（序盤位置・逃げ率・近い条件の位置・4角中央値のレース内順位と前後との差）: 1角 +0.531 / 4角 +0.487（下がらないが上がらない）。
- 隊列を「並び順を当てる学び方」（LightGBM lambdarank）: 1角 +0.535・4角 +0.495（回帰の +0.536・+0.494 と同等）。
- → 手元の材料（3年分の成績・ラップ・通過順・騎手・風・クラス）では、ペース 65〜66%・隊列 1角 +0.53 / 4角 +0.49 が上限。
  これ以上は、成績表の外の材料（血統・厩舎コメント・調教・映像）が要る。
