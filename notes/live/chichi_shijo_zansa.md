## 何を測ったか

父の成績そのものは測らない。「パイロ産駒はダートが得意」が本当でも、
それが本当なら既にオッズに入っているので買えない。だから測るのは**市場からのズレ**。

```
残差 = 実際に勝ったか(0/1) − 市場の勝率
市場の勝率 = (1/単勝オッズ) ÷ そのレースの【全出走馬】の合計
```

正規化の分母を全出走馬にするのは `market_model.py` と同じ理由。
測れる馬だけで割ると確率が水増しされる。

2026年の南関1,824レース・20,322走のうち、父が判明した**19,807走（97%）／329種**。

## ① ばらつき検定 ── 判定が定まらない

150走以上の48種で、父ごとの平均残差がどれだけばらつくか。
父の欄をシャッフルしたときのばらつきと比べる。

```
実測            0.02049
プラセボ中央     0.01716
プラセボ95%上限  0.02017 〜 0.02089   ← 乱数の種で動く
超過率          3.4% 〜 6.0%
```

**5%の線をまたいでいる。**種を変えると「情報あり」と「でたらめ」が入れ替わる。
最初の報告（実測0.02066 > 上限0.02023）は、たまたま有利な側に落ちた1回を見ていた。

---

## ② 転移検定 ── こちらが本命。持ち越されない

年を前半・後半に割り、前半で出た父のズレが後半にも同じ向きに出るかを見る。
**持ち越されないズレは、来週の父を見ても使えない。**

```
        頭数    相関     プラセボ95%上限
40走以上  82種  +0.003      +0.229
60走以上  56種  +0.019      +0.225
80走以上  34種  +0.111      +0.338
```

**どれも大きく内側。** 前半のパイロが後半のパイロを予測しない。

これは今回いちばん重い結果で、①の判定がどちらに転んでも結論は変わらない。

## 条件で割ると即座に枯渇する

父×馬場、父×砂厚を測ろうとすると、そもそも母数が無い。

```
馬場状態（良/稍重/重/不良）で割る … 4区分すべてで50走以上ある父は【2種】
砂厚（船橋12cm / 他10cm）で割る  … 両方で50走以上ある父は【20種】
```

しかも符号が噛み合わない。

```
コパノリッキー   良+0.023(200)  稍重-0.005(83)  不良+0.075(55)  重-0.013(63)
ホッコータルマエ  良+0.002(265)  稍重+0.025(110) 不良+0.037(77)  重+0.034(63)
```

各セル50〜80走では、残差の平均は偶然で動く幅のほうが大きい。
**1年ぶんでは父×条件は測れない。**必要なのは年を足すことだが、
これは CLAUDE.md の「過去開催のバックテストはしない」に触れる。指示があるまでやらない。
