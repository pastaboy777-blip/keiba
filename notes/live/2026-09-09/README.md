## 何を間違えたか

### 1. 位置に寄せ過ぎた

**11R ⑪クレームドール** … 下地の数字はこの鞍で断然トップだったのに、
**「近走が4角9〜13番手だから今の川崎では届かない」と位置を理由に外した。**
実際は**4角先頭タイを取って上がり39.9＝組で最速。単勝2,780円で勝った。**
「この馬は後ろにしか行けない」という決めつけが間違いだった。

**12R ⑤シェナベスト** … 最初は◎候補にしていたのに、下地の数字がゼロなので⑦に替えた。
**⑤が単勝460円で勝ち、◎⑦は4着。**

**位置で切って外し、数字で切って外している。両方向でやった。**

### 2. 「不良だから前」は2日分のデータの引っ張り過ぎ

今日の三連単は 140,400／105,190／61,340／57,920／46,480／28,900／17,720。
**9/8（重）より明らかに荒れている。**

後ろから来た馬も毎鞍いた ── 3R 4角8番手が2着、4R 4角12番手が3着、
10R 4角7番手が3着、12R 4角5番手が3着。

**時計がかかる馬場ほど、前が最後に止まる余地ができて人気が崩れる。**
9/7・9/8の「前しか来ない」を3日目にそのまま持ち込んだのが誤り。

**穴の作り方を「人気薄で終いが使える馬」から

- ○②リコーベレッタ（位置だけ）→ 6着
- ○③アイリーズ（位置だけ）→ 9着

**近走の4角位置で「この馬は前に行けない」と決めつけない。**
