# 川崎 11/9（月）〜11/11（水）の3日 ── 展開隊列予想の狙い方

ユーザーの指示で測った（「月曜から水曜で」「何か傾向ない？？」「展開隊列予想の狙い方」）。
36鞍・406頭。**3日とも重〜不良**で、**当日の後3Fは36鞍のうち35鞍が水準より遅い**。

| 日 | 馬場 | 当日の流れ |
|---|---|---|
| 11/9（月） | 重 | 11Rだけ水準どおり(M)、他11鞍は遅い(S) |
| 11/10（火） | 不良 | 取れた8鞍すべて遅い(S)。4〜7Rはラップ欠け |
| 11/11（水） | 不良 | 12鞍すべて遅い(S) |

## 1. 「ミドルは中強い」 ── この3日では測れない

当日の流れが **M だったのは11/9 11Rの1鞍だけ**（該当12頭）。
35鞍が S なので、3日ぶんでは M の鞍が母数にならない。

11/11 12Rで**中の3頭が1-2-3**（⑦9人気・⑩1人気・⑧10人気、内度.45/.47/.45）になったのは事実だが、
**その鞍も実際は水準より4.6秒遅い S** だった。事前想定が M だっただけ。
→ 「ミドルは中」は**まだ確かめられていない**。M の鞍が出てきたら数える。

## 2. 「同じラインの馬がよく来る」 ── 偶然の範囲

帯（内度＝枠＋騎手）で数えた。偶然は、その鞍の帯の人数から3頭を引く確率。

| | 実際 | 偶然なら |
|---|---|---|
| 3着以内の3頭が**同じ帯** | 3鞍 / 36 = **8.3%** | 3.6鞍 = 10.1% |
| **2頭以上**が同じ帯 | 29鞍 / 36 = **80.6%** | 27.6鞍 = 76.8% |

**3頭そろうのは偶然より少なく、2頭以上は偶然どおり。** ラインで固まる傾向は出ていない。

そろった3鞍は

- **11/10 1R** 外3頭
- **11/10 7R** 内3頭（②③⑦。ユーザーが「②③を入れたうちのライン」と言った鞍。三連単949,920円）
- **11/11 12R** 中3頭

★ 11/11 10Rも**外3頭で1-2-3**だったが、あれは③を**手で外に動かした**結果（`--soto 10:3`）。
　枠＋騎手だけで計算すると③は内度.72＝内なので、この表では「内1中1外1」になる。
　**手直しが効いた鞍で、帯そのものの傾向ではない。**

## 3. 本当に出ている傾向 ── 4角の位置

これは桁がちがう。

| 4角の相対位置 | 3着内率 |
|---|---|
| **0.0〜0.2** | 121頭中 68頭 = **56.2%** |
| 0.2〜0.4 | 100頭中 26頭 = 26.0% |
| 0.4〜0.6 | 93頭中 10頭 = 10.8% |
| 0.6〜1.0 | 92頭中 5頭 = **5.4%** |

**終いと重ねると切れる。**

| | 3着内率 |
|---|---|
| **4角0.2以内 ＋ 上がり3位以内** | **44頭中 44頭 = 100.0%** |
| 4角0.2以内 ＋ 上がり4位以下 | 81頭中 26頭 = 32.1% |
| 4角0.4より後ろ ＋ 上がり3位以内 | 37頭中 12頭 = 32.4% |

**終いだけでは届かない。前めを取って、かつ終いがある馬が全部来ている。**（ルール13そのまま）

### 1角より4角のほうが差が大きい

| 1角の相対位置 | 3着内率 |
|---|---|
| 0.0〜0.2 | 107頭中 42頭 = 39.3% |
| 0.2〜0.4 | 82頭中 21頭 = 25.6% |
| 0.4〜0.6 | 71頭中 13頭 = 18.3% |
| 0.6〜1.0 | 74頭中 12頭 = 16.2% |

**隊列を組むのは1角（ルール23）。でも狙いを決めるのは4角。**
1角0.0〜0.2 で39.3%、4角0.0〜0.2 で56.2% ── その差が「1角で前にいて4角までに下がった馬」。
だから図では **1角の位置 ＋ gain（1角−4角）** を重ねて、**4角で0.2以内に残るか**を見る。

## まとめ ── 狙い方

1. **「4角で0.2以内を取れるか」を先に決める。** これだけで56.2%対5.4%。
2. その中から**上がり3位以内に入れる馬**を取る。**44頭中44頭（100%）。**
3. 穴も同じ。**7人気以下は4角0.2以内で35.3%、0.4以降は2.0%。**
   後ろから狙うなら**終い1〜4位が条件**。
4. ラインで固めない。**同じ帯に3頭そろうのは偶然より少ない（8.3%／偶然10.1%）。**
   内外は「前めを取れるか」が決まったあとの話。
5. 「ミドルは中」は**M の鞍が来てから数える**。この3日には1鞍しかない。

★ 3日とも重〜不良・ほぼ全鞍が遅い流れ。**良馬場や速い流れの日に持ち越さない**（ルール12）。
