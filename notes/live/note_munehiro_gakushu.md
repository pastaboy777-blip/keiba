# note「むねひろ」無料記事から学んだこと（2026-11-11）

取り込み: `scripts/note_harvest.py munehironet --free-only` → data/note/（コミットしない）。
無料140本（2025-12〜2026-11、約92万字）。有料461本は無料部分のみ。

## 1. 先週の風傾向 → 全10場の直線の向き（`scripts/note_kaze.py` → models/course_straight.json）
126件の記述(向かい/追い/横＋風向)から円周平均。揃い R は中山0.95・新潟0.93・京都0.92 と高い。中京だけ0.47(8件)。
3年で: 直線向かい風3m+ → 後半3Fが+0.3〜0.5秒(ハイ寄り)、追い風3m+ → −0.15〜0.45秒(スロー寄り)。全場で同じ向き。
ペース補正(前後差 −0.05〜0.06秒/向かい1m)を入れて ペース3区分 64.6→65.1%、風3m+の鞍 60.7→63.1%。
展開図のペース欄に「直線 向かい風◯m」を出す。

## 2. ペースの言い方（Ｓ/Ｍ/Ｈペース）
回顧でそのレースのペースを書いた41鞍で、こちらの3区分と一致 30/41(73%)。ずれは境目の鞍。
- 記事は **テン(前半3F)がそのコースにしては速い**と、前後差が平均でも「Ｈペース」と書く傾向
  （新潟芝2200・東京芝1600・中山芝1200）。馬場(重・稍重で軽いダート)も割り引いて読んでいる。
- 41鞍では少ないので判定の境目は変えない。

## 3. 「次走注目」に選ぶ馬の形（回顧92頭、ほぼ全部勝ち馬）
- ハイペースで褒めた23頭のうち15頭が **4角で前**(相対位置0.25以内) ＝ 展開に逆らって前で粘った馬
- 上がり1位が64頭
- 書いている材料: ゲートの出・ハナを主張できたか・外から圧をかけられたか・手前を替えての再加速・
  走破時計とレコード差・上がり順位・「控える形でも我慢できるか」(=隊列が変わったときの課題)
→ こちらの穴の考え方(展開に逆らって好走した馬を次で拾う)と同じ向き。

## 4. まだ取り込んでいない材料
- **気候適性(気候／寒・涼・暖)**: 馬ごとに得意な気温帯がある見方。人気薄の好走例が多い。
  気温を Open-Meteo で取り、馬ごとの気温帯別成績をこちらのデータで作れる。
- **馬場状態の変化時刻**(例 13:32 芝 良→稍重): 当日の途中から馬場が変わる鞍の補正に使える。
