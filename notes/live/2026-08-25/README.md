# 馬体重の検証（風の話をきっかけに）

画像: `funabashi_weight.png`

## 前提：風は検証できない

**風速・風向のデータは手元にない。** ラップも馬場状態（良・稍・重・不良）も取れるが、気象は取れない。
なので「強風の日に小型が有利／不利」は**このデータでは答えられない**。
検証できたのは「船橋でズブ穴を小型から選ぶのが正しいか」という別の問い。
