## 各レースの根拠

### 1R（ダ1200・7頭・2歳五）
全馬キャリア1〜3走。1200mの実測を持つのは①②④の3頭だけで、**最速は④ケイズブレイヴの1:19.4**（上39.7）。
7/2の不良を4-4-4、6/5の1000mを4-5と**もともと前で運べる馬**。前走7番人気4着で人気は被らない。
○⑦クレイジーロッカーは8/6の1000mが**1:03.5・上39.1**とメンバー断然。4角4番手で位置も足りる。

### 2R（ダ1200・9頭・2歳四）
⑧と⑤は**8/6の同じ1000mを走って、どちらも1:02.8・上38.8**。この9頭で最速。
違いは**⑧が5番人気で3着、⑤が2番人気で4着**という着順と人気のねじれ。⑧を上に取る。

### 3R（ダ1200・6頭・3歳四）
1200mの持ち時計（良）:

```
④ゴーレム   1:17.5  ／ 不良1:17.4
⑥ドジッコ   1:17.7  ／ 不良1:17.7
③ゴッドブラウン 1:17.9 ／ 8/4に1:18.1（上39.0＝メンバー最速）で2着
②マリノレーヴェ 1:18.1 ／ 8/3に1:18.5（4角1番手）で4着
①クラバエル   1:18.7
⑤ブライティアメール 1:19.4（8/4で1着）／ 1:19.7
```

**⑤は前走1着だが6頭で最も遅い持ち時計**。時計では買えないと判断。
◎⑥ドジッコは時計が2番目で、**直近4走の4角がすべて4番手**。5走して3着内がなく人気は落ちる。
④ゴーレムは時計最速・399=6.8で最上位だが、4角が10-9-7-9番手と後ろすぎるためヒモ。

### 4R（ダ1500・12頭・C2）
◎⑨ルナーサウスポールは**399=11.9・本物4で12頭断然**。
6/29の重馬場の船橋1500を4-4-4-4で4着、3/10も6-5-5-5で2着と**1500mでは位置を取れる**。
前走は1600mを13番手から6着（10番人気）で、**1600→1500の短縮**。
○③サージは6/5の稍重の船橋1500を10-10-8-5で1着、6/22の重の浦和1500も5-5-4-5で3着。

**⑥サトノオリエンタルは3走連続1番人気（2着・1着・1着）でエッジ5・399=8.0だが、方針どおり◎にせずヒモ。**
1200m→1500mの延長も未経験。

### 5R（ダ1200・12頭・3歳三）
8/24の5R（3歳・12頭・1200m）と条件がほぼ同じ。あの日は**上がり上位3頭がそのまま1〜3着**だった。
◎⑨トーヤマノゴールドは8/3に6-6-4から**上39.5で3着（8番人気）**、6/2も**上39.1**と
**船橋1200の上がり実数がこの12頭で最上位**。前走で4角4番手まで押し上げているので前残りでも対応できる。
○⑫エターナルフィズは7/15の浦和1400を9-9-6-3から**上38.1で2着**、6/29の不良の船橋1200は2-2-2で3着。

## 継続している方針

- **足切りしない**（4角位置による機械的除外はしない）
- **当日の人気・オッズはカードに書かない**（過去走の人気は可）
- ◎＝人気を被らない馬／○＝中身が確かな馬
- **1番人気になりそうな馬は◎にしない**（8/24でこの修正が効き、◎の複回収が160%）
- 締め文言は「この条件が向いている」のみ
