# 踏ん張り指数（`kawasaki_funbari.html` / `.png` ／ `scripts/funbari.py`）

## 考え方（2026-07-30 本人の読み）
砂が緩むと「走りやすい」と「踏ん張れない」が同時に来る。7/29川崎12Rの2着⑤アマビリティは
上がり41.4で**メンバー最速**だったが、41.4である＝誰も切れていない中でいちばん落ち幅が小さかっただけ。
**455kg・467kgのワンツーも「軽いから沈まない＝落ち幅が小さい」で説明がつく。**
→ この砂で勝つのは「速い上がりを使える馬」ではなく**「上がりが落ちない馬」**。決め手ではなく劣化しにくさの勝負。

## 指標の定義（推測ゼロ・馬柱の事実のみ）
- **踏ん張り回数** = その場×距離帯の「3着内の上がり中央値」より **+0.3秒以上遅い上がり**で、それでも **3着内**に来た走りの数。
- **最深** = 基準からどれだけ遅い上がりで残せたか（大きいほどタフな決着を耐えた）。
- **ブレ幅** = 近5走の上がり(川崎1400m相当)の最大−最小。小さいほど劣化しにくい。
- 基準表は `data/samples/top3_agari_ref.json`（南関全データの3着内上がり中央値・場×距離帯）。
  例：川崎900=38.0／川崎1400=40.6／川崎1600=40.5／川崎2000=40.6／浦和1400=39.3／船橋1400=38.9／大井1400=38.4。
  **帯補正だけで揃えると900mが全部「かかった」判定になる**ため、この実測基準に切替えた（初版のバグ）。
