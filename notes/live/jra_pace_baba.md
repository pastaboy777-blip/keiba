# 渋った馬場でペースの予想は偏るか（2026-11-15 京都の重い芝から）

スクリプト: `scripts/jra_pace_baba.py`（`--dump 2026-11-15` で当日の鞍ごと）。回収率は測っていない。

## 問い
11/15 はペース3区分の外れ17鞍のうち11鞍が「実際のほうが前半がゆるい」側、京都の重い芝はそろってスロー寄りにずれた。
渋った馬場でいつも起きる偏りか。

## 予想の作り方（展開図 jra_tenkai_zu.py）
- `learned_pace`: PaceModel（直線式＋コース平均＋馬場の項）＋当日の前の鞍のずれ×0.2。
  **馬場の項は芝ダ共通**（`baba_x` は稍/重/不のダミーだけで、芝ダとの掛け合わせが無い）。
- `pace_lgbm_diff`: models/pace_lgbm.json の reg（学習は 2025-05-10 より前）。材料に PaceModel の値・芝フラグ・馬場0〜3・
  「当日のずれ」。これがあれば最終値（`fc.diff_pred`）はこちら。
- 当日のずれの欄: 学習（jra_pace_lgbm.py）は**当日の前の鞍だけ**（無ければ0）。展開図は当日の前の鞍が無いとき
  （前日に描くとき）**同じ開催の前の開催日（8日以内）のずれ**を入れる。ここが学習と違う。
- 区分の境 q: 展開図はその日より前の全鞍の三分位（11/15 は −1.6 / +0.1）。この研究は学習区間の三分位（−1.7 / 0.0）。
- PaceModel は展開図ではその日より前の全鞍で作る。研究では月ごとに作り直し（その月より前だけ）。LGBM の材料は学習と同じ cut 前の PaceModel。

## 読み
- **渋った芝で「実際のほうが前半ゆるい」偏りは無い。逆**。重・不の芝は、予想より前半が**速い**ほうへ外れる（−0.2〜−0.3秒）。
- 渋った芝を開催日（日×場）ごとに見ると33日のうち −0.3秒以下が15日、+0.3秒以上が6日。11/15 京都（芝重5鞍 +0.50）は
  少ないほうの日。日によって向きが割れるので、11/15 の京都は「その日の馬場・メンバーのずれ」で、いつもの偏りではない。
- ダートの渋りは PaceModel 単独だと +0.2（前半ゆるい側）にずれる（馬場の項が芝ダ共通で、芝側に引っ張られている）が、
  LightGBM（芝フラグ×馬場が入る）がこれを消している（ダ稍〜不 −0.11〜+0.00）。展開図の最終値は LightGBM なので実害は小さい。
- 11/15 の京都10R は**ダ1800 不**（芝ではない）。芝の重は 5・7・9・11・12R。

## 補正を足すか → **入れない**
芝ダ×馬場の 実−予 平均を件数で縮め（n/(n+30)、良は0）、時系列で前で決めて後で確かめた。

| 予想 | 決めた期間 → 確かめた期間 | 3区分の当たり 補正なし → あり |
|---|---|---|
| LGBM前日 | 検証前半 → 検証後半（2026-02-14〜、2596鞍） | 65.8% → 65.8% |
| LGBM当日 | 同上 | 65.4% → 65.3% |
| PM | 同上 | 65.8% → 65.9% |
| PM（3年） | 〜2025-08-10 → 以降（4246鞍） | 65.4% → 65.5% |

- 芝重の補正は決める期間によって −0.04（検証前半）〜 −0.22（3年前半）と揺れ、芝稍は符号まで入れ替わる。
  渋った芝は数日にかたまる（芝重124鞍＝実質33日）ので、平均が日の当たり外れで動く。
- 当たりは ±0.1pt で動かない。`models/pace_baba_adj.json` は作らず、jra_tenkai_zu.py も変えていない。

## 来週に活かすこと
- 渋った芝を「1段スロー寄りに見る」は**やらない**（3年ではむしろハイ寄りに外れる）。11/15 の振り返りの §161 の一行は撤回扱い。
- 渋った日は、当日の前の鞍が出てからのずれ（LGBM当日、展開図を描き直す運用）のほうが芝重のずれが小さい（−0.23 → −0.11）。
  雨の日は前半の鞍の結果で展開図を描き直すほうが効く。
- PaceModel の馬場の項を芝ダ別にする余地はある（PM 単独のダート渋りのずれ +0.2 が消えるはず）が、最終値の LightGBM では
  すでに消えているので、今は手を入れない。
