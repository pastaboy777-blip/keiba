# 南関・穴スコア（サラブレ流をデータ検証して落とし込み）

`scripts/ana/nankan_ana.py`。サラブレ穴ぐさの考え方（脚質・ローテ・馬体重）を南関データで検証し、
効いた因子だけを重み付けした人気薄(6番人気↓)向けの穴スコア。

## 因子と重み（実測根拠つき）
| 因子 | 条件 | 重み | 実測 |
|---|---|---|---|
| 前受け習性 | 前走が逃/先 | +2 | 前受け人気薄 単回収189-261% |
| ローテ | 連闘〜中1週(≤10日) | +2 | 単回収117%（プラス収支） |
| ローテ | 中1-2週(11-20) | -1 | 単回収65%（谷） |
| ローテ | 中5週+(36日〜) | +1 | 単回収78% |
| 馬体重 | 前走比+2kg以上 | -2 | 増は単回収47-56%（地雷） |
| 馬体重 | 絞れ-2kg以下 | +1 | 複勝lift1.14 |
| 血統 | パワー軸(パ, daikei) | +1 | 穴率が中系の約2倍 |
| 血統 | 軽い系 | -0.5 | ダート穴で不利 |
| クロス | ND系(ストームキャット/ダンチヒ/サドラーズ) | +0.5 | サラブレのスパイス |

## バックテスト（南関4場 2026-04〜07・人気薄・血統抜き合成）
| スコア | n | 複勝率 | 単回収 |
|---|---|---|---|
| ≥2 | 899 | 12.7% | 106% |
| ≥3 | 396 | 13.9% | 108% |
| ≥4 | 81 | 13.6% | 29%(過剰) |
→ **score≥3で単回収108%＝プラス収支**（血統を足せば更に上振れ見込み）。

## 使い方
```python
from nankan_ana import ana_score
ana_score(nk=9, interval=7, wt_ch=-2, power='パ', habit_front=True)
# -> (6.0, ['前受け習性+2','連闘~中1週(7日)+2','絞れ(-2)+1','パワー血統+1'])
```
```
python3 scripts/ana/nankan_ana.py backtest   # 回収率の再検証
```
- 入力：nk=単勝人気、interval=前走からの日数、wt_ch=前走比体重、power=daikei.power(父)、habit_front=前走が逃/先。
- 出力：スコアと内訳。**score≥3を穴の本線、≥2をヒモ候補**に。

## 運用（毎日の南関予想への乗せ方）
1. 人気薄(6番人気↓)を対象に、前走脚質(逃/先)・前走からの間隔・体重増減・父のパワー軸でスコア化。
2. score≥3を複勝・3連複のヒモに厚く。体重+2kg以上は無条件で減点。
3. 前受けは事前予測が難しいので「前走が逃/先だった＝習性」で近似。
