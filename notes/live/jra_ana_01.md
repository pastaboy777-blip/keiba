# 隊列から穴を取る ── 集計1回目（約2,100鞍・16,886頭）

`scripts/jra_ana_kensho.py`。人気は予想に使わず、「穴＝7番人気以下」の定義と回収率の計算だけに使う。
単勝回収率は確定オッズで、各マス百頭前後なので**ぶれが大きい**。3着内率の方を主に見る。

## 1. コース別: 隊列予想の前1/3 と後1/3 の3着内率の差
全20コースで前1/3が上。差の大きい順（前残りしやすい）:
福島ダ +26.1 / 新潟ダ +21.2 / 中山芝 +19.4 / 中山ダ +19.2 / 小倉ダ +19.0 / 中京芝 +17.8 / 函館芝 +15.9 / 東京ダ +15.1
差の小さいコース: **東京芝 +7.2 / 阪神芝 +7.7**（直線の長い芝）。
→ 「直線が長いと前の有利が薄れる」は**隊列の効き方**としては正しい（ペースとの掛け算としては効かなかったが、
  コース別の前の有利さとしては出る）。
前1/3の穴の3着内率が高いコース: 中山芝 19.5% / 新潟ダ 16.5% / 福島ダ 13.5% / 福島芝 13.0% / 中京ダ 12.8%。

## 2. 隊列予想 前1/3 の穴（2,502頭、3着内 10.8%）── 条件別
| 条件 | 3着内 | 単勝回収率 |
|---|---|---|
| 距離延長 | 11.9% | 84% |
| 同距離 | 11.0% | 117% |
| **距離短縮** | **9.2%** | **46%** |
| **芝ダ替わり** | **6.2%** | **41%** |
| 前走4角で前 | 10.4% | 70% |
| **前走4角で後ろ（今回は前に行く予想）** | 11.4% | **119%** |
| 内枠 / 中枠 / 外枠 | 11.6 / 10.7 / 10.3% | 64 / 106 / 90% |

- **消し**: 芝ダ替わりの穴、距離短縮の穴（前に行く予想でも来ない）。
- **狙い**: 前走は後ろだったが今回は前に行く予想の穴（位置取りが前進する馬を市場が見落としている可能性）。
- 枠は3着内率ではほぼ差なし。
- いずれも7か月分。**3年分で残るか確認する。**
