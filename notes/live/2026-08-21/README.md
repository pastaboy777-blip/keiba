## 選定手順を変更した

8/20の結果を受けて、**一次ソートを「材料（タグ）の数」から「399・上がりの実数」に変えた**。

根拠（8/20 川崎）：

| 方式 | ◎3着内 | 複回収 |
|---|---|---|
| 確定版（測った数字を優先した最終形） | 7/12 | 138% |
| 材料の数だけで並べた案 | 3/12 | 35% |

決定的だったのが11R。材料タグ6個で最多だった①サザンカ（399=0.1）は12番人気12着、
タグ1個だけの⑥サヨノフィールド（399=11.9で14頭最上位）が2着（複320）だった。

### 新しい順序

1. **399スコアと上がりの実数**（測ったもの）
2. 4角3番手以内を取れるか — ただし**上がりが断然なら後方でも可**（8/20 11R⑥が4角10番手から2着・上がり38.5）
3. 材料タグの数は上位2の裏付けとして見る（同点の切り分けにのみ使う）

### 11R — 399スコアを鵜呑みにしなかった一戦

399だけを見ると ⑧スカイブルー が 9.2 で8頭中断然だが、**この数字は中央時代の芝1200由来**で、
南関に来てからは川崎1600で12着、川崎1400で9着（上がり44.3）と結果が出ていない。900mも初。

一方 ◎⑥フォーティチュードは399=0.0。これは**浦和800mが399の集計対象外**なだけで、実態は
**浦和800を5走して1着・3着・1着・1着・2着、5走とも4角先頭、上がり34.7〜35.8**。
4/24の重馬場でも34.7で、渋っても落ちない。800m→900mは100m延びるだけ。

**399は「測ったもの」の代理指標であって、測ったものそのものではない。**
スコアが0でも実際の上がりとレースぶりが揃っていればそちらを取る、というのが今日の適用。
8/20の学び（数えたものより測ったもの）を一段深めた形。

### 9R が本命本線

## 今日の敗因は「位置」ひとつ

勝ち馬の4角位置：

```
2, 1, 1, 1, 2, 1, 3, 4, 2, 3, 1, 2   ← 1番手5勝・3番手以内11勝
```

8/20は3番手以内が7勝だったが、**今日は11勝と大幅に前有利へ戻った**（8/19は10勝）。
8/20のほうが例外で、良馬場が続く川崎の基本形はこちら。

◎の4角位置ごとに割ると、結論が一目で出る：

| ◎の4角位置 | 頭数 | 3着内 |
|---|---|---|
| **4番手以内** | 4 | **4（100%）** |
| 7番手 | 3 | 0 |
| 11番手 | 3 | 1 |

- 4番手以内の4頭 … 6R①3着／7R②2着／8R③2着／11R⑥2着 → **全部3着内**
- 7番手の3頭 … 2R④5着／5R⑧7着／10R⑥4着 → **全滅**
- 11番手の3頭 … 1R⑧3着／9R②7着／12R①7着 → 届いたのは1R⑧だけ

1R⑧セイウンパイオニアは**上がり38.4でメンバー最速**（2着39.8・1着40.2）だったが、
それでも**3着まで**。今の川崎で後方から届く上限がここ。

## 「測った数字」だけで選ぶと位置が足りなくなる

399や上がり実数を一次ソートにする方針そのものは間違っていない。
8Rの◎○ワンツーは、399=7.9本物3（◎③）と399=5.8本物2（○②）を上から2頭取った結果そのもの。

問題は、**399の上位馬は「差し」「強差し」タグを持つ後方型に偏る**こと。
399を上から並べるだけだと、自動的に4角7番手以降の馬が並んでしまう。

象徴が9R。◎②アウェイクサードは**399=12.6・本物3・タグ7個とカード全項目で最上位**だったが、
4角11番手のまま7着。勝った⑥リッキーズラックは**399=0.4・タグ3個**で、4角2番手だった。

### 次回からの修正

1. 399・上がり実数で**上位3頭に絞る**（ここまでは今日と同じ）
2. その中から**過去3走で4角4番手以内を取ったことがある馬**を◎にする
3. 上がりがメンバー断然（1秒以上速い）なら後方型でも可。ただし**狙いは3着**であって1着ではない

## 3R・4Rを外した判断は正解だった

- 3R … 1着⑤スノージュエル（2番人気・単280、4角1番手）／2着⑨（1番人気）
- 4R … 1着④ゴールドモナコ（2番人気・単290、4角1番手）／2着⑤（1番人気）

どちらも人気決着で妙味なし。加えて、外す前に置いていた血統だけの印
（3R◎⑧ベラブラウニー／4R◎⑧ディスポスト）はどちらも掲示板を外している。
**データのない新馬戦は出さない**を今後も守る。
