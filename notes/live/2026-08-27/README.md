## 各レースの根拠

### 1R（ダ1200・10頭・3歳六）

**◎③ホワイトナイル** … 475kg・矢野貴。8/4の船橋1200を**4-3-3から1:18.7**で4着。
この1:18.7は10頭で最速タイで、しかも4角3番手という今日の狙いどおりの位置。
金沢1400では6/8に**1-1-1-1で1着**、7/5も3-2-2-2で2着と、**前で運んで結果を出す形**が固まっている。

**○⑤グランドタルマエ** … 買う材料の数が10頭で最多。名古屋1500を**8-6-6-3で1着**、1500mで上がり39.2を3回。
490kgで1500m→1200mの短縮。

### 2R（ダ1200・12頭・Ｃ３三）

**◎⑤フェアリーランド** … 458kg・斤52。8/5の船橋1200を**4-3-3から1:17.2**で3着。
**この1:17.2は12頭で最速**。7/13の浦和1500も3-3-3-1で2着、5/6は2-1-1と、
**直近5走の4角がすべて3番手以内**。今日の読みにど真ん中で当てはまる。

**○⑨ブロードファイラム** … 渋った馬場を後ろから走った中身が12頭で最上位。**5走とも掲示板**で、
6/28の不良では**上がり37.7**。447kg。ただし前走1番人気2着で人気を集める。

### 4R（ダ1500・6頭・2歳 船橋所属未勝利選抜馬）

**◎⑥フルールマジック** … 449kg・矢野貴。8/2の船橋1200を**4-4-4から1:17.9で3着**、
7/4の1000mも**3-3から1:02.9で2着（上がり38.3）**。**この6頭で時計も上がりも断然**。
1500mは初めてだが、通過が4-4-4・3-3と**常に前で運べている**のが今日は効く。

**○②フェズミント** … 8/3の船橋1500を4-3-3-4で**1:41.1**。1500mの時計は6頭で断然（①1:43.8・⑤1:43.7）
だが前走4番人気で人気を集める。

### 5R（ダ1200・12頭・Ｃ３二）

**◎⑦ノワスティエ** … 436kg・斤52。直近5走の4角が**5・1・3・4・3番手**と常に前で運んでいる。
7/16の浦和1400を**2-2-1-1で2着**、6/26の不良の浦和1500も**1-1-1-3で3着**。
1400m・1500m → 1200mの短縮で、前に行きやすくなる。

**○④エンドステージ** … **船橋1200で4勝**。8/5に**6-4-4から1:16.8・上がり37.9で1着**と
時計も上がりも12頭で断然だが、5走とも1〜2番人気で今日も人気を被る。520kg。

### 劇画タッチ版

画像: `funabashi_1_5_manga.png`／HTML: `funabashi_1_5_manga.html`

中身は上のズブ穴版と同じ（◎⑥／◎③／◎⑤／◎⑧）。見た目だけを劇画調にしたもの。

作りの要点（システムに劇画フォントが無いので、CSSだけで寄せている）：

- **太い黒フチ** … `-webkit-text-stroke` + `paint-order:stroke fill`。
  ◎○のような細い抜きのある文字はフチが3.5px以上だと中が潰れるので、見出しは7〜22px、印は3.5pxと使い分ける
- **「ズブ穴」の劇画ロゴ** … 118px・赤 `#e8232a`・黒フチ22px・`skewX(-9deg) rotate(-3deg)`・`text-shadow` で影を落とす
- **集中線** … `repeating-conic-gradient` を細く（1.5deg / 5.6deg）
- **網点（ハーフトーン）** … `radial-gradient` の点を `background-size:9px` で敷き詰め。
  白パネルの左側にも `.corner` で重ねてコマらしさを出す
- **爆発（星形）バッジ** … `clip-path:polygon()` を Python で生成（`star()` 関数、24点／16点）。
  右上の「南関ズブ穴」と勝負レースの「勝負」の2種類（締めの吹き出しは指示により削除）
- **コマ枠** … `border:6px solid #000` + `box-shadow:10px 10px 0` のベタ影
- **色数を絞る** … 黒・白・赤 `#e8232a`・黄 `#ffd400`・青 `#0d4d9c` の5色だけ

読ませる本文（メモ）は劇画にせず普通のゴシックのまま。フチを付けると読めなくなるため。
