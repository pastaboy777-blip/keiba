### この1鞍から取れること

**不良でも「前」だが、ハナ一辺倒ではない。番手から抜け出す形がいちばん良かった。**

1着4枠／2着6枠／3着8枠／4着5枠。**内1〜2枠は①が8着、②が6着。**

**不良の初戦は逆に出た。1鞍なので断定はしない。2R以降で内枠が来るかを必ず確認する。**

**3. 時計はかかっている。**

勝ち時計 **1:33.9**。8/18（**重**）のダ1400・1Rはラップ合計で **1:31.9** だった。
**2.0秒遅い。**
ただし8/18の1Rは3歳戦、今日はＣ３五。**条件が違うので単純比較はできないが、方向としては「不良のほうが時計がかかる」。**
**「渋るほど締まって速くなる」という大井での経験は、今日の川崎には当てはまっていない。**

1着から4着まで0.8秒に対して、**11着が3.8秒差・12着が5.6秒差**。
**前で運べた馬とそうでない馬の差がはっきり出た。脚を使えない馬場。**
