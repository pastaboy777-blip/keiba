## 締め

来週の大井は、まず馬場を見てから。前開催は60鞍とも渋っていて、乾くほど前有利が強まった。
良に戻るなら前有利はさらに強い可能性がある。

そのうえで、ここに並べた馬は **◎ではなく○とヒモの位置から** 入る。
上げてきたのは事実だが、前開催で後ろから勝ち切れたのは60鞍で2頭だけだったから。

**◎に取るなら「上げてきた」に加えて「前に付けられる」が要る。**
