# 並び(隊列)×展開(ハイ/ミドル/スロー)と荒れ方 — 中央 4000鞍

問い(ユーザー):「こういう並びで、こういう展開のときは、こういう荒れ方をする、というパターンはないか」。
中央の3年分のデータで研究してよい範囲の作業。回収率は測っていない。人気は「穴＝6番人気以下」の定義と配当の集計にだけ使い、
並びの分類には使っていない。

- スクリプト: `scripts/jra_arekata.py`
  - `python3 scripts/jra_arekata.py --n 4000 --out data/jra/arekata_rows.jsonl`(予想を作る。約45分。途中から再開できる)
  - `python3 scripts/jra_arekata.py --load data/jra/arekata_rows.jsonl`(集計だけ。約1分)
  - `--shuffle 種` で、結果だけを同じ頭数帯×芝ダ×距離帯の中で入れ替えた「偶然の目安」を同じ集計で出す
- 対象: 2024-06-01〜2026-11-15 の平地(芝・ダ)、新馬・障害を除き、4角の通過順・ラップ・3連複がある 7602鞍から日付順に等間隔で **4000鞍**。
  前半 1988鞍(〜2025-09-05)/ 後半 2012鞍(2025-09-06〜)。
- 予想の作り方: その鞍の着順・通過順・タイム・上がり・人気・ラップを消した行と、それより前の走だけで
  `jra_tenkai_zu.one_race`(--from-data と同じ組み立て)を呼ぶ(jra_kensho.py と同じやり方)。展開図のコードは変えていない。
  ※ 位置・ペースの LightGBM は3年分で学習した表なので、その鞍自身が学習にわずかに混ざっている(既存の検証と同じ条件)。

## 分け方

| 並び(レース前) | 中身 |
|---|---|
| 逃げ候補 | nige_rate≥0.3 の頭数 0/1/2/3+ |
| 単騎逃げ | fc.lone_leader あり/なし |
| 前組の内外 | 予想1角(pos1)の順で前1/3の馬の outer_score 平均 − 全体平均。4000鞍の3等分: 内寄り < −0.046 ≤ 中 < +0.029 ≤ 外寄り |
| 先行の多さ | 予想1角 pos1≥0.67 の馬の割合。3等分: 先行少 < 0.25 ≤ 先行中 < 0.38 ≤ 先行多 |
| 終い候補 | あり/なし(芝16頭以上でしか付かない) |
| 押上候補 | あり/なし |
| 頭数・芝ダ・距離 | 〜11/12〜15/16〜頭、芝/ダ、〜1400/1500〜1800/1900〜 |

展開: 予想ペース = fc.pace(境は fc.q、learned_pace の学習期間の3等分)。実際のペース = `pace_of(lap)["diff"]` を同じ q で切ったもの。
予想と実際の一致は 2647/4000(66%)、ハイ⇔スロー の大外れは 39鞍(1%)。

**比べ方**: 荒れ方は頭数でほぼ決まる(〜11頭の3連複1万↑ 12%、16頭〜 44%)ので、並びの差は
「その鞍の頭数帯×芝ダ×距離帯の割合の平均(＝見込み)」との差で見た。前半・後半はそれぞれの中で見込みを作った。

## 2. 探し方と、偶然でどれくらい出るか

並び1つ・2つの組み合わせ × ペース(と、ペースを問わない形)を全部作り、鞍100以上の組について
「3連複1万円以上の割合」「穴が3着内に1頭以上の割合」が見込みより ±8pt 以上ずれ、前半・後半それぞれでも同じ向きに ±4pt 以上ずれたものを拾った。

| | 調べた組 | 拾えた組(本物の結果) | 結果を入れ替えたとき(8回) |
|---|---:|---:|---:|
| 予想ペース版 | 685 | **17** | 平均 8.1(5〜13) |
| 実際のペース版 | 698 | **30** | 平均 11.5(6〜19) |

本物の結果では偶然の目安の2〜3倍拾えるので、並びと荒れ方の結びつきはある。ただし拾えた組の半分くらいは偶然でも出る数なので、
1つ1つの組の数字ではなく、**何度も出てくる同じ形**だけをパターンとした。拾えた組は下の3つの形にほぼまとまる。

## 4. まとめ

| 形 | 荒れ方 | 穴馬はどこから |
|---|---|---|
| A 先行多(＋逃げ候補3頭以上)× ハイ | 3連複1万↑ +8〜12pt、穴3着内 +6〜13pt(実際のペースで強い。予想ペースでは重なったときだけ +8〜10) | 予想4角 後ろ・押し上げ(gain≥0.10)・4角で組の外や単独の穴。予想の前の穴の有利が消える |
| B 逃げ候補1・前組外寄り・先行少 × スロー | 穴3着内 −4〜−11pt、3連複1万↑ −2〜−12pt(重なったとき大きい) | 予想4角 前1/3 の穴だけ。後ろ・押し上げの穴は来ない |
| C 前組内寄り × 終い候補あり(芝16頭↑) | 3連複1万↑ +9pt | 終い候補・押し上げの差し、4角で組の外 |

- 予想ペース版は実際のペース版より弱い(予想と実際の一致が66%なので薄まる)。A は予想ハイでも「先行多かつ逃げ候補3+」が重なれば +8〜10pt 出る。
- 差の大きさは全体で ±10pt 前後。偶然の目安と比べて形として出ている、という程度の強さ。
- 見つからなかったもの: ペース単独の差(±3pt 以内)、単騎逃げの有無、押上候補の有無は、ペースと組み合わせても前半・後半でそろわなかった。

## 5. 展開図で使うなら(案)

レース前に出せるのは予想ペース版。

1. **荒れ方の札を1つ出す**(盤面の上、ペースの横):
   - 予想ハイ かつ 先行多(pos1≥0.67 の割合が 0.38 以上)かつ 逃げ候補3頭以上 →「先行過多・荒れ目」。
     穴の候補は予想4角が後ろ1/3で gain≥0.10 の馬、内に閉じ込められない(外寄りの馬番)馬。
   - 予想スロー かつ 逃げ候補1頭 かつ 前組外寄り →「前残り・堅め」。穴を探すなら予想4角 前1/3 の人気薄だけ。
   - 芝16頭以上で 前組内寄り かつ 終い候補あり →「差し届き・荒れ目」。終い候補をそのまま穴の欄へ。
2. 当日、前の鞍のラップでペースが速めに出ている日は A の形を強めに見る(実際ハイのほうが差がはっきりしているため)。
3. 札の数字は「荒れる/堅い」の向きだけ使い、点数(3連複の割合)は出さない(差が ±10pt 程度で、組ごとの数字は偶然の幅が大きい)。

展開図のコードは今回変えていない。
