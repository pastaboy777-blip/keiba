1200mの実測でこの上がりを持つのはこの馬だけ。7/4には1000mを1-1で運んでもいて前後どちらでも形が作れる。
**8番枠だけが前提②と噛み合わない**ので○。

**ヒモ④** … 4番枠・461kg、換算1:19.5で2番目。6-6の位置も条件に合う。
