### 選定

**8頭とも前走6〜8着で勝ち上がった馬がゼロ。** 材料の数（エッジ）は全馬1〜2個で横並びのため、
差がつくのは**時計と上がりの実数だけ**。399も全頭ゼロ（2歳で渋った馬場の中団実績が無い）。

**◎①コアレススピリット** … 1番枠・449kg。8/6の船橋1000が1:05.1で、1200m換算1:19.1。
**8頭で唯一、今日の水準（1:19.6）を上回る時計**を持つ。上がり39.3も8頭で最速。
しかも7-7の位置からで、**前提②「内で脚を溜める」がそのまま身についている**。

**○⑧キョウエイハルナ** … 444kg。8/3の船橋**1200mを9-9-9のまま上39.6**。
1200mの実測でこの上がりを持つのはこの馬だけ。7/4には1000mを1-1で運んでもいて前後どちらでも形が作れる。
**8番枠だけが前提②と噛み合わない**ので○。

**ヒモ④** … 4番枠・461kg、換算1:19.5で2番目。6-6の位置も条件に合う。
**ヒモ⑤** … 445kg、上がり40.0が3番目。

前提③（4歳450kg）は2歳戦なので年齢は不問。**体重帯だけ拾った**（◎449・○444・ヒモ445）。
