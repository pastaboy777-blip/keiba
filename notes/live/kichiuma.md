# 吉馬 地方競馬版 ── 指標の中身と、実測した効き方

データ元 `https://www.kichiuma-chiho.net/`（無料）。**環境のネットワーク許可ドメインに
`www.kichiuma-chiho.net` が入っている必要がある**（2026-10-22 に追加）。

## URL

```
一覧   /php/search.php?date=2026%2F10%2F22&id=18
各鞍   /php/search.php?race_id=202610220118&date=2026%2F10%2F22&no=1&id=18&p=<紙面>
```

- `race_id` = `YYYYMMDD` + `RR`(2桁) + 場コード(2桁)
- 場コード … **浦和 18 / 川崎 21**（笠松 23・園田 27・門別 36）。船橋・大井は id が別で未特定
- `p=` … `sp` 出馬表 / `ls` SP履歴(前走Rnk・過去Rnk) / `rf` ランク紙面(騎手・オッズ・血統) /
  `fp` 推奨紙面(評価・SP能力値・先行力ほか) / `res` 結果

**`p=res` が一番使える。** 1ページに「競走成績」「指標一覧」「配当金」が全部入っている。
取り込みは `scripts/ana/` ではなくスクラッチの `kichi_fetch.py` / `urawa_year.py` 系。

### パースの罠

- 競走成績の行は **16セル**。見出し `上3F(順)` が**1見出しで2セル**使うので、
  角通過順は `c[14]`、人気は `c[15]`。ここを1つずらすと通過順の代わりに上がり順位を読む。
- 指標一覧の行は **25セル**。各指標が (印, 値, 順位) の3セル。
  `0順 1枠 2馬 3評価 4SP能力値 5SP順位 6前走ランク 7過去走ランク 8馬名`
  `9-11先行力 12-14SP信頼 15-17SP調整 18-20SP最大 21-23末脚力 24人気`
- 履歴のない馬（新馬など）は値が `&nbsp;`。int() が落ちるので None にする。

## 指標の意味

| 指標 | 中身 |
|---|---|
| 先行力 | 先行指数から算出。**展開（誰が前に行くか）**を読む指標 |
| 末脚力 | 上がり指数から算出 |
| SP信頼 | スピード指数の近走加重平均（＝近走の調子） |
| SP調整 | 今回の斤量で調整したスピード指数 |
| SP最大 | 過去の最高指数 |
| SP能力値 | 上記を総合した評価。印（◎○▲△…）もこれ |
| **前走ランク A〜D** | **前走1走だけ**のスピード指数を今回斤量で調整してランク付け |
| **過去走ランク W〜Z** | **2〜5走前**（前走を含まない）で、出走馬全体の上位帯の指数を**何回マークしたか** |

## 実測（川崎 10/13-16 + 浦和 10/19-21、84鞍912頭。2026-10-22 にユーザー指示で測定）

### 着順を当てるのは SP 系。先行力ではない

| 1位の馬 | 1着 | 2着内 | 3着内 |
|---|---|---|---|
| SP能力値 | 25% | 39% | 51% |
| SP信頼 | 22% | 36% | 49% |
| SP調整 | 22% | 38% | 49% |
| 末脚力 | 13% | 31% | 47% |
| **先行力** | **10%** | **19%** | **27%** |

先行力は1位でも7位以下でも3着内27%対25%で**差がない**。

評価◎（78頭）は 1着27%・連対41%・3着内54%。
前走ランクA は連対40%（吉馬の公称「約4割」と一致）。

### 先行力が当てているのは「位置」

| 先行力の順位 | 1角で先頭2割 | 4角で先頭2割 |
|---|---|---|
| 1位 | **40%** | 33% |
| 7位以下 | **12%** | 14% |

→ **先行力は買う指標ではなく、展開を組む材料。**

### 先行力の「クセ」── 単独で使うと逆効果

| 先行力1位のうち | 頭数 | 1着 | 3着内 |
|---|---|---|---|
| 1〜3人気 | 22 | 27% | 55% |
| **7人気以下** | **34** | **0%** | **6%** |
| SP能力値3位以内 | 23 | 22% | 43% |
| SP能力値7位以下 | 45 | 4% | 11% |

**人気薄で先行力だけ高い馬は消し。** 前には行くが残らない。

### 穴を指名しているのは 過去走ランク W

6人気以下 492頭（全体 3着内12%）での倍率。

| 条件 | 頭数 | 1着 | 3着内 | 全体比 |
|---|---|---|---|---|
| **過去走ランク W** | 35 | 0 | **29%** | **×2.38** |
| 評価◎○▲ | 57 | 2 | 21% | ×1.76 |
| SP能力値3位以内 | 62 | 2 | 21% | ×1.75 |
| 前走ランクA | 20 | 0 | 10% | ×0.83 |
| **先行力1位** | 41 | **0** | **5%** | **×0.41** |

理由ははっきりしていて、**前走ランクは前走だけを見るので前走大敗＝低ランク＝人気も落ちる**。
**過去走ランクは前走を含まない**ので、「前走は負けたが2〜5走前には何度も走っている馬」が
W に残る。これが「人気は落ちているが能力はある馬」の定義そのものになっている。

6人気以下で3着内に来たW馬10頭のうち **7頭が前走ランク C・D・無印**。
ただし **10頭とも1着なし**（2着3・3着7）。頭ではなく**3連複の相手／馬連の裏**向き。

W は1鞍あたり約1.1頭しか出ない、絞られた印。

## 使い方（ここまでの結論）

1. **軸** … SP能力値（または評価◎）と自分の物差しの両方で上位の馬
2. **展開** … 先行力の上位3頭を並べて「前が揃うか／手薄か」を見る。
   手薄なら位置の重みを上げ、揃うなら末脚力の重みを上げる
3. **穴** … 6人気以下 × 過去走ランクW。複勝・ワイド・3連複の相手
4. **消し** … 人気薄 × 先行力1位 × SP能力値下位

※ 人気は当日しか分からない。前日カードでは「W の馬」を出しておき、
　 当日オッズで6人気以下を確認してから買う形になる。
