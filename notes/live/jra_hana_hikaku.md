# 展開図の先頭候補(ハナ)の出し方の比較(2026-11-14)

ハナの当て方だけの比較。回収率などは測っていない。スクリプト: `scripts/jra_hana_hikaku.py`

## やり方
- 2025-06-01〜2026-11-14 の中央の平地(芝・ダ、新馬・障害を除く、1角の通過順がある鞍)4,586鞍から、日付順に等間隔で 300鞍(補助で 900鞍)。
- jra_kensho.py と同じ組み立て(`from_data` → `build`)を、その日より前の走だけで行う。
  その鞍の行は出走馬・枠・騎手・斤量・馬体重だけ残し、着順・通過順・タイム・上がり・人気を消して渡した(結果は予想に混ざらない)。
- 比べた順(当たり = 1頭目が実際の1角先頭 / 上位3頭に1角先頭がいる)
  - order … `fc.order`(tenkai.forecast。jra_kensho.py の「ハナ」が数えている順)
  - pos1 … 位置モデルの1角(`r["pos1"]`)。**kawa の見解「1コーナーで前に行くのは①②③」が実際に使っているのはこれ**(fc.order ではない)
  - hana … ハナ専用モデル(`apply_hana_model`、線形→LightGBM)
- 3つとも出せた鞍だけで数えた(過去走の通過順が1頭も無い鞍は pos1/hana が出ないので除外: 300鞍中12鞍)。
- 注意: ハナ専用モデルは 2025-11-29 より前の鞍で学習している(`models/hana_model*.json` の cut)。それより前の鞍は学習に使った鞍なので、ハナ専用モデルに甘い。判断は 2025-11-29 以降の鞍で見る。

## 結果(1頭目 / 上位3頭)

| 鞍 | order | pos1(見解) | hana |
|---|---|---|---|
| 300鞍 全体(288) | 34.7% / 59.4% | 31.6% / 60.8% | 36.1% / 66.3% |
| 300鞍 学習より後(195) | 34.9% / 56.4% | 30.3% / 57.9% | 32.3% / 63.1% |
| 300鞍 学習期間(93) | 34.4% / 65.6% | 34.4% / 66.7% | 44.1% / 73.1% |
| 900鞍 全体(854) | 30.3% / 59.5% | 30.6% / 60.4% | 34.0% / 64.6% |
| 900鞍 学習より後(576) | 28.6% / 58.2% | 28.5% / 58.5% | 29.5% / 62.7% |

## 判断: 変えない
- 1頭目: 学習より後の鞍では hana は order・pos1 と +1〜2pt の差しかない(300鞍では order より低い)。
  全体での +3〜4pt は学習期間の鞍(+9〜10pt)に引っぱられた分。基準の「1頭目で +3pt 以上」に届かない。
- 上位3頭: hana は学習より後でも +4〜6pt 良い(63% 前後)。ここははっきり良い。
- よって jra_tenkai_zu.py の見解・kawa の表示は変えていない。上位3頭を「この中のどれか」と出す使い方なら hana の順のほうが良い(kawa 以外の見解 `make_memo` はすでに hana の上位3頭を出している)。
- jra_kensho.py の「ハナ(fc.order の順)」は、kawa の見解が出している pos1 の順とは別物。見解の当たりを数えるなら pos1 で数える必要がある。
