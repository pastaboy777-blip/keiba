# ズブ穴・展開プレイブック（2026-06 学習版・南関＆地方共通）

実戦で検証して固めた運用ルール。新セッションはまずこれを読む。

## 鉄則1：馬場バイアスは「測る」。決め打ちしない
- 買う前に `pace_day.py` で**当日の完了レースの勝ち脚質**を測り、前残り/差しを判定する。
- 馬場状態（重/不良）からバイアスを推定してはいけない。実測例：
  - 笠松 6/25(重) = 逃げ12/12 ＝ 前残り100%
  - 笠松 6/26(不良) = 頭は前だが**人気薄の大穴ヒモは内枠の差し**（7R②差し3着390円・9R③）
  - 浦和 6/26(不良) = 逃げ4/4 ＝ 前残り100%
  - → **同じ「不良」でも笠松と浦和で逆**。状態からは決まらない。トラック×当日で測る。
- **前日・他場のバイアスを持ち越さない**（笠松の重→不良へ前残りを持ち越して外した）。

## 鉄則2：頭とヒモは分けて考える（頭固定は禁物）
- **頭（勝ち・1着）**：前残り馬場では「前で運べる実力馬」（枠不問。外枠の前でも勝つ＝笠松6/26 7R⑨外枠同着勝ち）。
- **人気薄の大穴ヒモ（2-3着）**：**内〜中枠の差し馬**が前崩れを突く（笠松6/26 7R②・9R③）。
- → 買い方：**頭＝前の実力馬 ＋ ヒモ＝内枠の差し穴** で ワイド/3連複の面取り。

## 鉄則3：展開（ペース）で差しを拾う
- 前で運べる馬（senkou>=0.2）が**3頭以上**＝ハイペース→前崩れ→差し台頭。
- `zubu_table --bias pace` が自動判定。差し展開のレースは**内枠の差し穴（③④型）を人気不問で推奨**。
- 「前のセレクトが多すぎ」は危険信号。前が速そうなレースほど差しへ寄せる。

## 鉄則4：内〜中枠
- タイト/前残り/wet では内〜中枠が距離ロスなく有利（笠松6/25 人気薄馬券圏9頭は全部1-6番）。
- `zubu_table --draw inner`（馬番が頭数の約6割以内）。

## 鉄則5：回収率（ROI）の現実
- v2は的中率を上げるが**平均では市場に勝てない**（南関512R 複勝v2本命 55.7% ≒ 穴ベタ買い 55.6%）。
- +EVの兆しは**高確信帯（本命 v2>=2.0）の複勝1点**のみ（笠松6/25 131%・ただし薄標本）。
- **ワイドBOXは不振**（人気薄2-3頭の同時3着内は稀）。広く買わず本命1点の複勝へ寄せる。
- 浦和はv2が効きにくい唯一の場（検証で例外）。浦和は特にバイアス実測を重視。

## 中央競馬（netkeiba）ツール ※2026-06 追加
- `netkeiba.py` … 中央の取得・パース層（結果/ラップ/通過/払戻、レースID/開催日）。
- `nk_pace_day.py` … 中央の当日バイアス測定（通過列で脚質、全ハロンのラップでペース）。
- `nk_zubu.py` … 中央ズブ穴予想（shutuba_pastの近走通過→脚質×枠×差し/前）。馬ごとクロール不要。
- `nk_verify_roi.py` … 中央の複勝/ワイドROIを日次検証（人気薄を結果ページの人気で絞る）。
- 注意：**南関学習v2は中央へ転移しない**ため、中央は脚質×枠×バイアスを主軸にする。

### 実証（函館 2026-06-21＝前残り83%）
- **測ったバイアスに合わせると回収率が激変**：前残り優先の人気薄 複勝本命 **260.8%**／
  差し優先は87.5%。ワイドBOX 372.8%。→ 鉄則1（測る）＋バイアス整合の威力。
- 標準手順：`nk_pace_day`で測る → `nk_zubu --bias <測定結果>` で人気薄を同方向に張る。

## 流れ理論（失速幅）※ユーザー考案・2026-06 ★馬券の核
コーナー出口の急加速の後にどれだけ垂れたか＝失速幅でレースの流れを読む。着順は流れの産物。
- **失速幅 = 残り400-200m − 残り600-400m**（コーナー出口1Fの後にどれだけ遅くなったか）。
- **CA加速スパイク = (残り800-600 + 残り400-200)/2 − 残り600-400**（スパイクの深さ）。
- **流れ型と勝つ脚質**：
  - 失速幅 大(≧1.5)=**前崩壊→差し有利**（前で動いた馬が総崩れ、後方が拾う＝ベルガラス型）。
  - 失速幅 中=立ち回り型（先行・好位・内が残る）。
  - 失速幅 小(≦0.7)=前残り/直線勝負。
- **着順のウソを見抜く**：流れ恵まれ(流れに乗った好走)=次危険 / 流れ泣き(流れ逆風で凡走)=次狙い。
  例: 前崩壊レースを最後方から3着(エスケントバゴ11人気)=流れ恵まれ→次は無条件には買わない。
- **当日戦略**：前半数Rの平均失速幅で当日の流れを測る→差し有利なら後半は差し×人気薄。
  浦和6/26 前半8R平均+1.62=差し有利→ベルガラス2着・エスケントバゴ11人気3着で立証。
- ツール: `flow_day.py`(当日の流れ判定)・`corner_lap.py`(1レースの失速幅/CA・手入力可)・
  `flow_eval.py`(各馬の前走の流れ→次走 狙い/危険)。中央=netkeiba、南関=楽天(当日ラップ有)。笠松はラップ無。

## 鉄則6：6人気以下のv2最上位を「脚質」で安易に格下げしない ★2026-06-29 船橋11Rで学習
- ズブ穴の母集団（6人気以下）の中で**v2が頭抜けて高い馬は、脚質を理由に消してはいけない**。
- **脚質は固定値ではない**。馬場（重/不良）・距離・乗替で前付け/差しは変わる。
  履歴が後方型でも、重馬場で先行に転換して勝つ（=⑥タイセイバンクール）。
- 実証（船橋6/29 11R メイン・重・失速幅+0.2=前残り）：
  6人気以下の抽出4頭 ⑥(v2+1.18)・⑧(+0.86)・③(+0.13)・⑤(-0.38) のうち
  **⑥③⑤がそのまま1-2-3着**（5-9-8人気で三連複は万馬券）。
  - 流れ判定（前残り）は正解。エンジンの抽出も正解（候補4頭中3頭が3着内＝1-2-3着）。
  - **失敗は最終絞り込み**：⑥を「後方型→前残り展開は割引」と手心で格下げし、⑧（最下位9着）を本命にした。
  - → **データ（v2ランク）を信じきる**。脚質先入観のオーバーライドが的中を消した。
- 運用：6人気以下のv2上位は脚質に関わらず本線候補に残す。脚質転換の最終判断は**パドック診断①に委ねる**
  （実が入って前向き＝今日は前で運べる、を現場で確認）＝2本軸の噛み合いどころ。

## 鉄則7：理論ペースで差しに振る前に「当日実測」で答え合わせ ★2026-06-29 大井で学習
- `--bias pace` の差し判定は**理論カウント**（前で運ぶ馬が多い→競り合い→前崩壊→差し）。
  **このカウントが成立しないトラック／開催がある**（前が多くてもそのまま前残りする）。
- 失敗例（大井6/29）：朝イチで**全レース「差し有利」と判定**→中団・後方の人気薄を推奨。
  実際は**勝ち脚質 前11・中1・後0／失速幅は全R 0以下＝超・前残り馬場**で真逆。
  - 穴の正体も**差しではなく「前で残れる人気薄」**：12R⑦7人気逃→1着、1R⑤6人気先→1着・⑨10人気先→3着、8R⑥7人気中→3着。
  - 原因：**鉄則1（測る）の違反**。理論ペースだけで差しに振り、当日の実測を見なかった。
- **厳格化した手順**：
  1. 朝イチ予想は `--bias pace` の理論で叩き台を作ってよい（オッズ前は仮）。
  2. **1〜4R終了時点で必ず `pace_day.py --no-cache` で実測**。前残りと出たら**即 `--bias front` に切替**。
  3. 前残り実測なら穴の本線を**「人気薄の逃げ・先行」**に差し替える（差し穴は買わない）。
- 教訓の根は鉄則6と同じ：**思い込み（理論・脚質先入観）でデータ／実測の素直な答えを歪めない**。

## 鉄則8：上り3Fの"見かけの速さ"に騙されない＝持続戦を見抜く ★2026-06-29 船橋11Rで学習
- **上り3Fが速くても、ラスト1Fが大きく垂れていれば「持続戦」**＝瞬発(キレ)が使えない流れ。
- 指標：**ラスト失速 = ラスト1F − 残り800m以降の区間ベスト1F**。**≥0.8秒で持続戦フラグON**。
- 持続戦では：**後方一気/末脚型は構造的に届かない**（直線で爆発させる余力が残らない）。
  → **好位の持続型を狙う**。穴も「好位で止まらなかった人気薄」。
- 実証（船橋6/29 11R・重・ダ1600 ラップ 12.2-12.0-13.6-13.7-13.0-12.7-12.9-13.7）：
  - 上り3F=39.3（速く見える）／だが残り800mから12.7まで上げる**ロングスパート**→**ラスト200m=13.7**で全馬失速。
  - **ラスト失速 +1.00秒＝持続戦ON**。後方差しは0着内、1人気⑦(中団)6着・2人気④(逃)7着が末脚不発。
  - 残ったのは好位の人気薄 ⑥5人気先1着・③9人気逃2着・⑤8人気先3着（重馬場が末脚減衰を増幅）。
- ツール：`corner_lap.py` が「ラスト失速」「持続戦フラグON/OFF」を出力。差し有利と出ても**持続戦ONなら後方差しを割引**。

## 標準ワークフロー（南関）
0. （前提）朝の叩き台＝`--bias pace`。**買う前に必ず鉄則7の実測で上書き**する。
1. `pace_day.py --place <場> --no-cache` で当日バイアスを測る。
2. 前残り → `zubu_table --bias front`（頭=前の実力馬／穴＝人気薄の逃げ・先行）。差し/ハイペース → `--bias pace`。
3. 人気薄ヒモは `--draw inner` で内枠の差し穴を拾う（※差し有利と実測できた日のみ）。
4. 高確信（v2>=2.0）の本命は複勝1点。ヒモと合わせてワイド/3連複で面取り。
