## 調教読み4層（2026-07-11確立・ユーザー指定で記憶）
中央の調教は「終い1本の数字」で終わらせず、**4層**で読む：

1. **今週の生タイム**（動きの良さ）
   - 最速1F・終い3F・脚色・コース(美W/栗坂/CW/現地芝)。美W=時計出る/栗坂=出にくいのクセ補正必須。

2. **個体比（好走再現度）** ★南関の個体プロファイルの中央版・最重要
   - 各馬の過去3走の調教を全取得（馬ページ→過去raceid→各調教ページ）。
   - **その馬が好走(着≤3)した時の最速1Fと今回を照合**。今回が好走時を締めた＝上昇。
   - 絶対時計でなく"その馬の再現度"なので、時計が出にくい馬でも上昇を拾える。
   - 罠回避：今週最速でも過去3走オール凡走＝「動くけど走らない」を弾ける。

3. **レース別勝ち型（過去3年）**
   - 過去3年の好走馬(3着内)9頭の調教を集計＝そのレース固有の勝ち仕上げ。
   - 例)七夕賞=美W×馬なり×最速1F11秒台前半(全馬なり)／巴賞=馬なりで無理なくgood(馬なり8/9)。
   - 今年の該当馬が「勝ち型」に合うかで軸を締める。脚色が型と違う馬は要注意(巴賞⑨レディネスの一杯等)。

4. **ラップ内部（瞬発/持続/加速度の罠）** ★中央限定(6F-1F全ラップ)
   - 終い1F(瞬発)×終い3F(持続)×加速度=（終い3F-終い1F)/2 - 終い1F（正=尻上がり）。
   - 型: 瞬発◎(1F≤11.5&加速大=切れ→東京向き)／持続◎(3F速く加速小=均等→小回り福島/函館向き)。
   - **加速度の罠**：加速度大でも終い3Fが遅い＝前半緩め→最後だけの"見せ場型"(巴賞パレハ)。加速度は必ず終い3Fとセットで。

5. **調教ラップ型 × 実レースラップ の一致（コース質マッチング）** ★2026-07-12確立・最重要の上位概念
   - Layer4の致命的な落とし穴の修正：**「加速度は大きいほど良い」ではない**。瞬発◎(切れ)が正義なのは"平坦芝の瞬発戦"だけ。
   - **3段の相関**：①**コース質**が → ②**決まりやすいレースラップ(展開)**を規定し → ③その展開に**一致する調教ラップ型**の馬が好走する。
   - コース質 → 想定レースラップ → 買うべき調教ラップ型：
     - **平坦芝(福島・中京等/瞬発戦)** … 上がり勝負 → **瞬発◎(美W切れ・加速+1.5前後)**
     - **洋芝(函館・札幌/持続戦)** … 道中緩まぬミドル持続 → **持続・押し型(加速+0.3〜0.5・終い3F遅めでOK)**。瞬発の切れは過大評価になる。
     - **ダート(前傾消耗戦)** … 前半速く尻上がりに失速・逃げ/地力 → **中加速・地力型(加速+0.65〜1.0)**。芝的な切れは武器にならない。
   - **手順**：まずレース(枠・脚質・過去年ラップ・コース質)から「瞬発戦/持続戦/前傾戦」のどれになるか想定 → その展開に**合致する調教ラップ型**の馬を本命に。
   - データ源：`/cyuou/seiseki/{raceid}` に実レースラップ（ペース/平均ハロン/上がり3F/決め手/ラップ列）が載る＝結果検証で調教型との一致を答え合わせできる。
   - **根拠(2026-07-12・◎3戦全敗の教訓)**：全レースで瞬発◎を本命にしたら、瞬発決着は七夕賞(福島平坦)だけ。巴賞(函館洋芝=持続戦)は持続型ヴーレヴー/レディーが1・2着、瞬発◎の◎シルトホルンは3着。阿蘇S(小倉ダート=前傾戦)は中加速の地力型が1-2-3着独占、瞬発◎の◎ゴッドは5着。好走9頭中7頭が「コース質→レースラップ→調教ラップ型」の一致組だった。
   - 副次の教訓：Layer3(勝ち型)は"型が合う"だけで頭は絞れない。七夕賞は◎カラマも○アスクも同じ美W瞬発◎型で、絶対最速の◎カラマ(終1F11.1)がむしろ仕上げ過ぎで凡走・型内の○アスクが1着＝**型内では絶対最速を過信せず、人気妙味のある方を上に**。

### 5層の精緻化（2026-07-11〜12 週末2日間・7レースのバックテストで確認）
- **コース質は"叩き台の傾向"に過ぎず、最終の展開型は当日の実ペースで確定する**。
  - 実証：**同じ函館・洋芝1800でも、五稜郭S(スロー)は瞬発決着／巴賞(ミドル)は持続決着**と真逆になった。洋芝＝持続とは限らない。
  - → 予想手順を3段に：①**コース質**で叩き台の展開を想定 → ②当日の**想定ペース(ハイ/ミドル/スロー・逃げ馬の質・枠・頭数)**で「瞬発/持続/前傾」を確定 → ③一致する調教ラップ型＋個体比激変の馬を本命。
  - ペース→展開型の目安：スロー/上がり速い=瞬発戦(瞬発◎型)／ミドルで緩まない=持続戦(持続・押し型)／ハイで前傾・尻上がりに失速=消耗戦(中加速・地力型)。ダート1000電撃戦や芝1200先行押し切りも「前傾消耗/先行」寄り＝低〜中加速＋個体比激変が買い。
- **最も強い単一シグナル＝個体比の"激変"（▲1.0秒以上の上昇）**。人気に関わらず勝ち/連対に直結（週末実例：釜山Sベルギューン▲1.3・スノーサイレンス▲1.0、小倉12Rノボリリア▲1.4、巴賞ヴーレヴー▲0.5）。個体比は「維持」より「激変（上昇幅）」を本命優先で。
- **バックテスト結果**：週末7レース中6レースで「展開一致 or 個体比激変」が馬券になった馬を説明。唯一の取りこぼし=安達太良S(福島芝1200)は好走馬の調教シグナルが弱く上がり勝負を展開・決め手で制した"調教外の荒れ"＝**調教は万能でなく、シグナルが弱いレースは無理に本命を作らない**謙虚さも要る。

### 相場観：馬場・開催進行 × 個体比激変の出やすさ（2週分の比較で確認）
5層は「当てる型」だけでなく「その週が堅いか荒れるかを見極める型」としても使える。
- **展開型マッチング(Layer5)は堅い週でも荒れ週でも常に機能**（2週で13レース中12レースを説明）。まずこれで軸の骨格を作る。
- **個体比の激変(穴シグナル)は週次で出る/出ないがある**。この有無で張り方の強弱を変える：
  - 好走馬に個体比▲1.0級の激変馬が"いる週"＝**荒れ/穴週**（今週末7/11-12：ベルギューン・スノーサイレンス・ノボリリア・ヴーレヴーが主役、人気薄好走多発）→ 穴を厚く。
  - 激変馬が"いない週"＝**堅い週**（先週末7/4-5：好走馬に激変ゼロ、1〜2人気の地力・先行で堅く決着）→ 展開型＋人気地力で堅く。
- **馬場（開催進行の荒れ＋当日の雨/道悪）が激変の出やすさを後押しする**：道悪・荒れ馬場は「持続・地力・個体比上積み」型を後押しし穴が出やすい（今週末は巴賞=雨・重で持続型＋個体比▲0.5のヴーレヴー(無印)が差した／開催後半で内外・前後の偏りも増す）。
  - **ただし道悪は"必ず荒れる"ではなく"紛れを増やす"要因**。反例：今週末も阿蘇S・小倉12Rは晴・良で穴(6人気)が出た一方、先週末の北九州記念(G3)は小雨・重でも1人気で堅かった。馬場は確率を動かす一因であって決定要因ではない。
- 実運用：①Layer5で軸の骨格 → ②当週の好走傾向・出走各馬の個体比を見て「激変馬がいるか」を確認 → ③馬場(良/道悪)と開催進行を加味 → 激変馬あり＋道悪なら穴を厚く、なし＋良なら人気地力で堅く。

## 統合予想の型
4層すべてで高評価＝断然の軸。①②で強いが③(脚色)が型外なら対抗どまりの判断材料に。
穴は②(個体比)で大幅上昇＋人気薄。※調教ベースなので脚質/枠/馬場/斤量は当日別途。
