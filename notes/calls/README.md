# 宣言の記録

レースの結果を見る前に「どの物差しで、どの馬か」を1本だけ書き、
あとから突き合わせる。溜まって初めて、条件が本物かどうかが言える。

## なぜこれが要るか

材料をいくつも並べれば、どれかは当たる。そして「どれを使ったか」は
結果を見たあとで選べてしまう。それを避けるために、

1. **レース前に物差しを1つだけ決める**（複数禁止）
2. その物差しの**測定値（的中率・回収率・幅）を先に書く**
3. 該当する馬を機械的に出す。人の判断を入れない
4. 結果を書き足す。良くても悪くても消さない

1鞍の結果で条件を評価しない。14.9%の条件は7回に1回当たるので、
1回当たっても1回外れても、何も分からない。

## 書き方

`calls.jsonl` に1行1宣言。

```
ymd       レース日
race      場とレース番号
rule      使った物差し（1つだけ）
measured  その物差しの測定値（的中率・回収率・幅・母数）
pick      該当馬（機械的に出たものだけ）
why       なぜこの馬が該当するか（1行）
-- ここまでレース前 --
result    着順
payout    複勝の払戻
note      気づいたこと
```

## いまの成績

| | 宣言 | 的中 | 複勝の回収 |
|---|---|---|---|
| 合計 | 1 | 1 | 2040% |

母数1。何も言えない。
