# 内前・稍重の馬場読み & パスタ式◎(ズブ穴)ルール

作成: 2026-07-13(浦和で確立)。ユーザー(パスタ)合意のうえ記録。既存プレイブックは変更せず追加。

## ★馬場読みの核心 ── 「内目追走」= 内枠で先行〜好位につけて前で運ぶ馬
7/13浦和(稍重・内前有利)で確立。**用語の正確な意味を取り違えないこと**:

- **「内目追走」= 内枠で先行/好位につけて前で運ぶ馬**。これが本線。
- **「内追走差し」は"後方差し"ではない**。内を追走して**抜け出す**先行/好位の意。「差し」は差し切る/抜け出すの意で、脚質の後方一気ではない。
- **「逃げ馬ダメ」= 単騎逃げ切りが決まらない**の意。**先行・好位はむしろ本線**(逃げ ≠ 先行)。
- **「外先行きつい」= 外枠の先行がダメ**。**内枠の先行は本線**。
- **後方一気(深い差し)は割引。差しの決め打ちはしない**。
- 稍重・内前(内枠×先行)有利。**1R・2Rで馬場を実証してから確定**する。

### ⚠️戒め(2026-07-13の失敗)
「逃げ馬を選ぶな」を聞いて脚質を"後方差し"へ**真逆に振ったのは過剰修正**。正しくは
**「単騎逃げ✗／内枠の先行・好位○/外先行✗/後方一気△」**。**先行(内)を本線から外さない**。
実力v2＋「前で運べる」軸(強い騎手の複数鞍=陣営本気)が正解に近い。

### 買い方(内前・稍重の型)
- **◎本命 = 実力v2軸**(前で運べる内目の馬)。笹川翼など上位騎手の複数鞍騎乗=陣営本気=軸信頼。
- **鉄則の一撃 = 内枠×先行の人気薄**を3連単3列目に厚く(例: 6R③10人・11R④7人・12R②10人)。
- 鉄板軸(1人気級)は頭固定 → 内枠先行の人気薄へ流す。
- **やや重適性(稍重/重での実績)を加味**。道悪○を上げ、道悪▲は割引。

### 脚質は「通過順」で読む(上がりで判断しない)
- 脚質=道中の通過順(コーナー位置)。**上がり最速≠差し馬**(逃げて上がりも速い馬がいる)。
- 前走を主(重み2)、2走前(重み1)で道中位置%を加重して判定。

## ★パスタ式◎(ズブ穴)の思考 = 「敗因が明確で能力は本物」の人気薄 × 条件好転 × 上昇サイン

### 一般原則(◎の必要条件)
1. **敗因分析**: 前走の負けが〔距離不適/外枠or内枠/馬場逆行/馬体減/位置取り/相手強〕で説明でき、能力否定でない。「不利でも伸びた/差した」は能力の証拠。
2. **相手のレベル**: 好走時の相手が後に出世(現B1等)=クラス通用の裏付け。負けても価値。
3. **上昇のサイン**: 調教師コメント(間隔あけ良化等)・行きっぷり良化・叩き良化・ローテ最適化。
4. **条件好転(今回)**: 適距離への替わり(短縮/延長どちらも"合わせてきた")・枠の好転・馬場適性・転厩後の慣れ。
5. **枠はタイプ別**: 先行=内枠有利／差し・追走=ゴチャつかない外枠がスムーズ(馬場と脚質で好枠が変わる)。
6. **転厩後の着順は割引かない**: 額面でなく"中身"(行きっぷり・位置取り・脚)で見る。

### 事例(パスタの◎理由)
- **7/1大井11R セラフィックコール4着(10人気)**: 調教師「間隔あけて良化」+ 前走敗因=外枠不利&馬体減(能力否定でない)+ 外枠好転狙い。
- **7/1大井8R ペルセイズ1着(6人気)**: 相手が出世(現B1)=クラス通用 + 転厩後着順より行きっぷり + 距離短縮×先行。
- **6/3船橋6R ラヴィンローゼス2着(9人気)**: 距離不適(短すぎ)でも伸びた + 適距離替わり + 外枠(差し馬はスムーズ)+ 道悪得意。

### 機械化できる/できない(役割分担)
- **機械側(私)**: 敗因(枠/馬場/馬体)・相手レベル・距離替わり・行きっぷり(通過順)・叩き・調教ラップ(終い時計の詰まり)・やや重適性 を数値化 → 人気薄を絞る。
- **パスタさん(一次情報)**: 調教師コメント・パドック気配・枠なりの出方・展開読み で最終の◎確信を上乗せ。
