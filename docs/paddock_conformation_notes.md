# 馬体・パドックの覚書(不良馬場巧者の見抜き方)

> データ予想(能力・人気・走らせる観点)で拾えない馬を、**馬体**で補完するための
> 人の目のチェックリスト。パイプラインは馬体データを持たないため自動化できない。
> パドック静止画を共有された際の判断材料として使う。

## 不良馬場(特に時計のかかる/脚抜きの悪いダート)で買える馬体
- **蹄**: やや大きめ・幅広で接地面が広い → 緩い/濡れた馬場で滑らず踏ん張れる。
- **繋ぎ(球節〜蹄)**: 適度な角度(立ちすぎず・寝すぎず)→ 消耗戦の衝撃を吸収しつつ推進。
- **骨格**: 太い管・しっかりした飛節・厚いトモ=パワー優位。重心が低くがっしり。
  → 軽い高速馬場向きの華奢なスピード型とは"逆"のタイプ。
- 馬体重: 大型でも緩く見えず実が入っている。当日**絞れて(マイナス体重で締まって)**いれば尚良。

## 参照ケース(現物の好例)
- **2026-06-03 船橋10R ⑭ レイデルマール**(セ8・497kg(−14)・**単勝70.0倍**)
  - **不良馬場 ダ1000m を1着**。
  - データ面では拾えなかった:能力ランキング非上位、乗替は"弱化"、人気も最低級。
  - 実際の勝因 = **外枠(大外8枠)×荒れバイアス + ベテランのタフさ + パワー型の馬体**。
  - 教訓: **「データで切れても、不良巧者の馬体＋外枠＋荒れ条件なら買える」**。
    馬体は数値化されていない"市場の盲点"になりうる。

## 使い方(運用)
1. データ予想(predict_nankan / ズブ穴)で本線・候補を出す。
2. 不良/重の開催では、**人気薄の中に上記"不良巧者の馬体"がいないか**パドックで確認。
3. いれば**ヒモ穴に格上げ**。特に外枠×荒れ傾向の日は加点。

## 限界(正直に)
- 静止画1枚では蹄の形・繋ぎ角度の精密判定は難しい(横向き静止のアップが要る)。
- 歩様・気配など"動き"は動画必須で、本ツールでは判定不能。
- これは**人の判断を支える覚書**であり、自動予想には組み込まれない。
